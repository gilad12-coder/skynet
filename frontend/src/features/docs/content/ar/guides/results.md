تعرض صفحة التشغيل تقدّم التشغيل ونتائجه. يشرح هذا الدليل التبويبات في صفحة التشغيل، والدرجات، وكيف تصدّر أفضل إصدار أو تقدّمه كخدمة.

## التبويبات في صفحة التشغيل

تعرض صفحة التشغيل فقط التبويبات التي تنطبق على التشغيل. تعتمد بعض التبويبات على المسار والحالة ومستوى خبرتك.

| التبويب                    | متى يظهر                                                           | ما يحتويه                                                                          |
| -------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| **نظرة عامة**              | دائمًا                                                             | التقدّم والدرجات وسجل الدرجات                                                      |
| **الاستخدام**              | تشغيل ناجح لبرنامج يستطيع Skynet تقديمه كخدمة                      | نموذج لتشغيل البرنامج المُحسَّن، وكود التكامل                                      |
| **المخرج**                 | تشغيل موجّه أو كود أو نص له نتيجة                                  | إصدارات العنصر الخاص بك، مع أفضل إصدار                                             |
| **البيانات**               | تشغيل منتهٍ لبرنامج DSPy                                           | البيانات مقسّمة إلى مجموعات التدريب والتحقّق والاختبار، وتقييم مجموعة الاختبار     |
| **الكود**                  | عندما يكون للتشغيل كود يمكن عرضه                                   | كود التشغيل والمقياس                                                               |
| **المكافأة**               | تشغيل موجّه أو كود أو نص يعلن مقياسه عن أجزاء المكافأة             | أجزاء المكافأة وأوزانها                                                            |
| **المخرج**                 | تشغيل له موجّه مُحسَّن أو ملفات مُحسَّنة                           | المخرج المُحسَّن و**تصدير النتائج**                                                |
| **السجلات**                | معظم التشغيلات                                                     | سجل التشغيل                                                                        |
| **الاستخدام والتكلفة**     | عندما تكون مسجّل الدخول                                            | ما أنفقه التشغيل                                                                   |
| **تشغيل مجدول**            | تشغيل ناجح لموجّه أو كود أو نص                                     | جدول لتشغيل التحسين مرة أخرى                                                       |
| **الإعدادات**              | دائمًا                                                             | إعدادات التشغيل                                                                    |

> [!NOTE]
> في المستوى **الموجَّه**، تخفي صفحة التشغيل تبويبات **البيانات** و**الكود** و**السجلات** و**الإعدادات**. الرابط المباشر إلى أحد هذه التبويبات يفتحه مع ذلك. غيّر المستوى في **الإعدادات ← الحساب**.

## الدرجات

يختار Skynet الإصدارات على حالات التحقّق. ويبلّغ عن الدرجة النهائية على حالات الاختبار. لا ترى المحرّكات حالات الاختبار أبدًا. اقرأ [مجموعات البيانات والتقسيمات](/docs/concepts/datasets).

يعرض تبويب **نظرة عامة**:

- **التحسُّن**: التغيير من إصدار البداية إلى أفضل إصدار.
- **تطوّر النتيجة**: الدرجة على مدار التشغيل.
- **تفصيل النتيجة**: كل مقياس، مع الأعمدة **الأساس** و**مُحسَّن** و**التغيير**.

ما دام التشغيل نشطًا، تعرض النظرة العامة أيضًا **المنقضي** و**المتبقي** و**المعدّل**.

لتشغيل موجّه أو كود أو نص، تعرض النظرة العامة أيضًا **الدرجات المسماة** عندما يبلّغ مقياسك عن درجات مسماة.

لتشغيل برنامج DSPy، يحتوي تبويب **البيانات** على **تقييم مجموعة الاختبار**. يعرض درجة الأساس والدرجة المُحسَّنة لكل حالة اختبار.

### عندما يكون أفضل إصدار هو إصدار البداية

أحيانًا لا يتفوّق أي مرشّح على إصدار البداية. عندها يُرجع Skynet إصدار البداية. يخبرك تبويب **المخرج** بأنه طُبّقت حماية من التراجع.

إذا توقف التشغيل عند ميزانيته، تخبرك صفحة التشغيل بالإصدار الذي حفظه Skynet. اقرأ [عمليات التشغيل](/docs/concepts/runs).

## تصدير أفضل إصدار

### تشغيلات الموجّه والكود والنص

يسرد تبويب **المخرج** **الإصدارات** الخاصة بالعنصر. لكل إصدار يمكنك:

- نسخ الإصدار.
- تنزيل الإصدار كملف.
- لتشغيل مستودع، تنزيل الإصدار كملف zip للمستودع كله.

يمكنك مقارنة إصدار بإصدار آخر. يعرض التبويب أيضًا **ملاحظات المُقيِّم** لكل إصدار.

### تشغيلات برامج DSPy

في تبويب **المخرج** لوحة **تصدير النتائج**. افتح قائمة **تنزيل**. تعرض الصيغ المتاحة للتشغيل:

| الخيار              | الصيغة                                                  |
| ------------------- | ------------------------------------------------------- |
| برنامج DSPy         | `.zip`، تصدير مكتفٍ ذاتيًا يمكنك تشغيله                 |
| البرنامج المُحسَّن  | `.pkl`                                                  |
| الموجّه             | `.json`                                                 |
| الكود المُحسَّن     | `.py`                                                   |
| السجلات             | `.csv`                                                  |

## تقديم أفضل إصدار كخدمة

يمكنك استدعاء برنامج DSPy مُحسَّن من الكود الخاص بك. لتبويب **الاستخدام** جزءان:

- نموذج إدخال. أدخل حقول الإدخال واختر **تشغيل** للحصول على تنبؤ.
- **كود التكامل** بلغات cURL وPython وJavaScript وGo وDSPy.

يعمل البرنامج دائمًا على إعدادات النموذج التي حُسِّن بها. يجب أن تعطي جميع حقول الإدخال. يتجاهل Skynet الحقول الإضافية.

لاستدعاء البرنامج، أنشئ رمز API في **الإعدادات ← API**. ثم أرسل طلبًا:

```bash tab="cURL"
export APP_API_TOKEN=skyd_...
curl -X POST "$API_URL/serve/<optimization_id>" \
  -H "Authorization: Bearer $APP_API_TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"question": "What is DSPy?"}}'
```

```python tab="Python"
import os
import uuid
import requests

response = requests.post(
    f"{os.environ['API_URL']}/serve/<optimization_id>",
    headers={
        "Authorization": f"Bearer {os.environ['APP_API_TOKEN']}",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={"inputs": {"question": "What is DSPy?"}},
)
print(response.json()["outputs"])
```

استبدل `question` بحقول الإدخال في برنامجك. يملأ **كود التكامل** في تبويب **الاستخدام** عنوان URL الحقيقي وأسماء الحقول لك.

تحتوي الاستجابة على `outputs` و`input_fields` و`output_fields` و`model_used`.

> [!TIP]
> يقبل جسم الطلب أيضًا `max_cost_cents`. يعيّن أقصى تكلفة لهذا الاستدعاء الواحد، بالسنتات. بعض التشغيلات تتطلبه.

للحصول على مخرجات جزئية فور وصولها، أرسل الطلب نفسه إلى `/serve/<optimization_id>/stream`. الاستجابة هي تدفق من أحداث server-sent events.

اقرأ [API](/docs/api) للمصادقة ونقاط النهاية الأخرى.
