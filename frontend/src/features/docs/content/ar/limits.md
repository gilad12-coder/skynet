يضع Skynet حدودًا على عمليات التشغيل والملفات والتخزين ومعدّلات الطلبات. تحافظ هذه الحدود على استقرار المنصة وتحمي رصيدك. تسرد هذه الصفحة القيم الافتراضية. يستطيع المسؤول تغيير بعض الحدود لحساب معيّن.

> [!NOTE]
> القيم في هذه الصفحة هي القيم الافتراضية الحالية. عندما تبلغ حدًا، يخبرك التطبيق أو الواجهة بالحد الذي أوقف الطلب.

## عمليات التشغيل

| الحد                              | مجاني | Pro   |
| --------------------------------- | ----- | ----- |
| عمليات التشغيل النشطة في الوقت نفسه | 5     | 20    |
| عمليات التشغيل المحفوظة            | 100   | 1,000 |

التشغيل النشط هو تشغيل حالته `pending` أو `validating` أو `running` أو `paused`. عندما يكون لديك الحد الأقصى من عمليات التشغيل النشطة، يرفض Skynet عمليات التشغيل الجديدة حتى ينتهي أحدها.

يحسب حد عمليات التشغيل المحفوظة جميع عمليات التشغيل الخاصة بك. احذف عمليات التشغيل التي لا تحتاجها لإفساح المجال لعمليات جديدة.

إذا فشل تجديد Pro، يحتفظ الحساب بحدود Pro لمدة 7 أيام. بعد ذلك، يستخدم حدود الخطة المجانية حتى ينجح الدفع.

| الحد                                     | القيمة                                                          |
| ---------------------------------------- | --------------------------------------------------------------- |
| النسخ في طلب استنساخ واحد عبر API         | من 1 إلى 5                                                      |
| محاولات الاسترداد التلقائي لتشغيل واحد    | 3                                                               |
| الحالات النموذجية في فحص العقد            | 3                                                               |
| أحداث التقدّم المخزّنة لكل تشغيل           | 5,000. يزيل Skynet الأحداث الأقدم أولًا.                         |
| عمر بيئة معزولة واحدة                     | 45 دقيقة. التشغيل الذي يحتاج وقتًا أطول يفتح بيئة معزولة جديدة.  |

اقرأ [عمليات التشغيل](/docs/concepts/runs) لتعرف كيف تعمل محاولات الاسترداد.

## التخزين

| الحد            | مجاني   | Pro    |
| --------------- | ------- | ------ |
| إجمالي التخزين  | 250 MiB | 10 GiB |

يشمل إجمالي التخزين عمليات التشغيل ومجموعات البيانات والسجلات ومحادثات الوكيل والملفات المرفوعة المؤقتة وبيانات البحث. يرفض Skynet أي كتابة تتجاوز حد التخزين الخاص بك.

تشمل الموصّلات التي تستورد السجلات جداول قواعد البيانات وآثار LLM (traces) وقواعد بيانات Notion. اقرأ [تجهيز مجموعة بيانات](/docs/guides/datasets).

### ملفات مساحة العمل في المعالج

| الحد                              | القيمة                                                                  |
| --------------------------------- | ----------------------------------------------------------------------- |
| الملفات الإضافية في مساحة العمل    | 20                                                                      |
| طول اسم الملف                      | 120 حرفًا                                                               |
| عمق المجلدات                       | 3 مجلدات                                                                |
| أنواع الملفات                      | `.py`, `.txt`, `.md`, `.json`, `.yaml`, `.csv`, `.toml`, `.ini`, `.cfg` |

الملفان `run.py` و`metric.py` هما ملفا الدخول للتشغيل. لا يمكنك حذفهما أو إعادة تسميتهما أو نقلهما.

## معدلات الطلبات

| الحد                                                                 | القيمة                                       |
| -------------------------------------------------------------------- | -------------------------------------------- |
| إرسال عمليات التشغيل                                                 | 30 لكل حساب في دقيقة متحرّكة                 |
| مقاطع الإملاء                                                        | 120 لكل حساب في الساعة                       |
| الملفات المقروءة لمحادثات الوكيل                                      | 300 لكل حساب في الساعة                       |
| طلبات الحساب (التسجيل، إعادة تعيين كلمة المرور، التحقق من البريد)      | 20 لكل عنوان بريد إلكتروني في ساعة متحرّكة   |
| أدوار مساعد المعالج                                                  | 50 لكل حساب في يوم UTC                       |
| رموز (tokens) البحث والفهرسة                                         | 2,000,000 لكل حساب في الشهر                  |

عندما تتجاوز حد معدّل، تُرجع الواجهة حالة HTTP `429`. انتظر، ثم أرسل الطلب مرة أخرى.

عندما يتجاوز حساب رموز البحث والفهرسة الشهرية، يتوقف Skynet عن فهرسة العناصر الجديدة لذلك الحساب. ويعمل البحث بعد ذلك كما لو أن البحث الدلالي غير متاح.
