يتيح خادم Skynet MCP لوكيل ذكاء اصطناعي أن يستخدم Skynet نيابةً عنك. يمكن لـ Claude وChatGPT وCodex وCursor وعملاء MCP الآخرين فحص إعداد تشغيل، وبدء عمليات التشغيل، ومتابعتها، وإيقافها. توافق على الاتصال مرة واحدة في متصفحك. ويضع الوكيل حد إنفاق لكل تشغيل.

## عنوان URL للخادم

يستخدم كل عميل العنوان نفسه:

```text
https://mcp.skynetml.com/mcp
```

يستخدم الخادم Streamable HTTP. ويستخدم تسجيل الدخول OAuth 2.1. لا تنسخ أي رمز أو مفتاح API إلى العميل.

## ربط العميل

اختر عميلك. اتبع خطواته، ثم انتقل إلى [الموافقة على الاتصال](#الموافقة-على-الاتصال).

```skynet-mcp-clients

```

## الموافقة على الاتصال

في المرة الأولى التي يستدعي فيها الوكيل Skynet، يفتح متصفحك صفحة من Skynet.

1. سجّل الدخول إلى Skynet، إن لم تكن مسجّلًا.
2. اقرأ الصفحة. تعرض اسم الوكيل، والموقع الذي يعود إليه، وحسابك.
3. اقرأ ما يستطيع الوكيل فعله:
   - رؤية عمليات التحسين الخاصة بك ونتائجها.
   - بدء عمليات التحسين وإيقافها، مع الدفع من رصيدك.
4. انقر **Allow** للاتصال. انقر **Deny** للإيقاف.

بعد أن تنقر **Allow**، يعود المتصفح إلى الوكيل. يستطيع الوكيل الآن استدعاء الأدوات أدناه.

> [!NOTE]
> يضع الوكيل حد إنفاق لكل تشغيل. ولا يستطيع إضافة أموال.

## الأدوات

| الأداة      | ما الذي تفعله                                                                  | الوصول |
| ----------- | ------------------------------------------------------------------------------ | ------ |
| `check_run` | تفحص إعداد تشغيل دون تشغيله ودون أن تُحاسَب. وتقترح حد إنفاق.                   | قراءة  |
| `start_run` | تبدأ تشغيلًا بحد إنفاق.                                                         | كتابة  |
| `get_run`   | تُرجع الحالة والإنفاق، والنتيجة عندما ينتهي التشغيل.                            | قراءة  |
| `list_runs` | تسرد عمليات التشغيل الخاصة بك، الأحدث أولًا. ويمكنها التصفية حسب الحالة.         | قراءة  |
| `stop_run`  | توقف تشغيلًا. يُرجع الاستدعاء الثاني خطأً يفيد بأن التشغيل انتهى بالفعل.          | كتابة  |

يستخدم الوصول للقراءة النطاق `runs:read`. ويستخدم الوصول للكتابة النطاق `runs:write`.

لا توجد أداة تضيف أموالًا أو تغيّر رصيدك أو تغيّر إعدادات الفوترة.

## كيف يشغل الوكيل عملية تحسين

1. يستدعي الوكيل `check_run` مع إعداد التشغيل. يُجري Skynet الفحوص الثابتة ويُرجع:
   - نتيجة كل فحص.
   - أدنى حد إنفاق يمكن أن يبدأ به التشغيل.
   - حد إنفاق مقترح. لا يقل عن 5.00 دولارات.
   - النماذج التي ليس لها سعر معروف.
   - المبلغ الذي يمكنك إنفاقه الآن.
2. يستدعي الوكيل `start_run` مع حد إنفاق (`max_cost_cents`، من 1 إلى 1,000,000 سنت أمريكي). ويمكنه أيضًا إرسال `idempotency_key`، حتى لا تبدأ إعادة المحاولة تشغيلًا ثانيًا.
3. إذا كان فحص الإعداد ما زال قيد التنفيذ، تُرجع `start_run` القيمتين `in_progress` و`retry_after_seconds`. يستدعي الوكيل `start_run` مرة أخرى بالمُدخلات نفسها بعد ذلك الوقت.
4. يستدعي الوكيل `get_run` حتى ينتهي التشغيل. الحالات النهائية هي `success` و`failed` و`cancelled` و`stopped`.

> [!TIP]
> أخبر الوكيل بحد إنفاقك في موجّهك، مثل "حسّن هذا الموجّه. أنفق 10 دولارات على الأكثر." عندها يستخدم الوكيل هذا الحد في `start_run`.

يتوقف التشغيل عندما يبلغ حد إنفاقه. اقرأ [الفوترة](/docs/concepts/billing) لتعرف كيف يحاسب Skynet على التشغيل.

## الأمان

- يحصل كل عميل على تفويض خاص به. لا يرى العميل كلمة مرورك أبدًا.
- يستخدم تسجيل الدخول PKCE (S256). يسجّل العميل نفسه عبر التسجيل الديناميكي للعملاء أو عبر مستند بيانات وصفية لمعرّف العميل (client ID metadata document).
- تنتهي صلاحية رموز الوصول بعد ساعة واحدة. يجدّدها العميل برمز تحديث.
- تنتهي صلاحية رمز التحديث بعد 30 يومًا دون استخدام. ويدوم التفويض 90 يومًا على الأكثر. بعدها توافق على الاتصال مرة أخرى.
- يعمل كل رمز تحديث مرة واحدة فقط. إذا استخدم أحد رمز تحديث قديمًا مرة أخرى، يُنهي Skynet التفويض.
- لا يستطيع الوكيل أن يرى أو يغيّر إلا عمليات التشغيل الخاصة بك.

اقرأ [الأمان](/docs/security) لتعرف كيف يحمي Skynet حسابك وبياناتك.

## قطع الاتصال

لقطع اتصال وكيل، أزل خادم Skynet من العميل. تُبطل معظم العملاء رموزها بعد ذلك. إذا لم يُبطلها العميل، تنتهي صلاحية رمز التحديث الخاص به بعد 30 يومًا دون استخدام.

## استكشاف الأخطاء وإصلاحها

| المشكلة                                    | ما الذي تفعله                                                           |
| ------------------------------------------ | ----------------------------------------------------------------------- |
| يفشل الاتصال فورًا                          | تحقّق من عنوان الخادم. يجب أن يكون `https://mcp.skynetml.com/mcp` بالضبط. |
| "This agent can't connect"                 | ابدأ الاتصال مرة أخرى من العميل.                                         |
| "Too many attempts"                        | انتظر بضع دقائق، ثم حاول مرة أخرى.                                       |
| لا يفتح العميل متصفحًا                      | حدّث العميل. يجب أن يدعم خوادم MCP البعيدة مع OAuth.                      |
| تفشل `start_run` بخطأ في الرصيد             | أضف أموالًا في Skynet، أو ابدأ التشغيل بحد إنفاق أقل.                     |
| تتوقف الأدوات عن العمل بعد بضعة أسابيع      | انتهت صلاحية التفويض. أزل الخادم واتصل مرة أخرى.                          |

للوصول المباشر عبر HTTP دون وكيل، اقرأ [API](/docs/api).
