Skynet מגדיר מגבלות על ריצות, קבצים, אחסון וקצב בקשות. המגבלות שומרות על יציבות הפלטפורמה ומגינות על היתרה שלך. העמוד הזה מציג את ערכי ברירת המחדל. מנהל מערכת יכול לשנות חלק מהמגבלות לחשבון מסוים.

> [!NOTE]
> הערכים בעמוד הזה הם ברירות המחדל הנוכחיות. כשמגיעים למגבלה, האפליקציה או ה-API מציינים איזו מגבלה עצרה את הבקשה.

## ריצות

| מגבלה                 | Free | Pro   |
| --------------------- | ---- | ----- |
| ריצות פעילות בו-זמנית | 5    | 20    |
| ריצות שמורות          | 100  | 1,000 |

ריצה פעילה היא ריצה בסטטוס `pending`,‏ `validating`,‏ `running` או `paused`. כשיש לך את המספר המרבי של ריצות פעילות, Skynet דוחה ריצות חדשות עד שאחת מהן מסתיימת.

המגבלה על ריצות שמורות סופרת את כל הריצות שלך. כדי לפנות מקום לריצות חדשות, מחק/י ריצות שאין בהן צורך.

אם חידוש של Pro נכשל, החשבון שומר את מגבלות Pro למשך 7 ימים. אחרי זה הוא משתמש במגבלות Free עד שהתשלום מצליח.

| מגבלה                          | ערך                                               |
| ------------------------------ | ------------------------------------------------- |
| עותקים בבקשת שכפול אחת ב-API   | 1 עד 5                                            |
| ניסיונות שחזור אוטומטיים לריצה | 3                                                 |
| מקרים לדוגמה בבדיקת החוזה      | 3                                                 |
| אירועי התקדמות שמורים לכל ריצה | 5,000. Skynet מסיר קודם את האירועים הישנים ביותר. |
| משך החיים של sandbox אחד       | 45 דקות. ריצה שצריכה יותר זמן פותחת sandbox חדש.  |

קרא/י את [ריצות](/docs/concepts/runs) כדי להבין איך ניסיונות שחזור עובדים.

## אחסון

| מגבלה      | Free    | Pro    |
| ---------- | ------- | ------ |
| אחסון כולל | 250 MiB | 10 GiB |

האחסון הכולל כולל את הריצות, הדאטאסטים, הלוגים, הצ'אטים עם הסוכן, ההעלאות הממתינות ונתוני החיפוש שלך. Skynet דוחה כתיבה שתחרוג ממגבלת האחסון שלך.

## קבצים ודאטאסטים

| מגבלה                             | ערך                         |
| --------------------------------- | --------------------------- |
| קובץ דאטאסט שנשמר בספרייה         | 50 MiB לכל קובץ, אחרי דחיסה |
| שורות ממחבר שמייבא רשומות         | 20,000                      |
| קובץ שמצורף לצ'אט עם הסוכן        | 20 MiB                      |
| טקסט שנקרא מקובץ מצורף אחד בצ'אט  | 50,000 תווים                |
| קטע שמע להכתבה                    | 25 MB                       |
| ארכיון של מאגר קוד ב-GitHub       | 200 MiB, דחוס               |
| קובץ ממאגר הקוד שנפתח בעמוד הריצה | 1 MiB                       |

מחברים שמייבאים רשומות כוללים טבלאות מסד נתונים, LLM traces ומסדי נתונים של Notion. קרא/י את [הכנת דאטאסט](/docs/guides/datasets).

### קבצי סביבת העבודה באשף

| מגבלה                      | ערך                                                                     |
| -------------------------- | ----------------------------------------------------------------------- |
| קבצים נוספים בסביבת העבודה | 20                                                                      |
| אורך שם קובץ               | 120 תווים                                                               |
| עומק תיקיות                | 3 תיקיות                                                                |
| סוגי קבצים                 | `.py`, `.txt`, `.md`, `.json`, `.yaml`, `.csv`, `.toml`, `.ini`, `.cfg` |

`run.py` ו-`metric.py` הם קובצי הכניסה של ריצה. אי אפשר למחוק, לשנות שם או להעביר אותם.

## קצב בקשות

| מגבלה                                          | ערך                              |
| ---------------------------------------------- | -------------------------------- |
| הגשות של ריצות                                 | 30 לכל חשבון בדקה מתגלגלת        |
| קטעי הכתבה                                     | 120 לכל חשבון בשעה               |
| קבצים שנקראים לצ'אטים עם הסוכן                 | 300 לכל חשבון בשעה               |
| בקשות חשבון (הרשמה, איפוס סיסמה, אימות אימייל) | 20 לכל כתובת אימייל בשעה מתגלגלת |
| תורות של העוזר באשף                            | 50 לכל חשבון ביום UTC            |
| טוקנים של חיפוש ואינדוקס                       | 2,000,000 לכל חשבון בחודש        |

כשחורגים ממגבלת קצב, ה-API מחזיר סטטוס HTTP‏ `429`. יש לחכות, ואז לשלוח את הבקשה שוב.

כשחשבון חורג מהטוקנים החודשיים של חיפוש ואינדוקס, Skynet מפסיק לאנדקס פריטים חדשים לחשבון הזה. אחר כך החיפוש עובד כאילו חיפוש סמנטי לא זמין.
