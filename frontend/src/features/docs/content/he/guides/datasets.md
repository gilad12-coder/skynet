דאטאסט הוא טבלה של דוגמאות. ריצת אופטימיזציה לומדת ממנו ומקבלת ציון לפיו. המדריך הזה מסביר איך להעלות קובץ, לערוך שורות ועמודות, להגדיר תפקידי עמודות ולשתף דאטאסט. להסבר על המושגים, קרא/י את [דאטאסטים](/docs/concepts/datasets).

## קבצים נתמכים

Skynet קורא את סוגי הקבצים האלה:

| סיומת           | איך Skynet קורא אותה                                                          |
| --------------- | ----------------------------------------------------------------------------- |
| `.csv`          | השורה הראשונה היא שורת הכותרות. הקובץ צריך לפחות שורת נתונים אחת.             |
| `.json`         | מערך של אובייקטים, או אובייקט אחד. המפתחות של האובייקט הראשון הופכים לעמודות. |
| `.xlsx`, `.xls` | Skynet קורא רק את הגיליון הראשון.                                             |

Skynet דוחה סיומות אחרות עם ההודעה "Unsupported file format".

> [!TIP]
> כדאי לשים את הפלט הצפוי בעמודה האחרונה. אשף ההגשה מסמן את העמודה האחרונה כפלט כברירת מחדל.

### דוגמת CSV

```csv
question,answer
What is the capital of France?,Paris
How many legs does a spider have?,8
```

### דוגמת JSON

```json
[
  { "question": "What is the capital of France?", "answer": "Paris" },
  { "question": "How many legs does a spider have?", "answer": "8" }
]
```

## העלאת דאטאסט

1. פתח/י את **דאטאסטים**.
2. לחץ/י על **העלאת דאטאסט**, או גרור/גררי קובץ אל העמוד. בזמן הגרירה העמוד מציג "שחרר/י כדי להעלות".
3. חכה/חכי להודעה "הדאטאסט נשמר בספרייה".

Skynet משתמש בשם הקובץ בלי הסיומת כשם הדאטאסט. כדי לשנות אותו, בחר/י את הדאטאסט ולחץ/י על **שנה/שני שם**.

> [!NOTE]
> לכל חשבון יש מכסת אחסון. אם העלאה חורגת מהמכסה, Skynet פותח חלון שמסביר את המגבלה. ראה/ראי [מגבלות](/docs/limits).

אפשר גם להעלות קובץ באשף ההגשה ("העלו קובץ CSV,‏ JSON או Excel") או לצרף קובץ ב[פאנל הסוכן](/docs/guides/agent-panel).

## חיפוש דאטאסט

הספרייה מציגה את הדאטאסטים שלך. השתמש/י ב-**חיפוש לפי שם** כדי לסנן את הרשימה. דאטאסטים שאנשים אחרים שיתפו איתך מופיעים תחת **משותף איתי**.

כשבוחרים דאטאסט אחד, מופיעות הפעולות האלה:

- **תיוג הדאטאסט** פותח את [כלי התיוג](/docs/guides/tagger) עם הדאטאסט הזה.
- **עריכת נתונים** פותח את עורך הדאטאסט.
- **שתף/שתפי** פותח את חלון השיתוף.
- **שנה/שני שם** משנה את שם הדאטאסט.

פעולות נוספות הן **שמור/שמרי עותק** ו-**מחק/י**.

> [!WARNING]
> מחיקה מסירה את הדאטאסט מהספרייה שלך לצמיתות. אי אפשר לבטל אותה. ריצות שנבנו מהדאטאסט נשארות תקינות, אבל הקישור שלהן אליו נשבר.

## עריכת דאטאסט

העורך מציג את הדאטאסט כטבלה. הוא מציג 100 שורות בכל עמוד. השתמש/י ב-**השורות הבאות** וב-**השורות הקודמות** כדי לעבור בין עמודים.

### שינוי שורות ועמודות

- **הוספת שורה** ו-**הוספת עמודה** מוסיפות תאים חדשים בסוף.
- **הוספת שורה מעל** ו-**הוספת שורה מתחת** מוסיפות שורה ליד השורה שנבחרה.
- **שכפול שורה**, **מחיקת שורה**, **מחיקת עמודה** ו-**שינוי שם עמודה** משנות את המבנה.
- **גרירה למילוי** מעתיקה ערך של תא לתאים שלידו.
- **ביטול** ו-**ביצוע מחדש** מבטלות או חוזרות על השינוי האחרון.

לחץ/י לחיצה כפולה על שורה כדי לראות אותה במלואה.

### שמירה

העורך שומר את השינויים אוטומטית, זמן קצר אחרי כל עריכה. בזמן השמירה הסטטוס מציג **שומר…**. אם השמירה נכשלת, הסטטוס מציג **השמירה נכשלה**.

> [!NOTE]
> העורך לא יכול לשמור דאטאסט בלי שורות. הוא מציג "הוסיפו שורה כדי לשמור את השינויים" עד שמוסיפים שורה.

בסיום, לחץ/י על **חזרה לספרייה**.

### גישת קריאה בלבד

אם יש לך תפקיד צופה בדאטאסט משותף, העורך נפתח במצב קריאה בלבד. כדי לשנות את הנתונים, בקש/י מהבעלים את תפקיד העורך, או השתמש/י ב-**שמור/שמרי עותק**.

### תיוג עם AI

בעורך יש פעולה **תיוג עם AI**. היא פותחת את כלי התיוג, שבו מודל AI עוזר לך להוסיף תיוגים. ראה/ראי [תיוג נתונים עם כלי התיוג](/docs/guides/tagger).

## הגדרת תפקידי עמודות

ריצה צריכה לדעת אילו עמודות הן קלטים ואיזו עמודה היא הפלט הצפוי. מגדירים את התפקידים האלה כשמגישים ריצה, לא בעורך הדאטאסט.

באשף ההגשה, השלב "איך לקרוא את הנתונים" מציג כל עמודה עם שלוש אפשרויות:

- **קלט**: התוכנית מקבלת את הערך הזה.
- **פלט**: התשובה הצפויה שפונקציית המדידה (Metric) משווה אליה.
- **דלג/י**: הריצה מתעלמת מהעמודה הזו.

ברירות המחדל הן:

- כל עמודה היא קלט, והעמודה האחרונה היא הפלט.
- לדאטאסט עם עמודה אחת יש קלט אחד ואין פלט.

כשאין עמודת פלט, Skynet משתמש בשורה הראשונה כקלט אחד. חובה לבחור לפחות עמודת קלט אחת.

חלק מהעמודות יכולות להכיל גם תמונות. בעמודות האלה, בחר/י **תמונה** או **טקסט** כדי להגיד ל-Skynet איך לקרוא את הערכים.

> [!TIP]
> עורך הדאטאסט מציג תג "פלט" על עמודות פלט. עמודה חדשה שמוסיפים בעורך מתחילה כקלט.

האשף גם מחלק את השורות לחלקים לאימון ולהערכה. סכום החלקים חייב להיות 1. כשהסכום שונה, האשף מציג "סכום החלוקה חייב להיות 1.". לתהליך המלא, קרא/י את [הגשת ריצה](/docs/guides/submit).

## שיתוף דאטאסט

בחר/י דאטאסט ולחץ/י על **שתף/שתפי**. החלון **שיתוף ופרטיות** נפתח.

### גישה דרך קישור

| אפשרות                     | מי יכול לפתוח את הדאטאסט                        |
| -------------------------- | ----------------------------------------------- |
| **מוגבל**                  | רק הבעלים ואנשים שהוזמנו.                       |
| **כל מי שיש לו את הקישור** | כל אדם מחובר שיש לו את הקישור, עם התפקיד שבחרת. |

לדאטאסט במצב "כל מי שיש לו את הקישור", בחר/י את התפקיד שהקישור נותן: **צופה** או **עורך**. לחץ/י על **העתק/העתיקי קישור** כדי להעתיק את הכתובת.

### הזמנת אנשים

1. תחת **הזמנת אנשים**, הקלד/י שם משתמש ב-**הוסף/הוסיפי אנשים לפי שם משתמש**.
2. לחץ/י על **הזמן/הזמיני**.
3. בדוק/בדקי את הרשימה תחת **אנשים עם גישה**. השתמש/י ב-**שנה/שני תפקיד** כדי לשנות את התפקיד של אדם.

התפקידים הם:

| תפקיד | גישה                                          |
| ----- | --------------------------------------------- |
| בעלים | שליטה מלאה, כולל ניהול שיתוף ומחיקה.          |
| עורך  | גישת צופה, ובנוסף הרצת המודל, צ'אט ושינוי שם. |
| צופה  | פותח את הדאטאסט. העורך במצב קריאה בלבד.       |

### העברת בעלות

השתמש/י ב-**העבר/העבירי בעלות** כדי לתת את הדאטאסט לאדם אחר. Skynet מבקש ממך לאשר.

> [!WARNING]
> אחרי ההעברה, את/ה הופך/ת לעורך/ת ומאבד/ת את הרשאות הבעלים.
