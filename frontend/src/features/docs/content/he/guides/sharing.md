אפשר לשתף ריצה עם אנשים אחרים, ואפשר להציג אותה בגלריה הציבורית בעמוד **חיפוש** (Explore). אלה שתי הגדרות שונות. גישה דרך קישור והזמנות קובעות מי יכול לפתוח ריצה. חשיפה ציבורית קובעת אם הריצה מופיעה בחיפוש הציבורי. המדריך הזה מסביר את שתיהן.

## ברירות מחדל

| הגדרה | ברירת מחדל לריצה חדשה |
| --- | --- |
| חשיפה ציבורית | **ציבורי**. הריצה מופיעה בחיפוש הציבורי. |
| גישה דרך קישור | **מוגבל**. רק הבעלים ואנשים שהוזמנו יכולים לפתוח את הריצה. |
| תפקיד עבור **כל מי שיש לו את הקישור** | **צופה** |

אשף ההגשה מציג את הנראות של ריצה חדשה במסך האחרון שלו. משנים אותה אחרי שהריצה מתחילה, בחלון **שיתוף ופרטיות**.

> [!WARNING]
> ריצות חדשות הן ציבוריות כברירת מחדל. אם הריצה שלך מכילה נתונים שמשתמשים אחרים לא צריכים לראות, הגדר/י אותה כ-**פרטי** בחלון **שיתוף ופרטיות**.

## פתיחת הגדרות השיתוף

בעמוד הריצה, בחר/י **שיתוף ופרטיות**. רק הבעלים של הריצה רואים את הכפתור הזה.

## תפקידים

לכל אדם שיכול לפתוח ריצה יש אחד משלושה תפקידים:

| תפקיד | מה האדם יכול לעשות |
| --- | --- |
| **צופה** | לפתוח את הריצה ולראות את התוצאות שלה ואת הבעלים שלה. לשכפל את הריצה. |
| **עורך** | גישת צופה, ובנוסף הרצת המודל, צ'אט ושינוי שם. עורך יכול גם לבטל, להשהות, להמשיך ולנסות שוב את הריצה. |
| **בעלים** | שליטה מלאה, כולל ניהול שיתוף ומחיקה. |

לריצה יש בדיוק בעלים אחד. כל מי שפותח ריצה משותפת חייב להתחבר. אין גישה אנונימית לריצה משותפת.

## שיתוף קישור

1. פתח/י את **שיתוף ופרטיות**.
2. תחת **גישה דרך קישור**, בחר/י אחת מהאפשרויות האלה:
   - **מוגבל**: רק הבעלים ואנשים שהוזמנו יכולים לפתוח את הריצה.
   - **כל מי שיש לו את הקישור**: כל משתמש מחובר שיש לו את הקישור יכול לפתוח את הריצה.
3. עבור **כל מי שיש לו את הקישור**, בחר/י את התפקיד שהקישור נותן: **צופה** או **עורך**. קישור אף פעם לא נותן את התפקיד **בעלים**.
4. בחר/י **העתק/העתיקי קישור**.

לקישור יש הצורה `/share/<token>`. ה-token הוא החלק בקישור שקשה לנחש. אם הקישור בוטל, או שהריצה נמחקה, הקישור מציג **השיתוף לא נמצא**.

> [!NOTE]
> סודות, כמו מפתחות API וכתובות בסיס, אף פעם לא מופיעים בריצה משותפת.

## הזמנת אנשים

1. פתח/י את **שיתוף ופרטיות**.
2. תחת **הזמנת אנשים**, הזן/הזיני שם משתמש. הרשימה מציגה עד 10 משתמשים שמתאימים.
3. בחר/י תפקיד: **צופה** או **עורך**.
4. בחר/י **הזמן/הזמיני**.

**אנשים עם גישה** מציג את כל מי שיש לו תפקיד בריצה. לכל אדם אפשר:

- לשנות את התפקיד.
- להסיר את הגישה.

כל אדם מקבל את הגישה הגבוהה ביותר שהכללים נותנים לו. לדוגמה, עורך שהוזמן נשאר בתפקיד **עורך** גם כשהקישור נותן **צופה**.

### העברת בעלות

אפשר לתת את הריצה למשתמש אחר:

1. פתח/י את תפריט התפקיד של אדם ב-**אנשים עם גישה**. אפשר גם להשתמש בתפריט התפקיד תחת **הזמנת אנשים**.
2. בחר/י **העבר/העבירי בעלות**.
3. אשר/י את ההעברה.

הבעלים החדש מקבל שליטה מלאה. את/ה הופך/ת לעורך/ת ומאבד/ת את הרשאות הבעלים.

## חשיפה ציבורית

חשיפה ציבורית קובעת אם ריצה מופיעה בחיפוש הציבורי בגלריה בעמוד **חיפוש**. היא לא משנה את הגישה דרך קישור או את ההזמנות.

| אפשרות | משמעות |
| --- | --- |
| **ציבורי** | מופיע בחיפוש הציבורי. גלוי לכל המשתמשים. |
| **פרטי** | מוסתר מהחיפוש הציבורי. גלוי רק לך ולאנשים שהוזמנו. |

רק הבעלים יכולים לשנות את החשיפה הציבורית. השינוי חל מיד.

## גלריית Explore

עמוד **חיפוש** (Explore) מאפשר לחפש אופטימיזציות. יש בו שלוש לשוניות:

| לשונית | מה היא מציגה |
| --- | --- |
| **שלי** | האופטימיזציות שלך, פרטיות וציבוריות |
| **ציבורי** | אופטימיזציות ציבוריות של משתמשים אחרים |
| **שותף איתי** | אופטימיזציות שמשתמשים אחרים שיתפו איתך |

השתמש/י בשורת החיפוש וב-**מסננים** כדי למצוא ריצות.

אפשר לפתוח ריצה ציבורית מעמוד החיפוש רק אם היא הסתיימה בסטטוס `success`. כשפותחים אותה:

- מקבלים את התפקיד **צופה**. אפשר לקרוא את הריצה ולשכפל אותה.
- העמוד מציג את הבעלים של הריצה.
- Skynet מסיר סודות, כמו מפתחות API וכתובות בסיס.
- אי אפשר להריץ את המודל. המודל היה מנצל את המפתח של הבעלים.

> [!TIP]
> כדי לתת לאדם אחד יותר גישה לריצה ציבורית, הזמן/הזמיני אותו כ-**עורך**.
