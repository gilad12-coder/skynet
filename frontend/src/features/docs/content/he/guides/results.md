עמוד הריצה מציג את ההתקדמות ואת התוצאות של ריצה. המדריך הזה מסביר את הלשוניות בעמוד הריצה, את הציונים, ואיך לייצא את הגרסה הטובה ביותר או להפעיל אותה כשירות.

## לשוניות בעמוד הריצה

עמוד הריצה מציג רק את הלשוניות שרלוונטיות לריצה. חלק מהלשוניות תלויות בסוג התוצר הסופי, בסטטוס וברמת הניסיון שלך.

| לשונית           | מתי היא מופיעה                                                   | מה יש בה                                                      |
| ---------------- | ---------------------------------------------------------------- | ------------------------------------------------------------- |
| **סקירה**        | תמיד                                                             | התקדמות, ציונים והיסטוריית הציונים                            |
| **שימוש**        | ריצה מוצלחת עם תוכנית ש-Skynet יכול להפעיל כשירות                | טופס להרצת התוכנית המיועלת, וקוד לשילוב                       |
| **תוצר**         | ריצת פרומפט, קוד או טקסט עם תוצאה                                | הגרסאות של התוצר הסופי שלך, עם הגרסה הטובה ביותר              |
| **נתונים**       | ריצת תוכנית DSPy שהסתיימה                                        | חלוקת הנתונים לסט אימון, סט אימות וסט בדיקה, והערכת סט הבדיקה |
| **קוד**          | כשיש לריצה קוד להציג                                             | קוד ההרצה ופונקציית המדידה (Metric)                           |
| **תגמול**        | ריצת פרומפט, קוד או טקסט שפונקציית המדידה שלה מגדירה רכיבי תגמול | רכיבי התגמול והמשקלים שלהם                                    |
| **תוצר**         | ריצה עם פרומפט או קבצים מיועלים                                  | הפלט המיועל ו-**ייצוא תוצאות**                                |
| **לוגים**        | רוב הריצות                                                       | הלוג של הריצה                                                 |
| **שימוש ועלות**  | בזמן התחברות                                                     | כמה הריצה הוציאה                                              |
| **ריצה מתוזמנת** | ריצת פרומפט, קוד או טקסט מוצלחת                                  | לוח זמנים להרצת האופטימיזציה שוב                              |
| **הגדרות**       | תמיד                                                             | התצורה של הריצה                                               |

> [!NOTE]
> ברמה **מודרך**, עמוד הריצה מסתיר את הלשוניות **נתונים**, **קוד**, **לוגים** ו-**הגדרות**. קישור ישיר ללשונית כזו עדיין פותח אותה. אפשר לשנות את הרמה ב-**הגדרות → חשבון**.

## ציונים

Skynet בוחר גרסאות לפי מקרי האימות. הוא מדווח את הציון הסופי לפי מקרי הבדיקה. המנועים אף פעם לא רואים את מקרי הבדיקה. קרא/י את [דאטאסטים וחלוקה](/docs/concepts/datasets).

הלשונית **סקירה** מציגה:

- **שיפור**: השינוי מגרסת ההתחלה לגרסה הטובה ביותר.
- **מהלך הציונים**: הציון לאורך הריצה.
- **פירוט הציון**: כל פונקציית מדידה, עם העמודות **בסיס**, **משופר** ו-**שינוי**.

בזמן שהריצה פעילה, הסקירה מציגה גם **זמן שעבר**, **נותר** ו-**קצב**.

בריצת פרומפט, קוד או טקסט, הסקירה מציגה גם **ציונים בעלי שם** כשפונקציית המדידה שלך מדווחת ציונים בעלי שם.

בריצת תוכנית DSPy, בלשונית **נתונים** יש **הערכת סט הבדיקה**. היא מציגה את ציון הבסיס ואת הציון המיועל לכל מקרה בדיקה.

### כשהגרסה הטובה ביותר היא גרסת ההתחלה

לפעמים אף מועמד לא עוקף את גרסת ההתחלה. במקרה כזה Skynet מחזיר את גרסת ההתחלה. הלשונית **תוצר** מציינת שהופעל מנגנון הגנה מפני נסיגה.

אם הריצה נעצרה בגלל התקציב, עמוד הריצה מציין איזו גרסה Skynet שמר. קרא/י את [ריצות](/docs/concepts/runs).

## ייצוא הגרסה הטובה ביותר

### ריצות פרומפט, קוד וטקסט

הלשונית **תוצר** מציגה את ה**גרסאות** של התוצר הסופי שלך. לכל גרסה אפשר:

- להעתיק את הגרסה.
- להוריד את הגרסה כקובץ.
- בריצה על מאגר קוד, להוריד את הגרסה כקובץ zip של כל המאגר.

אפשר להשוות גרסה לגרסה אחרת. הלשונית מציגה גם את **משוב המדד** של כל גרסה.

### ריצות תוכנית DSPy

בלשונית **תוצר** יש פאנל **ייצוא תוצאות**. פתח/י את התפריט **הורד/הורידי**. הוא מציג את הפורמטים שיש לריצה:

| אפשרות        | פורמט                           |
| ------------- | ------------------------------- |
| תוכנית DSPy   | `.zip`, ייצוא עצמאי שאפשר להריץ |
| תוכנית מיועלת | `.pkl`                          |
| פרומפט        | `.json`                         |
| קוד מיועל     | `.py`                           |
| לוגים         | `.csv`                          |

## הפעלת הגרסה הטובה ביותר כשירות

אפשר לקרוא לתוכנית DSPy מיועלת מהקוד שלך. בלשונית **שימוש** יש שני חלקים:

- טופס. הזן/הזיני את שדות הקלט ובחר/י **הרץ/הריצי** כדי לקבל תחזית.
- **קוד לשילוב** ב-cURL,‏ Python,‏ JavaScript,‏ Go ו-DSPy.

התוכנית תמיד רצה עם הגדרות המודל שאיתן היא עברה אופטימיזציה. חובה לתת את כל שדות הקלט. Skynet מתעלם משדות נוספים.

כדי לקרוא לתוכנית, צור/צרי טוקן API ב-**הגדרות → API**. אחר כך שלח/י בקשה:

```bash tab="cURL"
export APP_API_TOKEN=skyd_...
curl -X POST "$API_URL/serve/<optimization_id>" \
  -H "Authorization: Bearer $APP_API_TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"question": "What is DSPy?"}}'
```

```python tab="Python"
import os
import uuid
import requests

response = requests.post(
    f"{os.environ['API_URL']}/serve/<optimization_id>",
    headers={
        "Authorization": f"Bearer {os.environ['APP_API_TOKEN']}",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={"inputs": {"question": "What is DSPy?"}},
)
print(response.json()["outputs"])
```

החלף/החליפי את `question` בשדות הקלט של התוכנית שלך. **קוד לשילוב** בלשונית **שימוש** ממלא בשבילך את הכתובת האמיתית ואת שמות השדות.

התשובה מכילה את `outputs`, את `input_fields`, את `output_fields` ואת `model_used`.

> [!TIP]
> גוף הבקשה מקבל גם את `max_cost_cents`. השדה הזה קובע את העלות המרבית של הקריאה הזו, בסנטים. חלק מהריצות דורשות אותו.

כדי לקבל פלטים חלקיים בזמן שהם מגיעים, שלח/י את אותה בקשה אל `/serve/<optimization_id>/stream`. התשובה היא זרם של server-sent events.

קרא/י את [API](/docs/api) לגבי אימות ולגבי שאר ה-endpoints.
