Skynet משפר תוצר שכבר יש לך. נותנים לו גרסת התחלה, קבוצת מקרים ופונקציית מדידה (Metric). Skynet מציע גרסאות חדשות, מריץ כל אחת מהן על המקרים שלך, נותן ציון לפלט בעזרת פונקציית המדידה שלך, ושומר את הגרסה הטובה ביותר.

## מה Skynet משפר

Skynet עובד עם ארבעה סוגי תוצרים:

| סוג התוצר | מה משתנה |
| --- | --- |
| פרומפט | הטקסט של הפרומפט |
| קוד | קוד המקור |
| תוכנית DSPy | ההוראות של ה-predictors ב-`dspy.Module` |
| טקסט | כל טקסט אחר, למשל מסמך או קובץ הגדרות |

כל ריצה משתמשת באותו חוזה. קוד ההרצה שלך מגדיר `run(artifact, input)`. פונקציית המדידה שלך מגדירה `score(input, output, expected=None)`. פונקציית המדידה מחזירה ציון ומשוב כתוב. האופטימייזר קורא את המשוב כדי לשפר את הגרסה הבאה.

> [!NOTE]
> קוד ההרצה ופונקציית המדידה רצים ב-sandbox, בתהליכים נפרדים. קוד ההרצה לא רואה את קוד המקור של פונקציית המדידה ולא את הערכים הצפויים.

## שני מסלולים

ל-Skynet יש שני מסלולי אופטימיזציה:

- **DSPy** משפר תוכנית DSPy בעזרת האופטימייזרים של DSPy: DSPy GEPA,‏ DSPy MIPROv2 ו-DSPy BootstrapFewShot.
- **Optimize Anything** מתייחס לתוצר כקופסה שחורה. הוא משתמש במנועים GEPA,‏ Best-of-N,‏ Meta-Harness,‏ AutoResearch,‏ AutoSaddler ו-ShinkaEvolve.

**Auto** בוחר בשבילך. בתוכנית DSPy,‏ Auto משתמש ב-DSPy GEPA. בסוגי תוצרים אחרים, Auto משלב חמישה מנועי קופסה שחורה. קרא/י את [DSPy ו-Optimize Anything](/docs/concepts/paths) ואת [מנועים](/docs/concepts/engines).

## איך ריצה עובדת

1. מתארים את המשימה וקובעים את גרסת ההתחלה.
2. נותנים את המקרים. Skynet מחלק אותם לקבוצות אימון, אימות ובדיקה.
3. בוחרים אופטימייזר, מודלים ותקציב.
4. כותבים את קוד ההרצה ואת פונקציית המדידה. בדיקת חוזה מריצה אותם על מקרים לדוגמה.
5. Skynet מריץ את האופטימיזציה ומציג את התוצאות.

Skynet בוחר גרסאות לפי מקרי האימות. הוא מדווח על הציון הסופי לפי מקרי הבדיקה. המנועים אף פעם לא רואים את מקרי הבדיקה.
