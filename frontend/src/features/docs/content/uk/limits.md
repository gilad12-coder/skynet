Skynet встановлює ліміти на запуски, файли, сховище й частоту запитів. Ліміти підтримують стабільність платформи й захищають ваш баланс. На цій сторінці наведено типові значення. Адміністратор може змінити деякі ліміти для окремого акаунта.

> [!NOTE]
> Значення на цій сторінці — поточні типові значення. Коли ви досягаєте ліміту, застосунок або API повідомляє, який саме ліміт зупинив запит.

## Запуски

| Ліміт                              | Free | Pro   |
| ---------------------------------- | ---- | ----- |
| Одночасно активні запуски          | 5    | 20    |
| Збережені запуски                  | 100  | 1 000 |

Активний запуск — це запуск зі статусом `pending`, `validating`, `running` або `paused`. Коли кількість активних запусків досягає максимуму, Skynet відхиляє нові запуски, доки один із них не завершиться.

Ліміт збережених запусків враховує всі ваші запуски. Видаліть непотрібні запуски, щоб звільнити місце для нових.

Якщо продовження Pro не вдається, акаунт зберігає ліміти Pro протягом 7 днів. Після цього він використовує ліміти Free, доки оплата не пройде.

| Ліміт                                              | Значення                                                         |
| -------------------------------------------------- | ---------------------------------------------------------------- |
| Копії в одному запиті API на клонування            | Від 1 до 5                                                       |
| Спроби автоматичного відновлення запуску           | 3                                                                |
| Приклади кейсів у перевірці контракту              | 3                                                                |
| Збережені події прогресу для кожного запуску       | 5 000. Skynet спершу видаляє найстаріші події.                   |

Як працюють спроби відновлення, описано в розділі [Запуски](/docs/concepts/runs).

## Сховище

| Ліміт              | Free    | Pro    |
| ------------------ | ------- | ------ |
| Загальне сховище   | 250 MiB | 10 GiB |

Загальне сховище включає ваші запуски, набори даних, журнали, чати з агентом, підготовлені завантаження й пошукові дані. Skynet відхиляє запис, який перевищив би ваш ліміт сховища.

## Частота запитів

| Ліміт                                                                          | Значення                                                  |
| ------------------------------------------------------------------------------ | --------------------------------------------------------- |
| Надсилання запусків                                                            | 30 для кожного акаунта за ковзну хвилину                  |
| Кліпи для диктування                                                           | 120 для кожного акаунта за годину                         |
| Файли, прочитані для чатів з агентом                                           | 300 для кожного акаунта за годину                         |
| Запити акаунта (реєстрація, скидання пароля, підтвердження електронної пошти)  | 20 для кожної адреси електронної пошти за ковзну годину   |
| Ходи асистента майстра                                                         | 50 для кожного акаунта за добу UTC                        |
| Токени пошуку й індексування                                                   | 2 000 000 для кожного акаунта на місяць                   |

Коли ви перевищуєте обмеження частоти, API повертає HTTP-статус `429`. Зачекайте, а потім надішліть запит знову.

Коли акаунт перевищує місячний обсяг токенів пошуку й індексування, Skynet припиняє індексувати нові елементи для цього акаунта. Після цього пошук працює так, ніби семантичний пошук недоступний.
