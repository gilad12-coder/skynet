Запуск — це одна оптимізація. Він має статус, ліміт витрат і набір збережених версій. На цій сторінці пояснено стани запуску, дії, які можна виконати із запуском, і причини, з яких запуск зупиняється.

## Стани запуску

Кожен запуск має один із цих статусів:

| Статус       | Значення                                                                 |
| ------------ | ------------------------------------------------------------------------ |
| `pending`    | Запуск у черзі.                                                          |
| `validating` | Skynet перевіряє налаштування перед початком оптимізації.                |
| `running`    | Оптимізатор пропонує та оцінює нові версії.                              |
| `success`    | Запуск завершено. Найкращу версію збережено.                             |
| `failed`     | Помилка зупинила запуск.                                                 |
| `cancelled`  | Користувач скасував запуск.                                              |
| `paused`     | Запуск зупинився на контрольній точці. Його можна відновити.             |
| `stopped`    | Запуск зупинився, вичерпавши бюджет. Він зберігає найкращу знайдену версію. |

`success`, `failed`, `cancelled`, `stopped` і `paused` — кінцеві стани. Оптимізатор не працює із запуском у кінцевому стані. `paused` — єдиний кінцевий стан, призначений для відновлення.

## Дії

Сторінка запуску показує дії, які відповідають поточному статусу та вашій ролі. API має ті самі дії.

| Дія              | Коли її можна використати                                                                                         | Що вона робить                                                               |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Призупинити**  | Запуск виконується і має збережену контрольну точку.                                                              | Зупиняє запуск на контрольній точці. Статус змінюється на `paused`.          |
| **Скасувати**    | Запуск має статус `pending`, `validating` або `running`.                                                          | Зупиняє запуск. Скасування не можна відмінити.                               |
| **Відновити**    | Запуск має статус `failed`, `cancelled`, `paused` або `stopped` через бюджет і має збережену контрольну точку.    | Продовжує той самий запуск з останньої контрольної точки. Запуск зберігає свій id. |
| **Клонувати**    | Будь-коли, коли ви бачите запуск.                                                                                 | Відкриває майстер надсилання з копією конфігурації.                          |
| **Видалити**     | Запуск у кінцевому стані. Лише власник.                                                                           | Остаточно видаляє запуск і всі його дані.                                    |

API також має ще дві дії для запуску зі статусом `failed` або `cancelled`:

- **Повторити** починає новий запуск із тією самою конфігурацією. Новий запуск отримує новий id.
- **Перезапустити** знову починає той самий запуск із самого початку. Запуск зберігає свій id.

> [!NOTE]
> Повтор, перезапуск і клонування через API відхиляють запуск, який має власний ліміт витрат. Відкрийте конфігурацію в майстрі надсилання й задайте новий бюджет, перш ніж почати новий запуск. Кнопка **Клонувати** на сторінці запуску робить це за вас.

Клонування через API може створити від 1 до 5 копій за один запит. Кожна копія зараховується до ваших лімітів запусків. Див. [Обмеження](/docs/limits).

### Хто може виконувати дії

Ваша роль у запуску визначає, які дії ви бачите:

- **Власник** може виконувати всі дії, керувати спільним доступом і видалити запуск.
- **Редактор** може призупинити, скасувати, відновити й повторити запуск, а також підвищити його ліміт витрат.
- **Глядач** може відкрити запуск і клонувати його.

Прочитайте [Спільний доступ і публікація](/docs/guides/sharing), щоб дізнатися більше про ролі.

## Як запуск зупиняється

Запуск зупиняється з однієї з чотирьох причин.

### Завершення

Оптимізатор завершує роботу. Статус змінюється на `success`. Skynet зберігає найкращу версію і виконує фінальний тест. Прочитайте [Читання результатів](/docs/guides/results).

### Бюджет

Запуск не має оцінки вартості перед стартом. Його ліміт витрат — це бюджет, який він може використати. Skynet вимірює реальну вартість кожного запуску оцінювача під час роботи:

1. Skynet чекає на 10 завершених запусків оцінювача. До цього вартість одного виклику надто нестабільна, щоб на неї спиратися.
2. Skynet використовує середню вартість на цей момент, щоб оцінити ціну наступної ітерації. Він множить ціну на 1,5, бо пізніші ітерації зазвичай коштують більше.
3. Коли залишку бюджету не вистачає на наступну ітерацію, Skynet перестає приймати нову роботу. Оптимізатор зупиняється на наступному платному виклику.

Після цього запуск має статус `stopped` і причину зупинки `budget_reached`. Сторінка запуску показує повідомлення **Бюджет вичерпано**. Повідомлення вказує, яку версію зберіг Skynet:

- Вашу найкращу оцінену версію.
- Вашу оцінену початкову версію, якщо кращої версії не знайдено.
- Жодної версії, якщо бюджет закінчився до того, як будь-який кандидат пройшов оцінювання. Ваші вхідні дані й журнали залишаються збереженими.

Щоб продовжити, натисніть **Підвищити ліміт і продовжити** у повідомленні. Skynet відновлює запуск з останньої контрольної точки.

> [!TIP]
> Запуск із режимом **Без ліміту** витрачає баланс вашого рахунку, доки не завершиться. Якщо баланс закінчиться, запуск зупиняється і зберігає те, що має. Тоді повідомлення показує **Баланс рахунку вичерпано**. Поповніть баланс, а потім відновіть запуск.

Деякі старіші запуски призупинилися з причиною зупинки `budget_projected`. Їх можна відновити так само.

### Збій

Помилка зупиняє запуск. Статус змінюється на `failed`. Вкладка **Журнали** показує, що сталося. Якщо запуск має збережену контрольну точку, його можна відновити. Його також можна повторити.

Якщо воркер зупиняється під час виконання вашого завдання, Skynet відновлює завдання й пробує знову. Після 3 спроб Skynet позначає завдання як невдале. Відновлення після збою або скасування також зараховується як спроба. Відновлення після призупинення або зупинки через бюджет не зараховується.

### Скасування

Ви скасовуєте запуск. Статус змінюється на `cancelled`. Скасування не можна відмінити. Пізніше ви можете відновити запуск зі збереженої контрольної точки або повторити його.
