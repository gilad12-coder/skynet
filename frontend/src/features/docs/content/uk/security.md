Ця сторінка описує, як Skynet захищає ваш акаунт, ваші ключі та ваші дані. Вона також пояснює, як повідомити про проблему безпеки.

## Повідомлення про вразливість

Повідомляйте про проблеми безпеки приватно. Не створюйте публічний issue.

- На GitHub відкрийте репозиторій Skynet і перейдіть до **Security** > **Report a vulnerability**.
- Або надішліть лист на `security@skynetml.com`.

Команда намагається підтвердити отримання кожного повідомлення протягом п’яти робочих днів.

## Ваш акаунт

### Способи входу

Увійти можна за допомогою:

- Адреси електронної пошти й пароля.
- **Продовжити з Google** або **Продовжити з GitHub**.
- **Увійти за допомогою ключа доступу**. Ключ доступу використовує Face ID, Touch ID або апаратний ключ.

Постачальниками, якими ви користуєтеся, можна керувати в розділі **Пов’язані акаунти**.

### Правила для пароля

Пароль має:

- Містити щонайменше 8 символів.
- Містити щонайбільше 128 символів.
- Не містити вашої адреси електронної пошти.

Новий акаунт має підтвердити адресу електронної пошти кодом. Скидання пароля також використовує код, який Skynet надсилає електронною поштою.

Після повторних невдалих спроб Skynet на певний час блокує вхід для цієї адреси електронної пошти.

### Двоетапна перевірка

Для додаткового захисту ввімкніть двоетапну перевірку. Оберіть один спосіб:

| Спосіб                              | Як це працює                                                      |
| ----------------------------------- | ----------------------------------------------------------------- |
| **Додаток для автентифікації**      | Введіть 6-значний код зі свого додатка для автентифікації.        |
| **Коди на електронну пошту**        | Введіть 6-значний код, який Skynet надсилає під час кожного входу. |

Skynet також надає вам коди відновлення. Зберігайте їх у надійному місці. Використайте один із них, якщо втратите доступ до свого способу перевірки.

> [!NOTE]
> Якщо ви входите через Google або GitHub, вашою двоетапною перевіркою керує цей постачальник.

## Де виконується ваш код

Робочі навантаження користувачів виконуються в ізольованих пісочницях. У хостинговому продукті межею виконання є Vercel Sandbox. Це стосується перевірок налаштувань, запусків оптимізації, відновлення й роботи із завершеними запусками.

Воркери Skynet не виконують ваш код. Вони є площиною керування. Вони запускають завдання, резервують і розраховують бюджети, видають пісочницям облікові дані з обмеженою областю дії та зберігають контрольні точки.

Перш ніж почати платну роботу, Skynet резервує запас у вашому гаманці та в бюджеті запуску. Див. [Бюджети й оплата](/docs/concepts/billing).

У [застосунку для Mac](/docs/guides/mac-app) завдання виконуються в локальних контейнерах Docker. Усі локальні сервіси слухають лише `127.0.0.1`.

## Ключі постачальників (BYOK)

Ви можете додати власні ключі постачальників моделей.

- Skynet шифрує кожен ключ під час зберігання.
- Skynet ніколи не повертає повний ключ через API.
- Skynet зберігає лише останні чотири символи й статус: неперевірений, перевірений або недійсний.
- Коли ви вводите ключ, Skynet надсилає невеликий тестовий запит, щоб його перевірити.

Коли ви використовуєте власний ключ, постачальник стягує плату безпосередньо з вашого ключа. Skynet і далі стягує з вашого балансу комісію платформи й плату за використання пісочниці.

Skynet також видаляє секрети з журналів і повідомлень про помилки. Він замінює їх на `[REDACTED]`.

## API-токени

API-токени дають змогу скриптам та інструментам викликати API Skynet.

- Кожен користувач має щонайбільше один дійсний токен. Коли ви генеруєте новий токен, старий перестає працювати.
- Токени починаються з `skyd_`.
- Skynet зберігає лише хеш токена.
- Skynet показує повний токен лише один раз. Одразу скопіюйте й збережіть токен.
- Після цього Skynet показує лише замасковану форму: `skyd_…` і останні чотири символи.

Передавайте токен у заголовку `Authorization`:

```http
Authorization: Bearer skyd_...
```

Щоб анулювати токен, натисніть **Відкликати токен**. Повний опис API наведено в розділі [API](/docs/api).

> [!WARNING]
> Поводьтеся з токеном як з паролем. Будь-хто з цим токеном може діяти від вашого імені через API. Не комітьте його в репозиторій.

## Конфіденційність даних у моделях

Налаштування **Конфіденційність даних у моделях** визначає, що постачальники моделей можуть робити з вашими даними. Воно стосується оптимізацій, які Skynet оплачує з вашого балансу.

| Варіант               | Дія                                                                                                      |
| --------------------- | -------------------------------------------------------------------------------------------------------- |
| **Дозволити всіх**    | Будь-який постачальник, зокрема ті, що можуть навчатися на ваших промптах або зберігати їх.             |
| **Без навчання**      | Лише постачальники, які не навчаються на ваших промптах і не зберігають їх. Це типове значення.          |
| **Без зберігання**    | Лише кінцеві точки з угодою про нульове зберігання даних. Деякі моделі можуть бути недоступні.           |

> [!NOTE]
> Оптимізації з вашим власним ключем підпорядковуються налаштуванням конфіденційності вашого акаунта OpenRouter.

## Видимість запусків

> [!WARNING]
> Нові запуски за замовчуванням **Публічні**. Публічний запуск з’являється в публічному пошуку. Будь-хто може знайти його й переглянути його результати.

Щоб запуск не потрапив у публічний пошук, під час надсилання встановіть **Видимість** на **Приватний**. Видимість можна змінити пізніше в діалозі спільного доступу. Див. [Спільний доступ і публікація](/docs/guides/sharing).

Нові набори даних мають доступ **Обмежений**. Відкрити їх можете лише ви й люди, яких ви запросили, доки ви не зміните доступ за посиланням. Див. [Підготовка набору даних](/docs/guides/datasets).

## Ваші дані

Щоб керувати своїми даними, відкрийте вкладку **Конфіденційність і дані** в **Налаштуваннях**.

### Експорт даних

Натисніть **Експорт** у розділі **Експортувати мої дані**. Експорт містить усі дані вашого акаунта. Оберіть один формат: JSON, CSV, Excel, Pickle, Parquet або Feather.

### Видалення акаунта

Натисніть **Видалити обліковий запис**. Для підтвердження введіть свій поточний пароль і вашу адресу електронної пошти.

> [!WARNING]
> Ця дія назавжди видаляє ваш акаунт і всі його дані. Її не можна скасувати.

### Аналітика використання

Налаштування **Надсилати анонімну аналітику використання** вмикає або вимикає анонімну аналітику продукту.
