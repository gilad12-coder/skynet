Набір даних — це таблиця прикладів, на яких запуск оптимізації навчається і за якими оцінює результати. У цьому посібнику показано, як завантажити файл, редагувати рядки та стовпці, задати ролі стовпців і надати спільний доступ до набору даних. Про основні поняття читайте в [Набори даних](/docs/concepts/datasets).

## Підтримувані файли

Skynet читає такі типи файлів:

| Розширення      | Як Skynet його читає                                                                     |
| --------------- | ---------------------------------------------------------------------------------------- |
| `.csv`          | Перший рядок — рядок заголовків. Файл має містити щонайменше один рядок даних.           |
| `.json`         | Масив об’єктів або один об’єкт. Ключі першого об’єкта стають стовпцями.                  |
| `.xlsx`, `.xls` | Skynet читає лише перший аркуш.                                                          |

Інші розширення Skynet відхиляє з повідомленням «Unsupported file format».

> [!TIP]
> Розмістіть очікуваний вивід в останньому стовпці. Майстер надсилання за замовчуванням позначає останній стовпець як вивід.

### Приклад CSV

```csv
question,answer
What is the capital of France?,Paris
How many legs does a spider have?,8
```

### Приклад JSON

```json
[
  { "question": "What is the capital of France?", "answer": "Paris" },
  { "question": "How many legs does a spider have?", "answer": "8" }
]
```

## Завантаження набору даних

1. Відкрийте **Набори даних**.
2. Натисніть **Завантажити набір даних** або перетягніть файл на сторінку. Під час перетягування сторінка показує «Перетягніть, щоб завантажити».
3. Дочекайтеся сповіщення «Набір даних збережено у вашу бібліотеку».

Skynet використовує назву файлу без розширення як назву набору даних. Щоб змінити її, виберіть набір даних і натисніть **Перейменувати**.

> [!NOTE]
> Кожен обліковий запис має квоту сховища. Якщо завантаження перевищує квоту, Skynet відкриває діалог із поясненням обмеження. Див. [Обмеження](/docs/limits).

Також можна завантажити файл у майстрі надсилання («Завантажте файл CSV, JSON або Excel») або прикріпити його в [панелі агента](/docs/guides/agent-panel).

## Пошук набору даних

Бібліотека показує ваші набори даних. Використовуйте **Пошук за назвою**, щоб відфільтрувати список. Набори даних, до яких інші люди надали вам доступ, з’являються в розділі **Спільні зі мною**.

Коли ви вибираєте один набір даних, з’являються такі дії:

- **Тегувати цей набір даних** відкриває [розмітник](/docs/guides/tagger) із цим набором даних.
- **Редагувати дані** відкриває редактор набору даних.
- **Поділитися** відкриває діалог спільного доступу.
- **Перейменувати** змінює назву набору даних.

Інші дії — **Зберегти копію** та **Видалити**.

> [!WARNING]
> Видалення назавжди прибирає набір даних із вашої бібліотеки. Цю дію не можна скасувати. Запуски, створені на основі набору даних, залишаються дійсними, але їхнє посилання на нього перестає працювати.

## Редагування набору даних

Редактор показує набір даних у вигляді сітки. На кожній сторінці він показує 100 рядків. Використовуйте **Наступні рядки** та **Попередні рядки**, щоб переходити між сторінками.

### Зміна рядків і стовпців

- **Додати рядок** і **Додати стовпець** додають нові клітинки в кінці.
- **Вставити рядок вище** і **Вставити рядок нижче** додають рядок поруч із вибраним рядком.
- **Дублювати рядок**, **Видалити рядок**, **Видалити стовпець** і **Перейменувати стовпець** змінюють структуру.
- **Потягніть для заповнення** копіює значення клітинки в сусідні клітинки.
- **Скасувати** і **Повторити** скасовують або повторюють вашу останню зміну.

Двічі клацніть рядок, щоб переглянути його повністю.

### Збереження

Редактор зберігає ваші зміни автоматично, невдовзі після кожного редагування. Під час збереження статус показує **Збереження…**. Якщо зберегти не вдається, статус показує **Не вдалося зберегти**.

> [!NOTE]
> Редактор не може зберегти набір даних без рядків. Він показує «Додайте рядок, щоб зберегти зміни», доки ви не додасте рядок.

Коли закінчите, натисніть **Назад до бібліотеки**.

### Доступ лише для читання

Якщо у вас роль «Глядач» у спільному наборі даних, редактор відкривається в режимі лише для читання. Щоб змінити дані, попросіть у власника роль «Редактор» або скористайтеся кнопкою **Зберегти копію**.

### Тегування за допомогою ШІ

Редактор має дію **Позначити за допомогою ШІ**. Вона відкриває розмітник, де модель ШІ допомагає вам додати мітки. Див. [Розмітка даних у розмітнику](/docs/guides/tagger).

## Задання ролей стовпців

Запуск має знати, які стовпці є вхідними, а який стовпець містить очікуваний вивід. Ці ролі задають під час надсилання запуску, а не в редакторі набору даних.

У майстрі надсилання крок «Як читати дані» показує кожен стовпець із трьома варіантами:

- **Вхід**: програма отримує це значення.
- **Вихід**: очікувана відповідь, з якою порівнює оцінювач.
- **Пропустити**: запуск ігнорує цей стовпець.

Значення за замовчуванням:

- Кожен стовпець вхідний, а останній стовпець — вихідний.
- Набір даних з одним стовпцем має один вхід і не має виходу.

Без вихідного стовпця Skynet використовує перший рядок як один вхід. Потрібно вибрати щонайменше один вхідний стовпець.

Деякі стовпці також можуть містити зображення. Для таких стовпців виберіть **Зображення** або **Текст**, щоб повідомити Skynet, як читати значення.

> [!TIP]
> Редактор набору даних показує позначку «output» на вихідних стовпцях. Новий стовпець, який ви додаєте в редакторі, спочатку є вхідним.

Майстер також ділить рядки на частини для навчання та оцінювання. Сума частин має дорівнювати 1. Якщо це не так, майстер показує «Сума часток розподілу має дорівнювати 1.». Повний процес описано в [Запуск через майстер](/docs/guides/submit).

## Спільний доступ до набору даних

Виберіть набір даних і натисніть **Поділитися**. Відкриється діалог **Доступ і конфіденційність**.

### Доступ за посиланням

| Варіант                            | Хто може відкрити набір даних                                         |
| ---------------------------------- | --------------------------------------------------------------------- |
| **Обмежений**                      | Лише власник і запрошені люди.                                        |
| **Будь-хто, хто має посилання**    | Будь-яка людина, що ввійшла в систему й має посилання, з вибраною вами роллю. |

Для набору даних із доступом «Будь-хто, хто має посилання» виберіть роль, яку надає посилання: **Глядач** або **Редактор**. Натисніть **Скопіювати посилання**, щоб скопіювати URL.

### Запрошення людей

1. У розділі **Запросити людей** введіть ім’я користувача в полі **Додавайте людей за іменем користувача**.
2. Натисніть **Запросити**.
3. Перевірте список у розділі **Люди з доступом**. Використовуйте **Змінити роль**, щоб змінити роль людини.

Ролі:

| Роль      | Доступ                                                                          |
| --------- | ------------------------------------------------------------------------------- |
| Власник   | Повний контроль, зокрема керування спільним доступом і видалення.               |
| Редактор  | Доступ глядача плюс запуск моделі, чат і перейменування.                        |
| Глядач    | Відкриває набір даних. Редактор доступний лише для читання.                     |

### Передавання права власності

Використовуйте **Передати право власності**, щоб передати набір даних іншій людині. Skynet просить вас підтвердити дію.

> [!WARNING]
> Після передавання ви стаєте редактором і втрачаєте привілеї власника.
