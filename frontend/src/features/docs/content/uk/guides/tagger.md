Розмітник додає мітки до рядків набору даних. Ви можете розмітити кожен рядок самостійно або доручити це моделі ШІ, а самі перевіряти її роботу. Результат — розмічений набір даних, який можна використати в запуску.

## Початок сесії

Відкрийте розмітник одним із таких способів:

- Відкрийте розмітник із панелі керування.
- У **Набори даних** виберіть один набір даних і натисніть **Тегувати цей набір даних**.
- У редакторі набору даних натисніть **Позначити за допомогою ШІ**.

### Вибір даних

Налаштування запитує дані для розмітки:

- **Виберіть зі своєї бібліотеки** використовує набір даних, який ви завантажили. Щоб завантажити новий файл, спершу скористайтеся [Набори даних](/docs/guides/datasets).
- **Згенерувати синтетичний датасет** створює рядки за вас. Для цього варіанта потрібен асистент.

### Вибір типу завдання

| Тип завдання                 | Що ви вказуєте для кожного рядка                                                               |
| ---------------------------- | ---------------------------------------------------------------------------------------------- |
| **Питання «так / ні»**       | Відповідь «так» або «ні».                                                                      |
| **Вибір із категорій**       | Одну або кілька категорій зі списку, який ви визначаєте. Додайте щонайменше дві категорії.     |
| **Письмові відповіді**       | Відповідь довільним текстом.                                                                   |

### Вибір режиму

Налаштування запитує «Як ви хочете тегувати?». Є три режими:

| Режим           | Що відбувається                                                                                                        |
| --------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Вручну**      | Ви розмічаєте кожен рядок самостійно. ШІ не бере участі.                                                               |
| **Другий пілот** (Co-pilot) | Після короткого інтерв’ю ШІ тегує першу партію. У раундах перевірки ви зберігаєте або виправляєте кожну мітку.         |
| **Автопілот** (Autopilot) | Після короткого інтерв’ю ШІ тегує всі рядки й позначає ті, щодо яких не впевнений.                                     |

Налаштування позначає один режим як **Рекомендовано**.

Налаштування також має вибір **Модель тегування**. Значення за замовчуванням підходить для більшості наборів даних.

> [!NOTE]
> У застосунку для Mac тегування за допомогою ШІ потребує вашого власного ключа провайдера. Виберіть модель у розділі **Власний ключ**. Див. [Застосунок для Mac](/docs/guides/mac-app).

## Інтерв’ю про набір даних

Режими «Другий пілот» і «Автопілот» починаються з **Інтерв'ю про набір даних**. ШІ ставить запитання про ваші дані та мітки. Можна натиснути **Пропустити інтерв'ю**.

Інтерв’ю створює **Посібник з розмічання**. Посібник містить правила, яких дотримується ШІ. Натисніть **Додати правило**, щоб додати власне правило.

Наприкінці ШІ показує **Ось план**. Потім ви починаєте роботу:

- У режимі «Другий пілот» натисніть **Протегувати перші {rows} рядків для моєї перевірки**.
- У режимі «Автопілот» натисніть **Протегувати всі {rows} рядків**.

## Раунди перевірки в режимі «Другий пілот»

У режимі «Другий пілот» ШІ спершу тегує калібрувальну партію. Розмір партії залежить від типу завдання:

| Тип завдання             | Перша партія                                              |
| ------------------------ | --------------------------------------------------------- |
| Питання «так / ні»       | 24 рядки                                                  |
| Вибір із категорій       | 6 рядків на кожну категорію, щонайменше 30 і щонайбільше 60 |
| Письмові відповіді       | 30 рядків                                                 |

Якщо набір даних має менше рядків, ШІ тегує всі.

### Перевірка кожної мітки

Для кожного рядка бічна панель показує мітку ШІ:

1. Прочитайте рядок і мітку.
2. Щоб зберегти мітку, натисніть **Підтвердити (Enter)** або клавішу Enter.
3. Щоб змінити мітку, виправте її. Панель показує «Виправлено — ШІ навчиться на цьому».
4. Коли закінчите, натисніть **Завершити цей раунд**.

Панель показує ціль: «Коли ми погоджуємося у {gate}% випадків, решту я протегую самостійно.»

### Поріг узгодженості

Після кожного раунду Skynet вимірює, як часто ви погоджувалися з ШІ. Поріг становить 92% для завдань «так / ні» і завдань із категоріями. Для письмових відповідей він становить 85%.

Підсумок раунду показує «Ви погодилися з ШІ у {agreement}% випадків». Потім ви вибираєте:

- **Ще один раунд перевірки** дає вам ще одну партію для перевірки.
- **Протегувати решту {rows} рядків** доручає ШІ тегувати решту.

## Автопілот і автоматичне тегування

Коли ШІ тегує решту рядків, робота виконується на сервері. Ви можете спокійно залишити сторінку й повернутися пізніше.

- **Продовжити тегування** продовжує зупинене завдання.
- **Скасувати — зберегти протеговане** зупиняє завдання й зберігає наявні мітки.

### Перевірка непевних рядків

ШІ присвоює кожній автоматичній мітці рівень упевненості. Skynet позначає рядок, коли впевненість нижча за 0,75. Після завершення завдання натисніть **Перегляньте {count} рядків, щодо яких ШІ не був упевнений**, щоб їх перевірити.

> [!TIP]
> Перевірте позначені рядки, перш ніж використовувати дані в запуску. Неправильні мітки знижують якість оптимізації.

## Ручний режим

У ручному режимі ви розмічаєте кожен рядок самостійно. Наведені нижче клавіатурні скорочення допомагають працювати швидко.

### Клавіатурні скорочення

| Клавіша              | Дія                                                       |
| -------------------- | --------------------------------------------------------- |
| Ctrl+H або Cmd+H     | Показати скорочення.                                      |
| Y / N                | Відповісти «так» або «ні» в рядку типу «так / ні».        |
| Від 1 до 9           | Вибрати або зняти цю категорію в рядку з категоріями.     |
| U                    | Перейти до наступного нерозміченого рядка.                |
| Home                 | Перейти до першого рядка.                                 |
| E                    | Експортувати як CSV.                                      |

## Результати

Результати показують, звідки взялася кожна мітка:

| Лічильник                          | Значення                                          |
| ---------------------------------- | ------------------------------------------------- |
| **Розмічено вами**                 | Мітки, які написали ви.                           |
| **Мітки ШІ, які ви підтвердили**   | Мітки ШІ, які ви зберегли під час перевірки.      |
| **Розмічено автоматично**          | Мітки ШІ без перевірки.                           |
| **Вартість**                       | Вартість роботи ШІ в цій сесії.                   |

Стовпець **Джерело** показує ті самі значення для кожного рядка: **Ви**, **ШІ підтверджено** або **ШІ**.

## Збереження та експорт

### Збереження в бібліотеку

Натисніть **Зберегти в бібліотеку** або **Перемістити до наборів даних**, щоб зберегти розмічені дані як набір даних. Потім їх можна використати в [запуску](/docs/guides/submit).

### Експорт файлу

Натисніть **Експортувати теги** й виберіть формат:

- CSV
- JSON
- Excel (`.xlsx`)
- Parquet
- Feather

Якщо деякі рядки не мають мітки, Skynet просить вас підтвердити експорт.

Експорт додає стовпець із мітками. Його назва залежить від типу завдання:

| Тип завдання             | Стовпець              |
| ------------------------ | --------------------- |
| Питання «так / ні»       | `binary_label`        |
| Вибір із категорій       | `selected_categories` |
| Письмові відповіді       | `extracted_text`      |

Стовпець `label_source` фіксує, звідки взялася кожна мітка.

## Сесії

Кожне завдання тегування — це сесія. Сесія має один із таких статусів: **У процесі**, **На перевірці**, **Автотегування** або **Готово**. Натисніть **Розпочати нову сесію**, щоб почати знову з новими налаштуваннями.

Ви можете надати іншим людям доступ до сесії через її діалог спільного доступу. Правила спільного доступу див. у [Спільний доступ і публікація](/docs/guides/sharing).
