Skynet 用預付結餘。你將資金加入結餘。每次運行都有花費上限，Skynet 會按運行嘅實際用量喺你嘅結餘扣錢。呢頁講解結餘、運行預算、預留、費用，同埋你自己嘅供應商金鑰。

> [!NOTE]
> 呢頁嘅數字係目前嘅預設值。應用程式會顯示即時數值。打開 **設定 → 帳單與收費**，就可以睇到你嘅結餘、增值手續費同交易記錄。

## 結餘

你嘅結餘以美元計算。Skynet 以仙為單位保存。

Skynet 預設唔會送免費起始結餘。開始第一次付費運行之前，請先增值。

你喺 **設定 → 帳單與收費** 增值。你可以揀固定金額，或者輸入自訂金額：

| 增值       | 加入結餘嘅金額               |
| ---------- | ---------------------------- |
| 固定金額   | $5、$20 或者 $50             |
| 自訂       | $5 至 $1,000 之間任何金額    |

你揀嘅金額就係入到你結餘嘅金額。增值手續費會另外再加。睇下面嘅費用部分。

**設定 → 用量** 會顯示你用咗幾多。**設定 → 帳單與收費** 入面嘅交易記錄會列出你嘅增值同運行收費。

## 運行預算

每次運行都有花費上限。上限就係運行最多可以用嘅金額。佢包括設定同最佳化。

運行開始之前冇成本估算。佢會用到上限為止，喺預算停止，並保留佢嘅最佳版本。想知 Skynet 點樣決定幾時停止，睇 [運行](/docs/concepts/runs)。

你喺提交精靈嘅 **預算** 畫面，喺 **支出上限** 欄位設定上限：

- **設定上限** 係預設模式。上限由 $5 開始。如果運行要多過 $5 先開始到，上限就由嗰個金額開始。
- **無上限** 令運行一直用你嘅結餘，直到完成為止。運行永遠唔會暫停。如果你嘅結餘用晒，運行會停止，並保留已經產生嘅成果。

### 開始所需金額

精靈會顯示 **開始所需** 嘅金額。呢個金額係：

- 運行喺第一次模型呼叫之前打開嘅沙盒嘅預留金額，加上
- 頭幾次模型呼叫嘅備用額度。備用額度係 $1；如果你揀咗嘅模型之中最貴嘅單次呼叫成本更高，就用嗰個成本。

當上限低過呢個金額，精靈唔會畀你繼續。如果你嘅結餘低過呢個金額，精靈都會阻止你。提高上限或者增值，就可以繼續。

> [!TIP]
> 當運行喺預算停止，喺運行頁面用 **提高上限並繼續**。運行會由最後一個檢查點繼續。

## 預留

Skynet 做付費工作之前，會預留運行上限嘅一部分。工作結算之後，Skynet 會釋放預留，只收實際成本。

當一個預算已經有活動，精靈入面嘅 **支出上限** 卡會顯示佢嘅帳目：

| 標籤                   | 意思                                                       |
| ---------------------- | ---------------------------------------------------------- |
| **呢個上限內剩返**     | 上限仲剩低嘅部分。                                         |
| **到目前為止用咗**     | 已經結算嘅成本。                                           |
| **已預留**             | 為進行中嘅工作保留嘅金額。工作結算之後，Skynet 會釋放佢。  |

## 費用

除咗供應商成本之外，Skynet 仲有三項收費。

| 收費               | 目前預設值                           | 適用於                                     |
| ------------------ | ------------------------------------ | ------------------------------------------ |
| 增值手續費         | 金額嘅 12.5%，再加 $0.35             | 每次增值                                   |
| 用量加價           | 供應商成本 × 1.15（成本加 15%）      | 用 Skynet 金鑰嘅模型呼叫，同埋沙盒運算     |
| 自己金鑰嘅平台費   | 模型成本嘅 5%                        | 用你自己供應商金鑰嘅模型呼叫               |

### 增值手續費

Skynet 會將百分比部分向上捨入到下一仙，然後再加 $0.35。例如，增值 $20 嘅手續費係 $2.85。增值畫面會喺你付款之前顯示手續費。

### 用量加價

Skynet 會將供應商成本乘以用量加價。加價適用於 Skynet 付費嘅模型呼叫，同埋沙盒運算。預留、開始所需金額，同埋應用程式入面嘅模型價錢，全部已經包括加價。

Skynet 會按以下次序搵出一次模型呼叫嘅供應商成本：

1. OpenRouter 為呢次呼叫報告嘅成本。
2. OpenRouter 對呢個模型嘅即時價目表。
3. LiteLLM 價目表。
4. 一個偏高嘅後備收費率：每百萬輸入 token $15，每百萬輸出 token $75。呢個收費率確保 Skynet 永遠唔會以低過成本嘅價錢收未知模型嘅錢。

## 你自己嘅供應商金鑰 (BYOK)

你可以用你自己嘅供應商金鑰做模型呼叫。喺 **設定 → 供應商** 加入金鑰。如果係 OpenRouter，你亦可以用 **用 OpenRouter 繼續**。

當模型呼叫用你嘅金鑰：

- 你嘅供應商會將模型 token 嘅費用記喺你嘅金鑰。
- Skynet 會喺你嘅結餘收取模型成本 5% 嘅平台費。Skynet 唔會喺呢筆費用上面再加用量加價。
- 運行嘅花費上限只包括平台費同沙盒用量。

外部評分器或者 MCP 供應商嘅任何費用，會直接交畀嗰個供應商。佢哋唔計入運行嘅花費上限。

## 沙盒用量

你嘅運行程式碼同指標喺沙盒入面運行。Skynet 會計量沙盒運算：

1. 沙盒開始之前，Skynet 會喺運行上限預留一筆金額。
2. 沙盒完成之後，Skynet 會按沙盒供應商報告嘅最終用量收費。
3. 用量加價適用於沙盒運算。

沙盒運算係運行花費上限嘅一部分，就算模型呼叫用緊你自己嘅金鑰都係。

## 方案

有兩個方案：Free 同 Pro。Pro 會提高部分限制，例如同時運行數目同儲存空間。如果 Pro 續期失敗，帳戶會保留 Pro 限制 7 日。之後，帳戶會用 Free 限制，直到付款成功為止。睇 [限制](/docs/limits)。

## 平台保障

- 互動式模型回合，例如同助手傾偈，開始之前要有最少 $0.05 結餘。
- 精靈助手係免費嘅。每個帳戶每個 UTC 日可以開始 50 個精靈助手回合。
