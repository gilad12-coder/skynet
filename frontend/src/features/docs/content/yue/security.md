呢頁講 Skynet 點樣保護你嘅帳戶、你嘅金鑰同你嘅數據，亦都話你知點樣報告安全問題。

## 報告漏洞

請私下報告安全問題。唔好開公開 issue。

- 喺 GitHub 打開 Skynet 儲存庫，去 **Security** > **Report a vulnerability**。
- 或者寄電郵去 `security@skynetml.com`。

團隊目標係喺五個工作天內確認收到每份報告。

## 你嘅帳戶

### 登入方法

你可以用以下方法登入：

- 電郵地址同密碼。
- **繼續使用 Google** 或者 **繼續使用 GitHub**。
- **使用 Passkey 登入**。Passkey 用 Face ID、Touch ID 或者硬件金鑰。

你可以喺 **已連結帳戶** 管理你用緊嘅登入供應商。

### 密碼規則

密碼一定要：

- 最少有 8 個字元。
- 最多有 128 個字元。
- 唔包含你嘅電郵地址。

新帳戶一定要用驗證碼驗證電郵地址。重設密碼亦會用 Skynet 經電郵寄出嘅驗證碼。

如果某個電郵地址重複登入失敗，Skynet 會鎖住嗰個電郵地址嘅登入一段時間。

### 兩步驗證

開啟兩步驗證可以加強保護。揀一個方法：

| 方法                   | 運作方式                                          |
| ---------------------- | ------------------------------------------------- |
| **驗證器應用程式**     | 輸入驗證器應用程式入面嘅 6 位數驗證碼。           |
| **電郵驗證碼**         | 輸入 Skynet 每次登入時寄出嘅 6 位數驗證碼。       |

Skynet 亦會畀你復原碼。將佢哋放喺安全嘅地方。如果你用唔到你嘅驗證方法，就用其中一個。

> [!NOTE]
> 如果你用 Google 或者 GitHub 登入，兩步驗證就由嗰個供應商管理。

## 你嘅程式碼喺邊度運行

用戶工作負載喺隔離嘅沙盒入面運行。喺託管產品入面，Vercel Sandbox 係執行邊界。呢個範圍包括設定檢查、最佳化運行、恢復，同埋已完成運行上嘅工作。

Skynet 嘅 worker 唔會運行你嘅程式碼。佢哋係控制平面。佢哋負責開始工作、預留同結算預算、將限定範圍嘅憑證交畀沙盒，同埋儲存檢查點。

Skynet 開始付費工作之前，會喺你嘅錢包同運行預算入面預留空間。請睇 [預算同收費](/docs/concepts/billing)。

喺 [Mac 應用程式](/docs/guides/mac-app) 入面，工作喺本機 Docker 容器入面運行。所有本機服務都只會監聽 `127.0.0.1`。

## 供應商金鑰（BYOK）

你可以加入你自己嘅模型供應商金鑰。

- Skynet 會將每條金鑰加密儲存。
- Skynet 永遠唔會經 API 回傳完整金鑰。
- Skynet 只保留最後四個字元同一個狀態：未驗證、已驗證或者無效。
- 你輸入金鑰嗰陣，Skynet 會傳送一個細嘅測試請求去檢查佢。

當你用自己嘅金鑰，供應商會直接向你嘅金鑰收費。Skynet 仍然會由你嘅結餘收取平台費同沙盒用量。

Skynet 亦會將日誌同錯誤訊息入面嘅機密資料移除，換做 `[REDACTED]`。

## API Token

API Token 等腳本同工具可以呼叫 Skynet API。

- 每個用戶最多只有一個有效 Token。當你產生新 Token，舊 Token 就會失效。
- Token 以 `skyd_` 開頭。
- Skynet 只儲存 Token 嘅雜湊值。
- Skynet 只會顯示完整 Token 一次。即刻複製同儲存個 Token。
- 之後 Skynet 只會顯示遮蓋咗嘅形式：`skyd_…` 加最後四個字元。

喺 `Authorization` 標頭傳送個 Token：

```http
Authorization: Bearer skyd_...
```

想停用一個 Token，撳 **撤銷 Token**。完整 API 請睇 [API](/docs/api)。

> [!WARNING]
> 要好似對待密碼咁對待個 Token。任何人有咗個 Token，都可以經 API 扮你做嘢。唔好將佢 commit 入儲存庫。

## 模型數據私隱

**模型數據私隱** 設定控制模型供應商可以點樣處理你嘅數據。佢適用於 Skynet 由你結餘扣費嘅最佳化。

| 選項           | 效果                                                                   |
| -------------- | ---------------------------------------------------------------------- |
| **全部允許**   | 任何供應商，包括可以用你嘅提示詞嚟訓練或者儲存佢哋嘅供應商。           |
| **唔准訓練**   | 只限唔會用你嘅提示詞嚟訓練、亦唔會保留佢哋嘅供應商。呢個係預設值。     |
| **零保留**     | 只限有零數據保留協議嘅端點。部分模型可能會用唔到。                     |

> [!NOTE]
> 用你自己金鑰嘅最佳化，會跟你 OpenRouter 帳戶嘅私隱設定。

## 運行嘅瀏覽權限

> [!WARNING]
> 新運行預設係 **公開**。公開運行會出現喺公開搜尋入面。任何人都可以搵到佢，同瀏覽佢嘅結果。

想運行唔出現喺公開搜尋，提交嗰陣將 **瀏覽權限** 設做 **私人**。你之後可以喺分享對話框改瀏覽權限。請睇 [分享同發佈](/docs/guides/sharing)。

新數據集係 **已限制**。喺你改連結存取權之前，只有你同你邀請嘅人可以打開佢哋。請睇 [準備數據集](/docs/guides/datasets)。

## 你嘅數據

喺 **設定** 打開 **私隱與資料** 分頁，就可以管理你嘅數據。

### 匯出你嘅數據

喺 **匯出我嘅資料** 下面撳 **匯出**。匯出檔包括你帳戶入面所有數據。揀一種格式：JSON、CSV、Excel、Pickle、Parquet 或者 Feather。

### 刪除你嘅帳戶

撳 **刪除帳戶**。輸入你而家嘅密碼，再打你嘅電郵地址確認。

> [!WARNING]
> 咁做會永久刪除你嘅帳戶同佢所有數據，冇得復原。
