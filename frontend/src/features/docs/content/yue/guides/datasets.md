數據集係一個例子表格，最佳化運行會由佢學習，亦會用佢嚟評分。呢份指南示範點樣上載檔案、編輯資料列同欄位、設定欄位角色，同埋分享數據集。想了解概念，睇 [數據集](/docs/concepts/datasets)。

## 支援嘅檔案

Skynet 讀取以下檔案類型：

| 副檔名          | Skynet 點樣讀取                                                  |
| --------------- | ---------------------------------------------------------------- |
| `.csv`          | 第一行係標題列。檔案最少要有一列數據。                           |
| `.json`         | 一個物件陣列，或者單一物件。第一個物件嘅鍵會變成欄位。           |
| `.xlsx`, `.xls` | Skynet 只會讀第一張工作表。                                      |

其他副檔名，Skynet 會拒絕，並顯示訊息「Unsupported file format」。

> [!TIP]
> 將預期輸出放喺最後一欄。提交精靈預設會將最後一欄標記為輸出。

### CSV 例子

```csv
question,answer
What is the capital of France?,Paris
How many legs does a spider have?,8
```

### JSON 例子

```json
[
  { "question": "What is the capital of France?", "answer": "Paris" },
  { "question": "How many legs does a spider have?", "answer": "8" }
]
```

## 上載數據集

1. 打開 **數據集**。
2. 撳 **上傳資料集**，或者將檔案拖到頁面上面。拖緊嘅時候，頁面會顯示「拖放至此上傳」。
3. 等到彈出通知「資料集已儲存到你嘅資料庫」。

Skynet 會用唔包副檔名嘅檔案名稱做數據集名稱。想改名，揀選個數據集，再撳 **重新命名**。

> [!NOTE]
> 每個帳戶都有儲存配額。如果上載會超出配額，Skynet 會打開一個對話框解釋呢個限制。睇 [限制](/docs/limits)。

你亦可以喺提交精靈上載檔案（「點擊上傳 CSV、JSON 或 Excel 檔案」），或者喺 [Agent 面板](/docs/guides/agent-panel) 附加檔案。

## 搵數據集

資料庫會列出你嘅數據集。用 **按名稱搜尋** 篩選清單。其他人同你分享嘅數據集會顯示喺 **同我分享** 下面。

當你揀選一個數據集，會出現以下操作：

- **為此數據集加上標籤** 會用呢個數據集打開 [標註工具](/docs/guides/tagger)。
- **編輯數據** 會打開數據集編輯器。
- **分享** 會打開分享對話框。
- **重新命名** 會改數據集嘅名稱。

其他操作有 **儲存複本** 同 **刪除**。

> [!WARNING]
> 刪除會將數據集永久喺你嘅資料庫移除。你冇得復原。由呢個數據集建立嘅運行仍然有效，但係佢哋連返呢個數據集嘅連結會斷咗。

## 編輯數據集

編輯器會以網格顯示數據集。每頁顯示 100 列。用 **下一批行** 同 **上一批列** 喺頁之間移動。

### 更改資料列同欄位

- **新增資料列** 同 **新增欄位** 會喺最尾加入新儲存格。
- **喺上方插入列** 同 **喺下方插入列** 會喺揀選咗嘅資料列旁邊加一列。
- **複製此行**、**刪除列**、**刪除欄位** 同 **重新命名欄位** 會改變結構。
- **拖曳以填滿** 會將一個儲存格嘅值複製去旁邊嘅儲存格。
- **復原** 同 **重做** 會撤銷或者重複你上一個變更。

撳兩下一列，就可以睇佢嘅完整內容。

### 儲存

每次編輯之後，編輯器好快就會自動儲存你嘅變更。儲存期間，狀態會顯示 **儲存緊…**。如果儲存失敗，狀態會顯示 **儲存失敗**。

> [!NOTE]
> 編輯器冇辦法儲存一個冇資料列嘅數據集。喺你加入一列之前，佢會一直顯示「新增一列以儲存你嘅變更」。

完成之後，撳 **返回資料庫**。

### 唯讀存取

如果你喺一個分享嘅數據集只有檢視者角色，編輯器會以唯讀模式打開。想改數據，就向擁有者要編輯者角色，或者用 **儲存複本**。

### 用 AI 標記

編輯器有一個 **使用 AI 標記** 操作。佢會打開標註工具，等 AI 模型幫你加標籤。睇 [用標註工具標註數據](/docs/guides/tagger)。

## 設定欄位角色

運行一定要知道邊啲欄位係輸入，邊一欄係預期輸出。你係喺提交運行嘅時候設定呢啲角色，唔係喺數據集編輯器。

喺提交精靈入面，「點樣讀取資料」呢一步會為每個欄位顯示三個選擇：

- **輸入**：程式會收到呢個值。
- **輸出**：評分器用嚟比較嘅預期答案。
- **略過**：運行會忽略呢個欄位。

預設係：

- 每個欄位都係輸入，最後一欄係輸出。
- 只有一欄嘅數據集有一個輸入，冇輸出。

冇輸出欄位嘅時候，Skynet 會將第一列當做一個輸入。你最少要揀一個輸入欄位。

有啲欄位亦可以裝圖片。對於呢啲欄位，揀 **圖片** 或者 **文字**，話畀 Skynet 知點樣讀取啲值。

> [!TIP]
> 數據集編輯器會喺輸出欄位顯示「output」標記。你喺編輯器新加嘅欄位，一開始係輸入。

精靈亦會將資料列分成訓練同評估用嘅部分。各部分加埋一定要等於 1。如果唔係，精靈會顯示「劃分比例加埋要等於 1。」。想睇完整流程，睇 [提交運行](/docs/guides/submit)。

## 分享數據集

揀選一個數據集，再撳 **分享**。**分享與私隱** 對話框會打開。

### 連結存取

| 選項                   | 邊個可以打開數據集                                       |
| ---------------------- | -------------------------------------------------------- |
| **已限制**             | 只有擁有者同獲邀請嘅人。                                 |
| **任何有連結嘅人**     | 任何已登入而且有連結嘅人，角色由你揀。                   |

對於「任何有連結嘅人」嘅數據集，揀連結畀嘅角色：**檢視者** 或者 **編輯者**。撳 **複製連結** 複製網址。

### 邀請成員

1. 喺 **邀請成員** 下面，喺 **輸入使用者名稱新增成員** 輸入使用者名稱。
2. 撳 **邀請**。
3. 檢查 **擁有存取權限嘅成員** 下面嘅清單。用 **變更角色** 改某個人嘅角色。

角色有：

| 角色     | 存取權限                                          |
| -------- | ------------------------------------------------- |
| 擁有者   | 完全控制，包括管理分享同刪除。                    |
| 編輯者   | 檢視者權限，再加運行模型、傾偈同重新命名。        |
| 檢視者   | 打開數據集。編輯器係唯讀。                        |

### 轉讓擁有權

用 **轉讓擁有權** 將數據集交畀另一個人。Skynet 會叫你確認。

> [!WARNING]
> 轉讓之後，你會變成編輯者，失去擁有者權限。
