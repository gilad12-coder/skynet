你可以同其他人分享一次運行，亦可以將佢列喺公開嘅探索圖庫。呢兩個係唔同嘅設定。連結存取同邀請控制邊個可以打開運行。公開瀏覽權限控制運行會唔會喺公開搜尋出現。呢份指南會講解兩樣。

## 預設值

| 設定                               | 新運行嘅預設值                                       |
| ---------------------------------- | ---------------------------------------------------- |
| 公開瀏覽權限                       | **公開**。運行會喺公開搜尋列出。                     |
| 連結存取                           | **已限制**。只有擁有者同獲邀請嘅人可以打開運行。     |
| **任何有連結嘅人** 嘅角色          | **檢視者**                                           |

提交精靈會喺最後一個畫面顯示新運行嘅瀏覽權限。運行開始之後，你可以喺 **分享與私隱** 對話框改佢。

> [!WARNING]
> 新運行預設係公開。如果你嘅運行有其他用戶唔可以睇到嘅數據，喺 **分享與私隱** 對話框將佢設為 **私人**。

## 打開分享設定

喺運行頁面，揀 **分享與私隱**。只有運行嘅擁有者先會見到呢個掣。

## 角色

每個可以打開運行嘅人都有以下三個角色之一：

| 角色         | 呢個人可以做乜                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------- |
| **檢視者**   | 打開運行，睇佢嘅結果同擁有者。複製運行。                                                       |
| **編輯者**   | 檢視者權限，再加運行模型、傾偈同重新命名。編輯者亦可以取消、暫停、繼續同重試運行。             |
| **擁有者**   | 完全控制，包括管理分享同刪除。                                                                 |

每次運行只有一個擁有者。所有打開分享運行嘅人都一定要登入。分享運行冇匿名存取。

## 分享連結

1. 打開 **分享與私隱**。
2. 喺 **連結存取權限** 下面，揀以下其中一個選項：
   - **已限制**：只有擁有者同獲邀請嘅人可以打開運行。
   - **任何有連結嘅人**：任何有連結而且已登入嘅用戶都可以打開運行。
3. 如果揀 **任何有連結嘅人**，就揀連結畀嘅角色：**檢視者** 或者 **編輯者**。連結永遠唔會畀 **擁有者** 角色。
4. 揀 **複製連結**。

連結嘅格式係 `/share/<token>`。token 係連結入面難以估到嘅部分。如果連結被撤銷，或者運行被刪除，連結會顯示 **搵唔到共用項目**。

> [!NOTE]
> 機密資料，例如 API 金鑰同 base URL，永遠唔會喺分享運行上面顯示。

## 邀請成員

1. 打開 **分享與私隱**。
2. 喺 **邀請成員** 下面，輸入使用者名稱。清單最多會顯示 10 個符合嘅用戶。
3. 揀一個角色：**檢視者** 或者 **編輯者**。
4. 揀 **邀請**。

**擁有存取權限嘅成員** 會列出所有喺呢個運行有角色嘅人。對每個人，你可以：

- 改角色。
- 移除存取權限。

每個人會保留規則畀佢嘅最高存取權限。例如，連結畀嘅係 **檢視者** 嘅時候，獲邀請嘅編輯者會保留 **編輯者** 角色。

### 轉讓擁有權

你可以將運行交畀另一個用戶：

1. 喺 **擁有存取權限嘅成員** 打開某個人嘅角色選單。你亦可以用 **邀請成員** 下面嘅角色選單。
2. 揀 **轉讓擁有權**。
3. 確認轉讓。

新擁有者會得到完全控制。你會變成編輯者，失去擁有者權限。

## 公開瀏覽權限

公開瀏覽權限控制運行會唔會喺探索圖庫嘅公開搜尋出現。佢唔會改變連結存取或者邀請。

| 選項         | 意思                                                       |
| ------------ | ---------------------------------------------------------- |
| **公開**     | 喺公開搜尋列出。所有用戶都睇到。                           |
| **私人**     | 喺公開搜尋隱藏。只有你同獲邀請嘅人睇到。                   |

只有擁有者可以改公開瀏覽權限。改動會即時生效。

## 探索圖庫

探索頁面畀你搜尋最佳化。佢有三個分頁：

| 分頁             | 顯示乜嘢                               |
| ---------------- | -------------------------------------- |
| **我嘅**         | 你嘅最佳化，包括私人同公開             |
| **公開**         | 其他用戶嘅公開最佳化                   |
| **同我分享**     | 其他用戶同你分享嘅最佳化               |

用搜尋列同 **篩選條件** 搵運行。

只有以狀態 `success` 完成嘅公開運行，你先可以喺探索打開。當你打開佢：

- 你會得到 **檢視者** 角色。你可以閱讀運行同複製佢。
- 頁面會顯示運行嘅擁有者。
- Skynet 會移除機密資料，例如 API 金鑰同 base URL。
- 你唔可以運行模型。因為模型會用擁有者嘅金鑰。

> [!TIP]
> 想畀某一個人喺公開運行有多啲權限，就邀請佢做 **編輯者**。
