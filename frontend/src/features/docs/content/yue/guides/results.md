運行頁面會顯示一次運行嘅進度同結果。呢份指南講解運行頁面嘅分頁、分數，同埋點樣匯出或者提供最佳版本。

## 運行頁面嘅分頁

運行頁面只會顯示適用於呢次運行嘅分頁。有啲分頁取決於路徑、狀態同你嘅經驗程度。

| 分頁               | 幾時顯示                                               | 內容                                                         |
| ------------------ | ------------------------------------------------------ | ------------------------------------------------------------ |
| **概覽**           | 一直顯示                                               | 進度、分數同分數歷史                                         |
| **用量**           | 成功嘅運行，而且有 Skynet 可以提供嘅程式               | 運行最佳化程式嘅表格，同埋整合程式碼                         |
| **成品**           | 有結果嘅提示詞、程式碼或者文字運行                     | 你個成品嘅各個版本，連埋最佳版本                             |
| **資料**           | 已完成嘅 DSPy 程式運行                                 | 分成訓練集、驗證集同測試集嘅資料，同埋測試集評估             |
| **程式碼**         | 運行有程式碼可以顯示嘅時候                             | 運行程式碼同指標                                             |
| **獎勵**           | 指標有宣告獎勵部分嘅提示詞、程式碼或者文字運行         | 獎勵部分同佢哋嘅權重                                         |
| **成品**           | 有最佳化提示詞或者檔案嘅運行                           | 最佳化之後嘅輸出同 **匯出結果**                              |
| **記錄**           | 大部分運行                                             | 運行記錄                                                     |
| **用量同費用**     | 你登入咗嘅時候                                         | 運行用咗幾多錢                                               |
| **排程執行**       | 成功嘅提示詞、程式碼或者文字運行                       | 再次運行最佳化嘅排程                                         |
| **設定**           | 一直顯示                                               | 運行設定                                                     |

> [!NOTE]
> 喺 **引導** 程度，運行頁面會隱藏 **資料**、**程式碼**、**記錄** 同 **設定** 分頁。直接連去其中一個分頁嘅連結仍然打得開。喺 **設定 → 帳戶** 改程度。

## 分數

Skynet 用驗證案例揀版本。佢用測試案例報告最終分數。引擎永遠睇唔到測試案例。睇 [數據集同分割](/docs/concepts/datasets)。

**概覽** 分頁會顯示：

- **提升幅度**：由起始版本到最佳版本嘅變化。
- **分數進度**：運行期間嘅分數。
- **評分細項**：每個指標，連埋 **基準**、**已最佳化** 同 **變動** 欄。

運行進行緊嘅時候，概覽亦會顯示 **已耗時**、**剩餘** 同 **速率**。

對於提示詞、程式碼或者文字運行，如果你嘅指標有報告命名分數，概覽亦會顯示 **命名分數**。

對於 DSPy 程式運行，**資料** 分頁有 **測試集評估**。佢會顯示每個測試案例嘅基準分數同最佳化分數。

### 當最佳版本就係起始版本

有時冇任何候選版本贏到起始版本。咁 Skynet 就會返回起始版本。**成品** 分頁會話你知用咗回歸保護。

如果運行喺預算停止，運行頁面會話你知 Skynet 儲存咗邊個版本。睇 [運行](/docs/concepts/runs)。

## 匯出最佳版本

### 提示詞、程式碼同文字運行

**成品** 分頁會列出你個成品嘅 **版本**。每個版本你都可以：

- 複製呢個版本。
- 將呢個版本下載成檔案。
- 如果係倉庫運行，將呢個版本下載成成個倉庫嘅 zip。

你可以將一個版本同另一個版本比較。分頁亦會顯示一個版本嘅 **評分器嘅回饋**。

### DSPy 程式運行

**成品** 分頁有一個 **匯出結果** 面板。打開 **下載** 選單。佢會顯示呢次運行有嘅格式：

| 選項             | 格式                                       |
| ---------------- | ------------------------------------------ |
| DSPy 程式        | `.zip`，一個可以直接運行嘅獨立匯出         |
| 已最佳化嘅程式   | `.pkl`                                     |
| 提示詞           | `.json`                                    |
| 最佳化程式碼     | `.py`                                      |
| 記錄             | `.csv`                                     |

## 提供最佳版本

你可以喺你自己嘅程式碼呼叫一個最佳化咗嘅 DSPy 程式。**用量** 分頁有兩部分：

- 一個表格。輸入啲輸入欄位，再揀 **執行**，就會得到一個預測。
- cURL、Python、JavaScript、Go 同 DSPy 嘅 **整合程式碼**。

程式一定會用佢最佳化時嘅模型設定運行。你一定要提供所有輸入欄位。Skynet 會忽略多出嚟嘅欄位。

想呼叫程式，喺 **設定 → API** 建立一個 API token。然後發送請求：

```bash tab="cURL"
export APP_API_TOKEN=skyd_...
curl -X POST "$API_URL/serve/<optimization_id>" \
  -H "Authorization: Bearer $APP_API_TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"question": "What is DSPy?"}}'
```

```python tab="Python"
import os
import uuid
import requests

response = requests.post(
    f"{os.environ['API_URL']}/serve/<optimization_id>",
    headers={
        "Authorization": f"Bearer {os.environ['APP_API_TOKEN']}",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={"inputs": {"question": "What is DSPy?"}},
)
print(response.json()["outputs"])
```

將 `question` 換成你程式嘅輸入欄位。**用量** 分頁上面嘅 **整合程式碼** 會幫你填好真正嘅網址同欄位名稱。

回應包括 `outputs`、`input_fields`、`output_fields` 同 `model_used`。

> [!TIP]
> 請求內容亦接受 `max_cost_cents`。佢設定呢一次呼叫最多可以用幾多錢，以仙計。有啲運行一定要有佢。

想喺部分輸出一出嚟就收到，將同一個請求發送去 `/serve/<optimization_id>/stream`。回應係一串 server-sent events。

身份驗證同其他端點，睇 [API](/docs/api)。
