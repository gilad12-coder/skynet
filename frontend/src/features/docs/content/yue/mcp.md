Skynet MCP 伺服器等 AI agent 可以代你使用 Skynet。Claude、ChatGPT、Codex、Cursor 同其他 MCP 用戶端可以檢查運行設定、開始運行、觀察運行同停止運行。你只需要喺瀏覽器批准連線一次。agent 會為每次運行設定花費上限。

## 伺服器 URL

所有用戶端都用同一個 URL：

```text
https://mcp.skynetml.com/mcp
```

伺服器用 Streamable HTTP。登入用 OAuth 2.1。你唔使將 Token 或者 API 金鑰複製入用戶端。

## 連接你嘅用戶端

揀你嘅用戶端。跟住佢嘅步驟做，然後去 [批准連線](#批准連線)。

```skynet-mcp-clients

```

## 批准連線

agent 第一次呼叫 Skynet 嗰陣，你嘅瀏覽器會打開一個 Skynet 頁面。

1. 如果你未登入，就先登入 Skynet。
2. 睇清楚個頁面。佢會顯示 agent 名稱、佢會返去嘅網站，同埋你嘅帳戶。
3. 睇清楚 agent 可以做啲乜：
   - 睇你嘅最佳化運行同佢哋嘅結果。
   - 開始同停止最佳化運行，費用由你嘅結餘支付。
4. 撳 **Allow** 就會連接。撳 **Deny** 就會停止。

撳咗 **Allow** 之後，瀏覽器會返去 agent 度。agent 而家可以呼叫下面嘅工具。

> [!NOTE]
> agent 會為每次運行設定花費上限。佢唔可以增值。

## 工具

| 工具        | 用途                                                                  | 權限 |
| ----------- | --------------------------------------------------------------------- | ---- |
| `check_run` | 檢查運行設定，唔會運行，亦唔會收你錢。會建議一個花費上限。            | 讀取 |
| `start_run` | 用一個花費上限開始一次運行。                                          | 寫入 |
| `get_run`   | 回傳狀態、已花費金額，運行完咗之後仲會回傳結果。                      | 讀取 |
| `list_runs` | 列出你嘅運行，最新嘅排先。可以按狀態篩選。                            | 讀取 |
| `stop_run`  | 停止一次運行。第二次呼叫會回傳錯誤，話運行已經完咗。                  | 寫入 |

讀取權限用 `runs:read` 範圍。寫入權限用 `runs:write` 範圍。

冇任何工具可以增值、改你嘅結餘，或者改收費設定。

## agent 點樣進行一次最佳化

1. agent 用運行設定呼叫 `check_run`。Skynet 會做靜態檢查，然後回傳：
   - 每項檢查嘅結果。
   - 運行可以開始嘅最低花費上限。
   - 一個建議嘅花費上限，最少係 $5.00。
   - 未知價錢嘅模型。
   - 你而家可以使嘅金額。
2. agent 用一個花費上限（`max_cost_cents`，由 1 至 1,000,000 美仙）呼叫 `start_run`。佢亦可以傳送 `idempotency_key`，咁重試就唔會開始第二次運行。
3. 如果設定檢查仲做緊，`start_run` 會回傳 `in_progress` 同 `retry_after_seconds`。過咗嗰段時間之後，agent 會用同一個輸入再呼叫 `start_run`。
4. agent 會一直呼叫 `get_run`，直到運行完結。最終狀態係 `success`、`failed`、`cancelled` 同 `stopped`。

> [!TIP]
> 喺你嘅提示詞入面話畀 agent 知你嘅花費上限，例如「最佳化呢個提示詞，最多使 $10。」agent 就會喺 `start_run` 用嗰個上限。

運行去到花費上限就會停止。想知 Skynet 點樣為一次運行收費，請睇 [預算同收費](/docs/concepts/billing)。

## 安全

- 每個用戶端都有自己嘅授權。用戶端永遠睇唔到你嘅密碼。
- 登入用 PKCE（S256）。用戶端會用動態用戶端註冊，或者用戶端 ID 中繼資料文件，嚟註冊自己。
- 存取 Token 1 個鐘之後過期。用戶端會用 refresh token 續期。
- refresh token 如果 30 日冇用就會過期。一個授權最長維持 90 日。之後你要再批准連線。
- 每個 refresh token 只可以用一次。如果有人再用一個舊嘅 refresh token，Skynet 會終止個授權。
- agent 只可以睇同改你自己嘅運行。

想知 Skynet 點樣保護你嘅帳戶同數據，請睇 [安全](/docs/security)。

## 中斷連線

想中斷一個 agent 嘅連線，就喺用戶端移除 Skynet 伺服器。大部分用戶端之後會撤銷佢哋嘅 Token。如果某個用戶端冇撤銷，佢嘅 refresh token 會喺 30 日冇用之後過期。

## 疑難排解

| 問題                                 | 點做                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------- |
| 一連接就失敗                         | 檢查伺服器 URL。佢一定要完全係 `https://mcp.skynetml.com/mcp`。         |
| 「This agent can't connect」         | 喺用戶端重新開始連線。                                                  |
| 「Too many attempts」                | 等幾分鐘，然後再試。                                                    |
| 用戶端冇打開瀏覽器                   | 更新用戶端。佢一定要支援用 OAuth 嘅遠端 MCP 伺服器。                    |
| `start_run` 出現結餘錯誤而失敗       | 喺 Skynet 增值，或者用一個較低嘅花費上限開始運行。                      |
| 用咗幾個禮拜之後工具停咗用           | 授權已經過期。移除伺服器，然後再連接。                                  |

如果想唔經 agent 直接用 HTTP 存取，請睇 [API](/docs/api)。
