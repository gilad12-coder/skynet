Skynet 對運行、檔案、儲存空間同請求速率設有限制。呢啲限制令平台保持穩定，亦保護你嘅結餘。呢頁列出預設數值。管理員可以為個別帳戶改部分限制。

> [!NOTE]
> 呢頁嘅數值係而家嘅預設值。當你去到某個限制，應用程式或者 API 會話你知係邊個限制擋住咗個請求。

## 運行

| 限制                 | Free | Pro   |
| -------------------- | ---- | ----- |
| 同一時間嘅進行中運行 | 5    | 20    |
| 已儲存嘅運行         | 100  | 1,000 |

進行中運行係指狀態係 `pending`、`validating`、`running` 或者 `paused` 嘅運行。當你嘅進行中運行數目去到上限，Skynet 會拒絕新運行，直到其中一個完咗為止。

已儲存運行嘅上限會計你所有運行。刪除你唔需要嘅運行，就可以騰出位畀新運行。

如果 Pro 續期失敗，帳戶會保留 Pro 限制 7 日。之後就會用 Free 限制，直到付款成功為止。

| 限制                           | 數值                                                    |
| ------------------------------ | ------------------------------------------------------- |
| 一個 API 複製請求嘅副本數目    | 1 至 5                                                  |
| 一次運行嘅自動恢復嘗試次數     | 3                                                       |
| 合約檢查入面嘅示例案例         | 3                                                       |
| 每次運行儲存嘅進度事件         | 5,000。Skynet 會先移除最舊嘅事件。                      |
| 一個沙盒嘅壽命                 | 45 分鐘。需要更長時間嘅運行會開一個新沙盒。             |

想知恢復嘗試點樣運作，請睇 [運行](/docs/concepts/runs)。

## 儲存空間

| 限制         | Free    | Pro    |
| ------------ | ------- | ------ |
| 總儲存空間   | 250 MiB | 10 GiB |

總儲存空間包括你嘅運行、數據集、日誌、agent 對話、暫存上載同搜尋數據。如果一次寫入會超過你嘅儲存空間上限，Skynet 會拒絕佢。

## 檔案同數據集

| 限制                             | 數值                           |
| -------------------------------- | ------------------------------ |
| 儲存到資料庫嘅數據集檔案         | 每個檔案 50 MiB（壓縮後）      |
| 由匯入記錄嘅連接器匯入嘅資料列   | 20,000                         |
| 附加到 agent 對話嘅檔案          | 20 MiB                         |
| 由一個對話附件讀取嘅文字         | 50,000 個字元                  |
| 語音輸入嘅音訊片段               | 25 MB                          |
| GitHub 儲存庫壓縮檔              | 200 MiB（已壓縮）              |
| 喺運行頁面打開嘅儲存庫檔案       | 1 MiB                          |

匯入記錄嘅連接器包括資料庫表、LLM 追蹤記錄同 Notion 資料庫。請睇 [準備數據集](/docs/guides/datasets)。

### 精靈入面嘅工作區檔案

| 限制                 | 數值                                                                    |
| -------------------- | ----------------------------------------------------------------------- |
| 工作區嘅額外檔案     | 20                                                                      |
| 檔案名稱長度         | 120 個字元                                                              |
| 資料夾深度           | 3 層資料夾                                                              |
| 檔案類型             | `.py`、`.txt`、`.md`、`.json`、`.yaml`、`.csv`、`.toml`、`.ini`、`.cfg` |

`run.py` 同 `metric.py` 係一次運行嘅入口檔案。你唔可以刪除、改名或者搬走佢哋。

## 請求速率

| 限制                                                 | 數值                               |
| ---------------------------------------------------- | ---------------------------------- |
| 運行提交                                             | 每個帳戶喺滾動一分鐘內 30 次       |
| 語音輸入片段                                         | 每個帳戶每個鐘 120 個              |
| 為 agent 對話讀取嘅檔案                              | 每個帳戶每個鐘 300 個              |
| 帳戶請求（註冊、重設密碼、電郵驗證）                 | 每個電郵地址喺滾動一個鐘內 20 次   |
| 精靈助手回合                                         | 每個帳戶每個 UTC 日 50 個          |
| 搜尋同索引 Token                                     | 每個帳戶每個月 2,000,000 個        |

當你超過速率限制，API 會回傳 HTTP 狀態 `429`。等一陣，然後再傳送個請求。

當一個帳戶超過每月嘅搜尋同索引 Token，Skynet 會停止為嗰個帳戶索引新項目。之後搜尋會當語義搜尋用唔到咁運作。

## 金額

| 限制                                 | 數值                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| 新運行嘅預設花費上限                 | $5，或者開始所需金額（如果較高）                             |
| 開始所需金額入面嘅預留空間           | $1，或者最貴單次模型呼叫嘅費用（如果較高）                   |
| 自訂增值                             | $5 至 $1,000                                                 |

想了解費用同預留，請睇 [預算同收費](/docs/concepts/billing)。
