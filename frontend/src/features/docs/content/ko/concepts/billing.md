Skynet은 선불 잔액을 사용합니다. 잔액을 충전합니다. 각 실행에는 지출 한도가 있고, Skynet은 실행의 실제 사용량을 잔액에서 청구합니다. 이 페이지는 잔액, 실행 예산, 예약, 수수료, 그리고 자신의 제공업체 키에 대해 설명합니다.

> [!NOTE]
> 이 페이지의 숫자는 현재 기본값입니다. 앱에는 실시간 값이 표시됩니다. 잔액, 충전 수수료, 거래 내역을 보려면 **설정 → 청구**를 여세요.

## 잔액

잔액의 단위는 미국 달러입니다. Skynet은 잔액을 센트 단위로 보관합니다.

Skynet은 기본적으로 무료 시작 잔액을 제공하지 않습니다. 첫 유료 실행을 시작하기 전에 충전하세요.

충전은 **설정 → 청구**에서 합니다. 정해진 금액을 고르거나 직접 금액을 입력할 수 있습니다.

| 충전          | 잔액에 추가되는 금액            |
| ------------- | ------------------------------- |
| 정해진 금액   | $5, $20 또는 $50                |
| 사용자 지정   | $5부터 $1,000까지 원하는 금액   |

선택한 금액이 그대로 잔액에 들어갑니다. 충전 수수료는 그 금액에 추가로 붙습니다. 아래 수수료를 참고하세요.

**설정 → 사용량**에서 지출 내역을 볼 수 있습니다. **설정 → 청구**의 거래 내역에는 충전과 실행 청구가 나열됩니다.

## 실행 예산

각 실행에는 지출 한도가 있습니다. 한도는 실행이 쓸 수 있는 최대 금액입니다. 설정과 최적화를 모두 포함합니다.

실행에는 시작 전 비용 추정치가 없습니다. 실행은 한도까지 지출하고, 예산에 도달하면 멈추고, 최고 버전을 유지합니다. Skynet이 언제 멈출지 정하는 방식은 [실행](/docs/concepts/runs)을 읽어 보세요.

한도는 제출 마법사의 **예산** 화면에 있는 **지출 한도** 필드에서 설정합니다.

- **한도 설정**이 기본 모드입니다. 한도는 $5에서 시작합니다. 실행을 시작하는 데 $5보다 많이 필요하면 한도는 그 금액에서 시작합니다.
- **한도 없음**은 실행이 끝날 때까지 잔액을 사용하게 합니다. 실행은 절대 일시 중지되지 않습니다. 잔액이 바닥나면 실행은 멈추고 지금까지 만든 결과를 유지합니다.

### 시작에 필요한 금액

마법사는 **시작에 필요한 금액**을 보여 줍니다. 이 금액은 다음을 더한 값입니다.

- 실행이 첫 모델 호출 전에 여는 샌드박스에 대한 보류 금액
- 첫 모델 호출을 위한 여유분. 여유분은 $1이며, 선택한 모델의 가장 비싼 단일 호출 비용이 더 크면 그 비용입니다.

한도가 이 금액보다 낮으면 마법사에서 계속할 수 없습니다. 잔액이 이 금액보다 적을 때도 진행이 막힙니다. 계속하려면 한도를 올리거나 충전하세요.

> [!TIP]
> 실행이 예산에 도달해 멈추면 실행 페이지에서 **한도 올리고 계속**을 사용하세요. 실행이 마지막 체크포인트에서 이어집니다.

## 예약

Skynet은 유료 작업을 하기 전에 실행 한도의 일부를 예약합니다. 작업이 정산되면 Skynet은 예약을 해제하고 실제 비용만 청구합니다.

예산에 이미 활동이 있으면 마법사의 **지출 한도** 카드에 원장이 표시됩니다.

| 라벨                          | 의미                                                                          |
| ----------------------------- | ----------------------------------------------------------------------------- |
| **이 한도에서 남은 금액**     | 한도 중 남은 부분.                                                            |
| **지금까지 지출**             | 정산된 비용.                                                                  |
| **예약됨**                    | 진행 중인 작업을 위해 보류한 금액. 작업이 정산되면 Skynet이 해제합니다.       |

## 수수료

Skynet은 제공업체 비용 외에 세 가지 수수료를 청구합니다.

| 수수료                        | 현재 기본값                              | 적용 대상                                         |
| ----------------------------- | ---------------------------------------- | ------------------------------------------------- |
| 충전 수수료                   | 금액의 12.5% + $0.35                     | 각 충전                                           |
| 사용량 마크업                 | 제공업체 비용 × 1.15(비용 + 15%)         | Skynet 키로 하는 모델 호출, 샌드박스 컴퓨팅       |
| 내 키에 대한 플랫폼 수수료    | 모델 비용의 5%                           | 내 제공업체 키로 하는 모델 호출                   |

### 충전 수수료

Skynet은 비율 부분을 다음 센트로 올림한 다음 $0.35를 더합니다. 예를 들어 $20 충전의 수수료는 $2.85입니다. 충전 화면은 결제하기 전에 수수료를 보여 줍니다.

### 사용량 마크업

Skynet은 제공업체 비용에 사용량 마크업을 곱합니다. 마크업은 Skynet이 비용을 내는 모델 호출과 샌드박스 컴퓨팅에 적용됩니다. 예약, 시작에 필요한 금액, 앱의 모델 가격에는 이미 마크업이 포함되어 있습니다.

Skynet은 다음 순서로 모델 호출의 제공업체 비용을 찾습니다.

1. OpenRouter가 해당 호출에 대해 보고한 비용.
2. 해당 모델에 대한 OpenRouter의 실시간 가격표.
3. LiteLLM 가격표.
4. 입력 토큰 100만 개당 $15, 출력 토큰 100만 개당 $75의 높은 대체 요율. 이 요율은 Skynet이 알 수 없는 모델을 원가 이하로 청구하지 않도록 보장합니다.

## 자신의 제공업체 키(BYOK)

자신의 제공업체 키로 모델 호출을 실행할 수 있습니다. 키는 **설정 → 공급자**에서 추가합니다. OpenRouter는 **OpenRouter로 계속하기**를 사용할 수도 있습니다.

모델 호출에 내 키를 사용하면 다음과 같습니다.

- 제공업체가 모델 토큰 비용을 내 키에 청구합니다.
- Skynet은 모델 비용의 5%를 플랫폼 수수료로 잔액에서 청구합니다. Skynet은 이 수수료에 사용량 마크업을 더하지 않습니다.
- 실행의 지출 한도는 플랫폼 수수료와 샌드박스 사용량만 포함합니다.

외부 채점기나 MCP 제공업체의 수수료는 해당 제공업체에 직접 지불됩니다. 실행의 지출 한도에는 포함되지 않습니다.

## 샌드박스 사용량

실행 코드와 메트릭은 샌드박스에서 실행됩니다. Skynet은 샌드박스 컴퓨팅을 계량합니다.

1. 샌드박스가 시작되기 전에 Skynet은 실행 한도에서 금액을 예약합니다.
2. 샌드박스가 끝나면 Skynet은 샌드박스 제공업체가 보고한 최종 사용량을 청구합니다.
3. 사용량 마크업은 샌드박스 컴퓨팅에 적용됩니다.

샌드박스 컴퓨팅은 모델 호출에 내 키를 사용할 때도 실행의 지출 한도에 포함됩니다.

## 플랜

플랜은 Free와 Pro 두 가지입니다. Pro는 동시 실행 수와 스토리지 같은 일부 제한을 높입니다. Pro 갱신이 실패하면 계정은 7일 동안 Pro 제한을 유지합니다. 그 후에는 결제가 성공할 때까지 Free 제한을 사용합니다. [제한](/docs/limits)을 참고하세요.

## 플랫폼 보호 장치

- 어시스턴트와의 채팅 같은 대화형 모델 턴은 시작하기 전에 최소 $0.05의 잔액이 필요합니다.
- 마법사 어시스턴트는 무료입니다. 각 계정은 UTC 기준 하루에 마법사 어시스턴트 턴을 50회 시작할 수 있습니다.
