Skynet은 실행, 파일, 스토리지, 요청 속도에 제한을 둡니다. 이 제한은 플랫폼을 안정적으로 유지하고 잔액을 보호합니다. 이 페이지는 기본값을 나열합니다. 관리자는 계정별로 일부 제한을 변경할 수 있습니다.

> [!NOTE]
> 이 페이지의 값은 현재 기본값입니다. 제한에 도달하면 앱이나 API가 어떤 제한 때문에 요청이 중단되었는지 알려 줍니다.

## 실행

| 제한                    | Free | Pro   |
| ----------------------- | ---- | ----- |
| 동시에 진행 중인 실행   | 5    | 20    |
| 저장된 실행             | 100  | 1,000 |

진행 중인 실행은 상태가 `pending`, `validating`, `running` 또는 `paused`인 실행입니다. 진행 중인 실행 수가 최대치에 이르면, 그중 하나가 끝날 때까지 Skynet은 새 실행을 거부합니다.

저장된 실행 제한은 모든 실행을 셉니다. 새 실행을 위한 공간을 만들려면 필요 없는 실행을 삭제하세요.

Pro 갱신이 실패하면 계정은 7일 동안 Pro 제한을 유지합니다. 그 후에는 결제가 성공할 때까지 Free 제한을 사용합니다.

| 제한                                | 값                                                          |
| ----------------------------------- | ----------------------------------------------------------- |
| API 복제 요청 한 번의 사본 수       | 1~5                                                         |
| 실행당 자동 복구 시도 횟수          | 3                                                           |
| 계약 검사의 샘플 케이스             | 3                                                           |
| 실행당 저장되는 진행 이벤트         | 5,000. Skynet은 가장 오래된 이벤트부터 제거합니다.          |
| 샌드박스 하나의 수명                | 45분. 시간이 더 필요한 실행은 새 샌드박스를 엽니다.          |

복구 시도의 작동 방식은 [실행](/docs/concepts/runs)을 읽어 보세요.

## 스토리지

| 제한          | Free    | Pro    |
| ------------- | ------- | ------ |
| 전체 스토리지 | 250 MiB | 10 GiB |

전체 스토리지에는 실행, 데이터셋, 로그, 에이전트 채팅, 업로드 대기 파일, 검색 데이터가 포함됩니다. Skynet은 스토리지 제한을 넘게 되는 쓰기를 거부합니다.

## 파일과 데이터셋

| 제한                                     | 값                                 |
| ---------------------------------------- | ---------------------------------- |
| 라이브러리에 저장하는 데이터셋 파일      | 파일당 50 MiB(압축 후)             |
| 레코드를 가져오는 커넥터의 행 수         | 20,000                             |
| 에이전트 채팅에 첨부하는 파일            | 20 MiB                             |
| 채팅 첨부 파일 하나에서 읽는 텍스트      | 50,000자                           |
| 음성 받아쓰기용 오디오 클립              | 25 MB                              |
| GitHub 리포지토리 아카이브               | 200 MiB(압축 기준)                 |
| 실행 페이지에서 여는 리포지토리 파일     | 1 MiB                              |

레코드를 가져오는 커넥터에는 데이터베이스 테이블, LLM 트레이스, Notion 데이터베이스가 있습니다. [데이터셋 준비](/docs/guides/datasets)를 읽어 보세요.

### 마법사의 작업 공간 파일

| 제한                         | 값                                                                      |
| ---------------------------- | ----------------------------------------------------------------------- |
| 작업 공간의 추가 파일        | 20                                                                      |
| 파일 이름 길이               | 120자                                                                   |
| 폴더 깊이                    | 폴더 3단계                                                              |
| 파일 형식                    | `.py`, `.txt`, `.md`, `.json`, `.yaml`, `.csv`, `.toml`, `.ini`, `.cfg` |

`run.py`와 `metric.py`는 실행의 진입 파일입니다. 이 파일은 삭제하거나, 이름을 바꾸거나, 이동할 수 없습니다.

## 요청 속도

| 제한                                                    | 값                                       |
| ------------------------------------------------------- | ---------------------------------------- |
| 실행 제출                                               | 계정당 최근 1분 동안 30회                |
| 음성 받아쓰기 클립                                      | 계정당 1시간에 120회                     |
| 에이전트 채팅용으로 읽는 파일                           | 계정당 1시간에 300개                     |
| 계정 요청(가입, 비밀번호 재설정, 이메일 인증)           | 이메일 주소당 최근 1시간 동안 20회       |
| 마법사 어시스턴트 턴                                    | 계정당 UTC 기준 하루 50회                |
| 검색 및 인덱싱 토큰                                     | 계정당 한 달에 2,000,000개               |

요청 속도 제한을 넘으면 API는 HTTP 상태 `429`를 반환합니다. 잠시 기다린 다음 요청을 다시 보내세요.

계정이 월간 검색 및 인덱싱 토큰을 초과하면 Skynet은 해당 계정의 새 항목 인덱싱을 중지합니다. 그러면 검색은 의미 기반 검색을 사용할 수 없는 것처럼 작동합니다.

## 금액

| 제한                                       | 값                                                                       |
| ------------------------------------------ | ------------------------------------------------------------------------ |
| 새 실행의 기본 지출 한도                   | $5. 시작에 필요한 금액이 더 크면 그 금액                                 |
| 시작에 필요한 금액에 포함되는 여유분       | $1. 가장 비싼 단일 모델 호출 비용이 더 크면 그 비용                      |
| 사용자 지정 충전                           | $5~$1,000                                                                |
| 대화형 모델 턴을 시작하는 데 필요한 잔액   | $0.05                                                                    |

수수료와 예약에 대해서는 [예산과 결제](/docs/concepts/billing)를 읽어 보세요.
