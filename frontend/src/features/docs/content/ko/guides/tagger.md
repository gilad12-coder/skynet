태거는 데이터셋의 행에 라벨을 추가합니다. 모든 행에 직접 라벨을 달 수도 있고, AI 모델이 행에 라벨을 다는 동안 그 작업을 검토할 수도 있습니다. 결과는 실행에 사용할 수 있는 라벨이 달린 데이터셋입니다.

## 세션 시작하기

다음 방법 중 하나로 태거를 엽니다.

- 대시보드에서 태거를 엽니다.
- **데이터셋**에서 데이터셋 하나를 선택하고 **이 데이터셋 태그 지정**을 클릭합니다.
- 데이터셋 편집기에서 **AI로 태그 지정**을 클릭합니다.

### 데이터 선택하기

설정 화면에서 라벨을 달 데이터를 묻습니다.

- **라이브러리에서 선택**은 업로드한 데이터셋을 사용합니다. 새 파일을 업로드하려면 먼저 [데이터셋](/docs/guides/datasets)을 사용하세요.
- **합성 데이터셋 생성**은 행을 대신 만들어 줍니다. 이 옵션에는 어시스턴트가 필요합니다.

### 작업 유형 선택하기

| 작업 유형                 | 각 행에 다는 것                                                                 |
| ------------------------- | ------------------------------------------------------------------------------- |
| **예 / 아니요 질문**      | 예 또는 아니요 답.                                                              |
| **카테고리에서 선택**     | 직접 정의한 목록의 카테고리 하나 이상. 카테고리를 최소 두 개 추가하세요.        |
| **서술형 답변**           | 자유 텍스트 답.                                                                 |

### 모드 선택하기

설정 화면에서 "어떻게 태깅하시겠어요?"라고 묻습니다. 모드는 세 가지입니다.

| 모드              | 동작                                                                                                         |
| ----------------- | ------------------------------------------------------------------------------------------------------------ |
| **수동**          | 모든 행에 직접 라벨을 답니다. AI는 관여하지 않습니다.                                                        |
| **코파일럿** (Co-pilot) | 짧은 인터뷰 후 AI가 첫 배치에 태그를 답니다. 검토 라운드에서 각 라벨을 유지하거나 수정합니다.               |
| **오토파일럿** (Autopilot) | 짧은 인터뷰 후 AI가 모든 행에 태그를 달고, 확신하지 못하는 행을 표시합니다.                                  |

설정 화면은 한 모드를 **권장**으로 표시합니다.

설정 화면에는 **태깅 모델** 선택도 있습니다. 대부분의 데이터셋에는 기본값이 적합합니다.

> [!NOTE]
> Mac 앱에서 AI로 태깅하려면 자신의 제공업체 키가 필요합니다. **내 키 사용**에서 모델을 선택하세요. [Mac 앱](/docs/guides/mac-app)을 참고하세요.

## 데이터셋 인터뷰

코파일럿과 오토파일럿은 **데이터셋 인터뷰**로 시작합니다. AI가 데이터와 라벨에 대해 질문합니다. **인터뷰 건너뛰기**를 클릭할 수도 있습니다.

인터뷰는 **라벨링 가이드**를 만듭니다. 가이드에는 AI가 따르는 규칙이 들어 있습니다. 직접 규칙을 추가하려면 **규칙 추가**를 사용하세요.

마지막에 AI가 **계획은 다음과 같습니다**를 보여 줍니다. 그런 다음 작업을 시작합니다.

- 코파일럿에서는 **검토를 위해 처음 {rows}개 행 태깅하기**를 클릭합니다.
- 오토파일럿에서는 **전체 {rows}개 행 태깅하기**를 클릭합니다.

## 코파일럿 검토 라운드

코파일럿에서 AI는 먼저 보정 배치에 태그를 답니다. 배치 크기는 작업 유형에 따라 다릅니다.

| 작업 유형            | 첫 배치                                               |
| -------------------- | ----------------------------------------------------- |
| 예 / 아니요 질문     | 24개 행                                               |
| 카테고리에서 선택    | 카테고리마다 6개 행, 최소 30개, 최대 60개             |
| 서술형 답변          | 30개 행                                               |

데이터셋의 행이 이보다 적으면 AI가 모든 행에 태그를 답니다.

### 각 라벨 검토하기

각 행마다 사이드 레일에 AI 라벨이 표시됩니다.

1. 행과 라벨을 읽습니다.
2. 라벨을 유지하려면 **확인 (Enter)**을 클릭하거나 Enter 키를 누릅니다.
3. 라벨을 바꾸려면 수정합니다. 레일에 "수정됨 — AI가 이를 학습합니다"가 표시됩니다.
4. 마치면 **이 라운드 마치기**를 클릭합니다.

레일에는 목표가 표시됩니다: "동의율이 {gate}%에 도달하면 나머지는 제가 직접 태깅하겠습니다."

### 동의율 게이트

각 라운드가 끝나면 Skynet은 내가 AI와 얼마나 자주 동의했는지 측정합니다. 게이트는 예 / 아니요 작업과 카테고리 작업에서 92%입니다. 서술형 답변에서는 85%입니다.

라운드 요약에 "이번 배치에서 AI와 {agreement}% 일치했습니다"가 표시됩니다. 그런 다음 선택합니다.

- **검토 라운드 한 번 더**는 검토할 배치를 하나 더 줍니다.
- **남은 {rows}개 행 태깅하기**는 AI가 나머지에 태그를 달게 합니다.

## 오토파일럿과 자동 태깅

AI가 남은 행에 태그를 다는 작업은 서버에서 실행됩니다. 페이지를 떠났다가 돌아와도 안전합니다.

- **태깅 이어서 하기**는 멈춘 작업을 계속합니다.
- **취소 — 태깅된 항목은 유지**는 작업을 멈추고 이미 있는 라벨을 유지합니다.

### 확신하지 못한 행 검토하기

AI는 각 자동 라벨에 신뢰도를 매깁니다. 신뢰도가 0.75 미만이면 Skynet이 그 행을 표시합니다. 작업이 끝나면 **AI가 확신하지 못한 {count}개 행 검토하기**를 클릭해 확인하세요.

> [!TIP]
> 데이터를 실행에 사용하기 전에 표시된 행을 검토하세요. 잘못된 라벨은 최적화의 품질을 떨어뜨립니다.

## 수동 모드

수동 모드에서는 모든 행에 직접 라벨을 답니다. 아래 키보드 단축키를 사용하면 빠르게 작업할 수 있습니다.

### 키보드 단축키

| 키                 | 동작                                                     |
| ------------------ | -------------------------------------------------------- |
| Ctrl+H 또는 Cmd+H  | 단축키를 표시합니다.                                     |
| Y / N              | 예 / 아니요 행에서 예 또는 아니요로 답합니다.            |
| 1~9                | 카테고리 행에서 해당 카테고리를 선택하거나 해제합니다.   |
| U                  | 다음으로 태그가 없는 행으로 이동합니다.                  |
| Home               | 첫 번째 행으로 이동합니다.                               |
| E                  | CSV로 내보냅니다.                                        |

## 결과

결과는 각 라벨이 어디에서 왔는지 보여 줍니다.

| 개수                         | 의미                                         |
| ---------------------------- | -------------------------------------------- |
| **직접 라벨링함**            | 내가 작성한 라벨.                            |
| **확인한 AI 라벨**           | 검토에서 내가 유지한 AI 라벨.                |
| **자동 라벨링됨**            | 검토하지 않은 AI 라벨.                       |
| **비용**                     | 이 세션에서 AI 작업에 든 비용.               |

**출처** 열은 각 행에 대해 같은 값을 보여 줍니다: **직접**, **AI 확인됨**, **AI**.

## 저장 및 내보내기

### 라이브러리에 저장하기

라벨이 달린 데이터를 데이터셋으로 보관하려면 **라이브러리에 저장** 또는 **데이터셋으로 이동**을 클릭합니다. 그러면 [실행](/docs/guides/submit)에 사용할 수 있습니다.

### 파일 내보내기

**태그 내보내기**를 클릭하고 형식을 선택합니다.

- CSV
- JSON
- Excel (`.xlsx`)
- Parquet
- Feather

일부 행에 라벨이 없으면 Skynet이 내보내기를 확인하도록 요청합니다.

내보내기에는 라벨 열이 추가됩니다. 열 이름은 작업 유형에 따라 다릅니다.

| 작업 유형            | 열                    |
| -------------------- | --------------------- |
| 예 / 아니요 질문     | `binary_label`        |
| 카테고리에서 선택    | `selected_categories` |
| 서술형 답변          | `extracted_text`      |

`label_source` 열은 각 라벨의 출처를 기록합니다.

## 세션

각 태깅 작업은 하나의 세션입니다. 세션은 **진행 중**, **검토 중**, **자동 태깅 중**, **완료** 중 하나의 상태를 가집니다. 새 설정으로 다시 시작하려면 **새 세션 시작**을 클릭합니다.

세션의 공유 대화상자에서 세션을 다른 사람과 공유할 수 있습니다. 공유 규칙은 [공유 및 게시](/docs/guides/sharing)를 참고하세요.
