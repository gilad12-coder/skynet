실행을 다른 사람과 공유할 수 있고, 공개 탐색 갤러리에 올릴 수도 있습니다. 이 둘은 서로 다른 설정입니다. 링크 접근 권한과 초대는 누가 실행을 열 수 있는지 정합니다. 공개 범위는 실행이 공개 검색에 표시되는지 정합니다. 이 가이드는 두 가지를 모두 설명합니다.

## 기본값

| 설정                                      | 새 실행의 기본값                                                          |
| ----------------------------------------- | ------------------------------------------------------------------------- |
| 공개 범위                                 | **공개**. 실행이 공개 검색에 표시됩니다.                                  |
| 링크 접근 권한                            | **제한됨**. 소유자와 초대된 사람만 실행을 열 수 있습니다.                 |
| **링크가 있는 모든 사람**의 역할          | **뷰어**                                                                  |

제출 마법사는 마지막 화면에서 새 실행의 공개 범위를 보여 줍니다. 공개 범위는 실행이 시작된 후 **공유 및 개인정보** 대화상자에서 바꿉니다.

> [!WARNING]
> 새 실행은 기본적으로 공개입니다. 실행에 다른 사용자가 보면 안 되는 데이터가 있다면 **공유 및 개인정보** 대화상자에서 **비공개**로 설정하세요.

## 공유 설정 열기

실행 페이지에서 **공유 및 개인정보**를 선택합니다. 이 버튼은 실행의 소유자에게만 보입니다.

## 역할

실행을 열 수 있는 각 사람은 세 가지 역할 중 하나를 가집니다.

| 역할         | 할 수 있는 일                                                                                                   |
| ------------ | --------------------------------------------------------------------------------------------------------------- |
| **뷰어**     | 실행을 열고 결과와 소유자를 봅니다. 실행을 복제합니다.                                                          |
| **편집자**   | 뷰어 권한 + 모델 실행, 채팅, 이름 바꾸기. 편집자는 실행을 취소, 일시 중지, 다시 시작, 재시도할 수도 있습니다.   |
| **소유자**   | 공유 관리와 삭제를 포함한 모든 권한.                                                                            |

실행의 소유자는 정확히 한 명입니다. 공유된 실행을 여는 모든 사람은 로그인해야 합니다. 공유된 실행에 익명으로 접근할 수는 없습니다.

## 링크 공유하기

1. **공유 및 개인정보**를 엽니다.
2. **링크 접근 권한**에서 다음 옵션 중 하나를 선택합니다.
   - **제한됨**: 소유자와 초대된 사람만 실행을 열 수 있습니다.
   - **링크가 있는 모든 사람**: 링크를 가진 로그인한 모든 사용자가 실행을 열 수 있습니다.
3. **링크가 있는 모든 사람**에서는 링크가 부여하는 역할을 **뷰어** 또는 **편집자** 중에서 선택합니다. 링크는 **소유자** 역할을 절대 부여하지 않습니다.
4. **링크 복사**를 선택합니다.

링크는 `/share/<token>` 형식입니다. 토큰은 링크에서 추측하기 어려운 부분입니다. 링크가 해지되거나 실행이 삭제되면 링크에 **공유를 찾을 수 없음**이 표시됩니다.

> [!NOTE]
> API 키와 기본 URL 같은 비밀 정보는 공유된 실행에 절대 표시되지 않습니다.

## 사람 초대하기

1. **공유 및 개인정보**를 엽니다.
2. **사람 초대**에서 사용자 이름을 입력합니다. 목록에 일치하는 사용자가 최대 10명까지 표시됩니다.
3. 역할로 **뷰어** 또는 **편집자**를 선택합니다.
4. **초대**를 선택합니다.

**접근 권한이 있는 사람**에는 실행에 역할이 있는 모든 사람이 나열됩니다. 각 사람에 대해 다음을 할 수 있습니다.

- 역할을 변경합니다.
- 접근 권한을 제거합니다.

각 사람은 규칙이 부여하는 가장 높은 접근 권한을 유지합니다. 예를 들어 초대된 편집자는 링크가 **뷰어**를 부여하더라도 **편집자** 역할을 유지합니다.

### 소유권 이전

실행을 다른 사용자에게 넘길 수 있습니다.

1. **접근 권한이 있는 사람**에서 사람의 역할 메뉴를 엽니다. **사람 초대** 아래의 역할 메뉴를 사용할 수도 있습니다.
2. **소유권 이전**을 선택합니다.
3. 이전을 확인합니다.

새 소유자는 모든 권한을 얻습니다. 나는 편집자가 되며 소유자 권한을 잃습니다.

## 공개 범위

공개 범위는 실행이 탐색 갤러리의 공개 검색에 표시되는지 정합니다. 링크 접근 권한이나 초대는 바꾸지 않습니다.

| 옵션         | 의미                                                                 |
| ------------ | -------------------------------------------------------------------- |
| **공개**     | 공개 검색에 표시됩니다. 모든 사용자가 볼 수 있습니다.                |
| **비공개**   | 공개 검색에서 숨겨집니다. 나와 초대된 사람만 볼 수 있습니다.         |

공개 범위는 소유자만 바꿀 수 있습니다. 변경 사항은 즉시 적용됩니다.

## 탐색 갤러리

탐색 페이지에서 최적화를 검색할 수 있습니다. 세 가지 탭이 있습니다.

| 탭                 | 표시되는 내용                                    |
| ------------------ | ------------------------------------------------ |
| **내 것**          | 내 최적화(비공개와 공개 모두)                    |
| **공개**           | 다른 사용자의 공개 최적화                        |
| **나와 공유됨**    | 다른 사용자가 나와 공유한 최적화                 |

실행을 찾으려면 검색창과 **필터**를 사용하세요.

탐색에서는 `success` 상태로 끝난 공개 실행만 열 수 있습니다. 공개 실행을 열면 다음과 같습니다.

- **뷰어** 역할을 받습니다. 실행을 읽고 복제할 수 있습니다.
- 페이지에 실행의 소유자가 표시됩니다.
- Skynet은 API 키와 기본 URL 같은 비밀 정보를 제거합니다.
- 모델을 실행할 수 없습니다. 모델을 실행하면 소유자의 키가 사용되기 때문입니다.

> [!TIP]
> 공개 실행에서 특정한 한 사람에게 더 많은 접근 권한을 주려면 그 사람을 **편집자**로 초대하세요.
