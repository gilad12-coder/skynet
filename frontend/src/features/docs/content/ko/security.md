이 페이지는 Skynet이 계정, 키, 데이터를 보호하는 방식을 설명합니다. 보안 문제를 신고하는 방법도 알려 줍니다.

## 취약점 신고

보안 문제는 비공개로 신고하세요. 공개 이슈를 열지 마세요.

- GitHub에서 Skynet 리포지토리를 열고 **Security** > **Report a vulnerability**로 이동합니다.
- 또는 `security@skynetml.com`으로 이메일을 보냅니다.

팀은 영업일 기준 5일 이내에 각 신고에 대한 접수를 확인하는 것을 목표로 합니다.

## 내 계정

### 로그인 방법

다음 방법으로 로그인할 수 있습니다.

- 이메일 주소와 비밀번호.
- **Google로 계속하기** 또는 **GitHub로 계속하기**.
- **패스키로 로그인**. 패스키는 Face ID, Touch ID 또는 하드웨어 키를 사용합니다.

사용하는 제공업체는 **연결된 계정**에서 관리할 수 있습니다.

### 비밀번호 규칙

비밀번호는 다음 조건을 충족해야 합니다.

- 8자 이상이어야 합니다.
- 128자 이하여야 합니다.
- 이메일 주소를 포함하지 않아야 합니다.

새 계정은 코드로 이메일 주소를 인증해야 합니다. 비밀번호 재설정에도 Skynet이 이메일로 보내는 코드를 사용합니다.

로그인 시도가 반복해서 실패하면 Skynet은 해당 이메일 주소의 로그인을 일정 기간 잠급니다.

### 2단계 인증

보호를 강화하려면 2단계 인증을 켜세요. 방법을 하나 선택합니다.

| 방법                  | 작동 방식                                                  |
| --------------------- | ---------------------------------------------------------- |
| **인증 앱**           | 인증 앱의 6자리 코드를 입력합니다.                         |
| **이메일 인증 코드**  | 로그인할 때마다 Skynet이 보내는 6자리 코드를 입력합니다.   |

Skynet은 복구 코드도 제공합니다. 안전한 곳에 보관하세요. 인증 방법에 접근할 수 없게 되면 복구 코드 하나를 사용하세요.

> [!NOTE]
> Google이나 GitHub로 로그인하면 해당 제공업체가 2단계 인증을 관리합니다.

## 코드가 실행되는 위치

사용자 워크로드는 격리된 샌드박스에서 실행됩니다. 호스팅 제품에서는 Vercel Sandbox가 실행 경계입니다. 여기에는 설정 검사, 최적화 실행, 복구, 완료된 실행에 대한 작업이 포함됩니다.

Skynet 워커는 사용자 코드를 실행하지 않습니다. 워커는 컨트롤 플레인입니다. 작업을 시작하고, 예산을 예약하고 정산하며, 범위가 제한된 자격 증명을 샌드박스에 제공하고, 체크포인트를 저장합니다.

유료 작업을 시작하기 전에 Skynet은 지갑과 실행 예산에 여유분을 예약합니다. [예산과 결제](/docs/concepts/billing)를 참고하세요.

[Mac 앱](/docs/guides/mac-app)에서는 작업이 로컬 Docker 컨테이너에서 실행됩니다. 모든 로컬 서비스는 `127.0.0.1`에서만 수신합니다.

## 제공업체 키(BYOK)

자신의 모델 제공업체 키를 추가할 수 있습니다.

- Skynet은 저장된 각 키를 암호화합니다.
- Skynet은 API를 통해 전체 키를 절대 반환하지 않습니다.
- Skynet은 마지막 네 글자와 상태(미인증, 인증됨, 유효하지 않음)만 보관합니다.
- 키를 입력하면 Skynet은 작은 테스트 요청을 보내 키를 확인합니다.

내 키를 사용하면 제공업체가 내 키에 직접 비용을 청구합니다. Skynet은 여전히 플랫폼 수수료와 샌드박스 사용량을 잔액에서 청구합니다.

Skynet은 로그와 오류 메시지에서 비밀 정보도 제거합니다. 비밀 정보는 `[REDACTED]`로 바뀝니다.

## API 토큰

API 토큰을 사용하면 스크립트와 도구가 Skynet API를 호출할 수 있습니다.

- 사용자마다 유효한 토큰은 최대 하나입니다. 새 토큰을 생성하면 이전 토큰은 작동하지 않습니다.
- 토큰은 `skyd_`로 시작합니다.
- Skynet은 토큰의 해시만 저장합니다.
- Skynet은 전체 토큰을 한 번만 보여 줍니다. 토큰을 바로 복사해서 보관하세요.
- 그 후에는 Skynet이 마스킹된 형태(`skyd_…`와 마지막 네 글자)만 보여 줍니다.

`Authorization` 헤더에 토큰을 넣어 보냅니다.

```http
Authorization: Bearer skyd_...
```

토큰을 중지하려면 **토큰 해지**를 클릭합니다. 전체 API는 [API](/docs/api)를 읽어 보세요.

> [!WARNING]
> 토큰은 비밀번호처럼 다루세요. 토큰을 가진 사람은 누구나 API를 통해 나로 행동할 수 있습니다. 토큰을 리포지토리에 커밋하지 마세요.

## 모델 데이터 개인정보 보호

**모델 데이터 개인정보 보호** 설정은 모델 제공업체가 내 데이터로 할 수 있는 일을 제어합니다. 이 설정은 Skynet이 내 잔액으로 청구하는 최적화에 적용됩니다.

| 옵션             | 효과                                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| **모두 허용**    | 프롬프트로 학습하거나 프롬프트를 저장할 수 있는 제공업체를 포함해 모든 제공업체.               |
| **학습 금지**    | 프롬프트로 학습하지 않고 프롬프트를 보관하지 않는 제공업체만. 기본값입니다.                    |
| **보관 없음**    | 데이터 무보관(zero-data-retention) 계약이 있는 엔드포인트만. 일부 모델을 사용하지 못할 수 있습니다. |

> [!NOTE]
> 내 키로 하는 최적화는 내 OpenRouter 계정의 개인정보 설정을 따릅니다.

## 실행의 공개 범위

> [!WARNING]
> 새 실행은 기본적으로 **공개**입니다. 공개 실행은 공개 검색에 나타납니다. 누구나 찾아서 그 결과를 둘러볼 수 있습니다.

실행을 공개 검색에서 제외하려면 제출할 때 **공개 범위**를 **비공개**로 설정하세요. 공개 범위는 나중에 공유 대화상자에서 바꿀 수 있습니다. [공유 및 게시](/docs/guides/sharing)를 참고하세요.

새 데이터셋은 **제한됨**입니다. 링크 접근 권한을 바꾸기 전까지는 나와 내가 초대한 사람만 열 수 있습니다. [데이터셋 준비](/docs/guides/datasets)를 참고하세요.

## 내 데이터

데이터를 관리하려면 **설정**에서 **개인정보 및 데이터** 탭을 엽니다.

### 데이터 내보내기

**내 데이터 내보내기**에서 **내보내기**를 클릭합니다. 내보낸 파일에는 계정의 모든 데이터가 들어 있습니다. 형식은 JSON, CSV, Excel, Pickle, Parquet, Feather 중 하나를 선택합니다.

### 계정 삭제

**계정 삭제**를 클릭합니다. 확인을 위해 현재 비밀번호를 입력하고 이메일 주소를 입력합니다.

> [!WARNING]
> 이 작업은 계정과 모든 데이터를 영구적으로 삭제합니다. 되돌릴 수 없습니다.

### 사용 분석

**익명 사용 분석 전송** 설정은 익명 제품 분석을 켜거나 끕니다.
