이 페이지는 Skynet에 대해 자주 묻는 질문에 답합니다. 각 답변에는 자세한 내용이 있는 페이지 링크가 있습니다.

## 일반

### Skynet은 무엇인가요?

Skynet은 프롬프트, 프로그램, 에이전트, 워크플로를 사용자의 데이터와 메트릭에 맞춰 최적화하는 플랫폼입니다. 데이터셋을 업로드하고, 작업을 설명하고, 실행을 시작합니다. 실행은 새 버전을 시도하고 따로 떼어 둔 데이터에서 채점합니다. 시작하려면 [빠른 시작](/docs/quickstart)을 읽어 보세요.

### Skynet은 무엇을 최적화할 수 있나요?

Skynet은 Optimize Anything입니다. 하나의 제품에서 프롬프트, 코드, 텍스트, DSPy 프로그램을 최적화합니다. 어떤 엔진이 작업할 수 있는지는 아티팩트 종류에 따라 정해집니다.

- 프롬프트, 코드, 텍스트 아티팩트는 네이티브 엔진을 사용합니다: GEPA, Best-of-N, Meta-Harness, AutoResearch, AutoSaddler, ShinkaEvolve.
- DSPy 프로그램은 DSPy 옵티마이저를 사용합니다: DSPy GEPA, DSPy MIPROv2, DSPy BootstrapFewShot.

**Auto**는 작업에 맞는 엔진을 조합합니다. [최적화의 작동 방식](/docs/concepts/optimization)과 [엔진](/docs/concepts/engines)을 참고하세요.

### 인터페이스는 어떤 언어를 지원하나요?

인터페이스는 24개 언어를 지원합니다. 기본 언어는 히브리어이며, 레이아웃은 오른쪽에서 왼쪽으로 쓰는 텍스트를 지원합니다. 히브리어 문서는 [/docs/he](/docs/he)에 있습니다.

### Skynet은 오픈 소스인가요?

네. 코드는 AGPL-3.0 라이선스를 사용합니다. 변경한 Skynet을 서비스로 제공하면, 라이선스에 따라 변경 사항을 공유해야 합니다.

## 데이터

### 어떤 파일 형식을 업로드할 수 있나요?

CSV, JSON, `.xlsx`, `.xls` 파일을 업로드할 수 있습니다. Excel 파일은 첫 번째 시트만 읽습니다. [데이터셋 준비](/docs/guides/datasets)를 참고하세요.

### 데이터에 라벨이 없습니다. 어떻게 해야 하나요?

태거를 사용하세요. 행에 직접 라벨을 붙이거나, AI 모델이 라벨을 붙이게 하고 그 작업을 검토할 수 있습니다. [태거로 데이터 라벨링](/docs/guides/tagger)을 참고하세요.

### 누가 내 실행과 데이터셋을 볼 수 있나요?

> [!WARNING]
> 새 실행은 기본적으로 **공개**입니다. 공개 실행은 공개 검색에 나타나며, 누구나 그 결과를 둘러볼 수 있습니다.

실행을 공개 검색에서 제외하려면 실행을 제출할 때 **공개 범위**를 **비공개**로 설정하세요. 새 데이터셋은 **제한됨**입니다. 나와 내가 초대한 사람만 열 수 있습니다. [공유 및 게시](/docs/guides/sharing)와 [보안](/docs/security)을 참고하세요.

### 모델 제공업체가 내 프롬프트로 학습하나요?

기본적으로 학습하지 않습니다. 기본 **모델 데이터 개인정보 보호** 옵션은 **학습 금지**입니다. 이 옵션은 프롬프트로 학습하지 않고 프롬프트를 보관하지도 않는 제공업체에만 프롬프트를 보냅니다. 이 설정은 Skynet이 내 잔액으로 청구하는 호출에 적용됩니다. 내 키로 하는 호출은 내 OpenRouter 계정의 개인정보 설정을 따릅니다. [보안](/docs/security)을 참고하세요.

## 청구

### Skynet은 실행 비용을 어떻게 청구하나요?

Skynet은 선불 잔액을 사용합니다. 호스팅 모델 사용량, Skynet 수수료, 샌드박스 사용량을 계량합니다. 유료 작업이 시작되기 전에 Skynet은 지갑과 실행 예산에 여유분을 예약합니다. [예산과 결제](/docs/concepts/billing)를 참고하세요.

### 내 모델 제공업체 키를 사용할 수 있나요?

네. 내 키(BYOK)를 사용하면 제공업체가 모델 호출 비용을 내 키에 직접 청구합니다. 플랫폼 수수료와 샌드박스 사용량은 여전히 Skynet 잔액에서 지불합니다. Skynet은 키를 암호화하며 다시는 보여 주지 않습니다. [예산과 결제](/docs/concepts/billing)와 [보안](/docs/security)을 참고하세요.

### 모델 호출 비용 없이 Skynet을 실행할 수 있나요?

[Mac 앱](/docs/guides/mac-app)은 내 컴퓨터에서 Skynet을 실행합니다. 모델 호출은 Mac에서 로그인한 Claude Code나 Codex를 통해 보냅니다. 이 호출 비용은 CLI 요금제가 부담하므로, 실행 비용에 $0가 추가됩니다.

## 도구와 연동

### 내 AI 클라이언트에서 Skynet을 제어할 수 있나요?

네. Skynet에는 `https://mcp.skynetml.com/mcp`에 MCP 서버가 있습니다. OAuth로 로그인합니다. 서버에는 `check_run`, `start_run`, `get_run`, `list_runs`, `stop_run` 도구가 있습니다. [MCP 서버](/docs/mcp)를 참고하세요.

### API가 있나요?

네. 설정에서 API 토큰을 생성한 다음 `Authorization: Bearer <token>`으로 보내세요. 사용자마다 한 번에 하나의 유효한 토큰만 가질 수 있습니다. [API](/docs/api)를 참고하세요.

### 에이전트 패널이 내 실행을 삭제할 수 있나요?

허용한 경우에만 가능합니다. 기본 **확인** 모드에서는 에이전트가 모든 작업 전에 묻습니다. **자동** 모드에서도 삭제나 제출 같은 파괴적인 작업 전에는 여전히 묻습니다. [에이전트 패널](/docs/guides/agent-panel)을 참고하세요.
