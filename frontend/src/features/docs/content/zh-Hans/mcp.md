Skynet MCP 服务器让 AI 智能体替你使用 Skynet。Claude、ChatGPT、Codex、Cursor 和其他 MCP 客户端可以检查运行设置、启动运行、观察运行并停止运行。你只需在浏览器中批准一次连接。智能体会为每次运行设置支出上限。

## 服务器 URL

所有客户端都使用同一个 URL：

```text
https://mcp.skynetml.com/mcp
```

服务器使用 Streamable HTTP。登录使用 OAuth 2.1。你不需要把令牌或 API 密钥复制到客户端中。

## 连接你的客户端

选择你的客户端。按照它的步骤操作，然后转到[批准连接](#批准连接)。

```skynet-mcp-clients

```

## 批准连接

智能体第一次调用 Skynet 时，浏览器会打开一个 Skynet 页面。

1. 如果你尚未登录，请登录 Skynet。
2. 阅读该页面。它会显示智能体名称、它将返回的网站以及你的账户。
3. 了解智能体可以做什么：
   - 查看你的优化运行及其结果。
   - 启动和停止优化运行，费用从你的余额中支付。
4. 点击 **Allow** 以连接。点击 **Deny** 以停止。

点击 **Allow** 后，浏览器会返回智能体。智能体现在可以调用下面的工具。

> [!NOTE]
> 智能体会为每次运行设置支出上限。它无法充值。

## 工具

| 工具        | 作用                                                         | 权限 |
| ----------- | ------------------------------------------------------------ | ---- |
| `check_run` | 检查运行设置，但不执行运行，也不向你收费。会建议一个支出上限。 | 读   |
| `start_run` | 以指定的支出上限启动运行。                                   | 写   |
| `get_run`   | 返回状态、已花费金额，以及运行结束时的结果。                 | 读   |
| `list_runs` | 列出你的运行，最新的在前。可以按状态筛选。                   | 读   |
| `stop_run`  | 停止一次运行。第二次调用会返回错误，说明该运行已经结束。     | 写   |

读权限使用 `runs:read` 范围。写权限使用 `runs:write` 范围。

没有任何工具可以充值、更改你的余额或更改计费设置。

## 智能体如何执行一次优化

1. 智能体用运行设置调用 `check_run`。Skynet 执行静态检查并返回：
   - 每项检查的结果。
   - 运行可以启动的最低支出上限。
   - 建议的支出上限，至少为 $5.00。
   - 没有已知价格的模型。
   - 你现在可以花费的金额。
2. 智能体用一个支出上限（`max_cost_cents`，1 到 1,000,000 美分）调用 `start_run`。它也可以发送一个 `idempotency_key`，这样重试时不会启动第二次运行。
3. 如果设置检查仍在进行，`start_run` 会返回 `in_progress` 和 `retry_after_seconds`。智能体在这段时间后用相同的输入再次调用 `start_run`。
4. 智能体反复调用 `get_run`，直到运行结束。最终状态为 `success`、`failed`、`cancelled` 和 `stopped`。

> [!TIP]
> 在提示词中告诉智能体你的支出上限，例如“优化这个提示词，最多花 $10。”智能体就会在 `start_run` 中使用这个上限。

运行达到支出上限时会停止。关于 Skynet 如何为运行收费，请阅读[计费](/docs/concepts/billing)。

## 安全

- 每个客户端都有自己的授权。客户端永远看不到你的密码。
- 登录使用 PKCE（S256）。客户端通过动态客户端注册或客户端 ID 元数据文档完成自身注册。
- 访问令牌在 1 小时后过期。客户端使用刷新令牌续期。
- 刷新令牌在 30 天未使用后过期。一次授权最长持续 90 天。之后你需要再次批准连接。
- 每个刷新令牌只能使用一次。如果有人再次使用旧的刷新令牌，Skynet 会终止该授权。
- 智能体只能查看和更改你自己的运行。

关于 Skynet 如何保护你的账户和数据，请阅读[安全](/docs/security)。

## 断开连接

要断开智能体，请从客户端中移除 Skynet 服务器。大多数客户端随后会吊销它们的令牌。如果客户端没有吊销，它的刷新令牌会在 30 天未使用后过期。

## 故障排除

| 问题                                 | 处理方法                                                         |
| ------------------------------------ | ---------------------------------------------------------------- |
| 连接立即失败                         | 检查服务器 URL。它必须完全是 `https://mcp.skynetml.com/mcp`。    |
| “This agent can't connect”           | 从客户端重新发起连接。                                           |
| “Too many attempts”                  | 等待几分钟，然后重试。                                           |
| 客户端没有打开浏览器                 | 更新客户端。它必须支持带 OAuth 的远程 MCP 服务器。               |
| `start_run` 因余额错误而失败         | 在 Skynet 中充值，或用更低的支出上限启动运行。                   |
| 几周后工具停止工作                   | 授权已过期。移除服务器并重新连接。                               |

如需不通过智能体直接访问 HTTP，请阅读 [API](/docs/api)。
