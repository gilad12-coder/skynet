你可以把运行分享给其他人，也可以把它列入公开的“探索”展示区。这是两个不同的设置。链接访问权限和邀请控制谁可以打开运行。公开可见性控制运行是否出现在公开搜索中。本指南会说明这两者。

## 默认设置

| 设置                               | 新运行的默认值                                       |
| ---------------------------------- | ---------------------------------------------------- |
| 公开可见性                         | **公开**。运行会列在公开搜索中。                     |
| 链接访问权限                       | **受限**。只有所有者和受邀的人可以打开运行。         |
| **任何拥有链接的人** 获得的角色    | **查看者**                                           |

提交向导会在最后一个页面上显示新运行的可见性。运行开始后，你可以在 **共享与隐私** 对话框中更改它。

> [!WARNING]
> 新运行默认是公开的。如果你的运行包含其他用户不应看到的数据，请在 **共享与隐私** 对话框中把它设为 **私有**。

## 打开分享设置

在运行页面上，选择 **共享与隐私**。只有运行的所有者能看到这个按钮。

## 角色

每个可以打开运行的人都拥有以下三种角色之一：

| 角色       | 此人可以做什么                                                                         |
| ---------- | -------------------------------------------------------------------------------------- |
| **查看者** | 打开运行，查看其结果和所有者。克隆运行。                                               |
| **编辑者** | 查看者权限，外加运行模型、对话和重命名。编辑者还可以取消、暂停、继续和重试运行。       |
| **所有者** | 完全控制，包括管理分享和删除。                                                         |

一次运行只有一个所有者。所有打开共享运行的人都必须登录。共享运行不支持匿名访问。

## 分享链接

1. 打开 **共享与隐私**。
2. 在 **链接访问权限** 下，选择以下选项之一：
   - **受限**：只有所有者和受邀的人可以打开运行。
   - **任何拥有链接的人**：任何拥有链接的已登录用户都可以打开运行。
3. 对于 **任何拥有链接的人**，选择链接授予的角色：**查看者** 或 **编辑者**。链接永远不会授予 **所有者** 角色。
4. 选择 **复制链接**。

链接的形式为 `/share/<token>`。token 是链接中难以猜测的部分。如果链接被吊销或运行被删除，链接会显示 **未找到共享**。

> [!NOTE]
> 机密信息（例如 API 密钥和 base URL）永远不会显示在共享的运行中。

## 邀请他人

1. 打开 **共享与隐私**。
2. 在 **邀请他人** 下输入用户名。列表最多显示 10 个匹配的用户。
3. 选择一个角色：**查看者** 或 **编辑者**。
4. 选择 **邀请**。

**拥有访问权限的人员** 列出了在该运行上拥有角色的所有人。对于每个人，你可以：

- 更改角色。
- 移除访问权限。

每个人保留规则所给予的最高权限。例如，当链接授予 **查看者** 时，受邀的编辑者仍保留 **编辑者** 角色。

### 转移所有权

你可以把运行交给另一个用户：

1. 在 **拥有访问权限的人员** 中打开某人的角色菜单。你也可以使用 **邀请他人** 下的角色菜单。
2. 选择 **转移所有权**。
3. 确认转移。

新所有者获得完全控制。你会成为编辑者，并失去所有者权限。

## 公开可见性

公开可见性控制运行是否出现在“探索”展示区的公开搜索中。它不会改变链接访问权限或邀请。

| 选项       | 含义                                                   |
| ---------- | ------------------------------------------------------ |
| **公开**   | 列在公开搜索中。所有用户都能看到。                     |
| **私有**   | 不出现在公开搜索中。只有你和受邀的人能看到。           |

只有所有者可以更改公开可见性。更改立即生效。

## “探索”展示区

“探索”页面让你搜索优化。它有三个标签页：

| 标签页           | 显示的内容                           |
| ---------------- | ------------------------------------ |
| **我的**         | 你的优化，包括私有和公开的           |
| **公开**         | 来自其他用户的公开优化               |
| **已共享给我**   | 其他用户分享给你的优化               |

使用搜索栏和 **筛选** 来查找运行。

只有以 `success` 状态完成的公开运行，你才能从“探索”中打开。打开后：

- 你获得 **查看者** 角色。你可以阅读运行并克隆它。
- 页面会显示运行的所有者。
- Skynet 会移除机密信息，例如 API 密钥和 base URL。
- 你无法运行模型，因为那会消耗所有者的密钥。

> [!TIP]
> 如果想让某个人对公开运行拥有更多权限，请邀请此人作为 **编辑者**。
