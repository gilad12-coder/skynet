Skynet 使用预付余额。你向余额中充值。每次运行都有一个支出上限，Skynet 会从你的余额中扣除运行的实际用量。本页说明余额、运行预算、预留、费用以及你自己的提供商密钥。

> [!NOTE]
> 本页中的数字是当前的默认值。应用中显示实时数值。打开 **设置 → 计费** 可以查看你的余额、充值手续费和交易记录。

## 余额

你的余额以美元计。Skynet 以美分为单位保存它。

默认情况下，Skynet 不提供免费的初始余额。请在开始第一次付费运行之前充值。

你可以在 **设置 → 计费** 中充值。你可以选择固定金额，也可以输入自定义金额：

| 充值方式 | 计入余额的金额               |
| -------- | ---------------------------- |
| 固定金额 | $5、$20 或 $50               |
| 自定义   | $5 到 $1,000 之间的任意金额  |

你选择的金额就是计入余额的金额。充值手续费另外收取。请参阅下面的费用说明。

**设置 → 用量** 显示你的花费。**设置 → 计费** 中的交易记录列出了你的充值和运行扣费。

## 运行预算

每次运行都有一个支出上限。上限是该运行最多可以花费的金额。它涵盖设置和优化。

运行在开始之前没有费用估算。它最多花到上限，在达到预算时停止，并保留最佳版本。关于 Skynet 如何决定何时停止，请阅读[运行](/docs/concepts/runs)。

你在提交向导的 **预算** 页面中，通过 **支出上限** 字段设置上限：

- **设置上限** 是默认模式。上限从 $5 开始。如果运行开始时需要超过 $5，上限就从该金额开始。
- **不设上限** 让运行一直使用你的余额，直到完成。运行永远不会暂停。如果你的余额用完，运行会停止并保留它已产出的结果。

### 开始所需金额

向导会显示 **开始所需** 的金额。该金额包括：

- 运行在第一次模型调用之前打开的沙箱所需的预留，加上
- 为最初几次模型调用准备的余量。余量为 $1；如果你所选模型中最贵的单次调用费用更高，则为该费用。

当上限低于此金额时，向导不允许你继续。当你的余额低于此金额时，向导也会阻止你。请提高上限或充值后继续。

> [!TIP]
> 当运行因达到预算而停止时，请在运行页面上使用 **提高上限并继续**。运行会从最后一个检查点继续。

## 预留

在 Skynet 执行付费工作之前，它会预留运行上限中的一部分。工作结算后，Skynet 会释放预留，只收取实际费用。

当某个预算已经有活动时，向导中的 **支出上限** 卡片会显示其账目：

| 标签                 | 含义                                                     |
| -------------------- | -------------------------------------------------------- |
| **此上限内剩余**     | 上限中剩余的部分。                                       |
| **迄今已花费**       | 已结算的费用。                                           |
| **已预留**           | 为进行中的工作冻结的资金。工作结算后，Skynet 会释放它。  |

## 费用

除提供商费用之外，Skynet 还有三项收费。

| 收费项                 | 当前默认值                                | 适用于                                         |
| ---------------------- | ----------------------------------------- | ---------------------------------------------- |
| 充值手续费             | 金额的 12.5%，另加 $0.35                  | 每次充值                                       |
| 用量加价               | 提供商费用 × 1.15（成本加 15%）           | 使用 Skynet 密钥的模型调用，以及沙箱计算       |
| 自有密钥的平台费       | 模型费用的 5%                             | 使用你自己的提供商密钥的模型调用               |

### 充值手续费

Skynet 把百分比部分向上取整到下一美分，然后加上 $0.35。例如，充值 $20 的手续费为 $2.85。充值页面会在你付款前显示手续费。

### 用量加价

Skynet 把提供商费用乘以用量加价。加价适用于由 Skynet 付费的模型调用，以及沙箱计算。预留、开始所需金额以及应用中的模型价格都已包含加价。

Skynet 按以下顺序确定一次模型调用的提供商费用：

1. OpenRouter 为该调用报告的费用。
2. OpenRouter 为该模型提供的实时价目表。
3. LiteLLM 价格表。
4. 一个较高的兜底费率：每百万输入 token $15，每百万输出 token $75。这个费率确保 Skynet 对未知模型的收费永远不会低于其成本。

## 你自己的提供商密钥（BYOK）

你可以用自己的提供商密钥执行模型调用。在 **设置 → 提供商** 中添加密钥。对于 OpenRouter，你也可以使用 **使用 OpenRouter 继续**。

当模型调用使用你的密钥时：

- 你的提供商把模型 token 的费用计到你的密钥上。
- Skynet 从你的余额中收取模型费用 5% 的平台费。Skynet 不会在这项费用上加收用量加价。
- 运行的支出上限只涵盖平台费和沙箱用量。

外部评分器或 MCP 提供商收取的任何费用都直接归该提供商所有。它们不属于运行的支出上限。

## 沙箱用量

你的运行代码和指标在沙箱中运行。Skynet 对沙箱计算按量计费：

1. 在沙箱启动之前，Skynet 从运行的上限中预留一笔金额。
2. 沙箱结束后，Skynet 按沙箱提供商报告的最终用量收费。
3. 用量加价适用于沙箱计算。

沙箱计算属于运行的支出上限，即使模型调用使用的是你自己的密钥也是如此。

## 套餐

有两种套餐：Free 和 Pro。Pro 会提高部分限制，例如并发运行数和存储量。如果 Pro 续费失败，账户会在 7 天内保留 Pro 限制。之后，在付款成功之前，账户使用 Free 限制。请参阅[限制](/docs/limits)。

## 平台保护措施

- 交互式模型轮次（例如与助手对话）开始前，余额至少需要 $0.05。
- 向导助手是免费的。每个账户每个 UTC 日可以发起 50 轮向导助手对话。
