Skynet 对运行、文件、存储和请求速率设有限制。这些限制可以保持平台稳定，并保护你的余额。本页列出默认值。管理员可以为某个账户更改部分限制。

> [!NOTE]
> 本页中的值是当前的默认值。当你达到某个限制时，应用或 API 会告诉你是哪个限制阻止了请求。

## 运行

| 限制                 | Free | Pro   |
| -------------------- | ---- | ----- |
| 同时进行的活跃运行   | 5    | 20    |
| 保存的运行           | 100  | 1,000 |

活跃运行是指状态为 `pending`、`validating`、`running` 或 `paused` 的运行。当你的活跃运行数达到上限时，Skynet 会拒绝新运行，直到其中一个结束。

保存运行的限制会计算你的所有运行。删除不需要的运行，为新运行腾出空间。

如果 Pro 续费失败，账户会在 7 天内保留 Pro 限制。之后，在付款成功之前，账户使用 Free 限制。

| 限制                             | 值                                                       |
| -------------------------------- | -------------------------------------------------------- |
| 一次 API 克隆请求中的副本数      | 1 到 5                                                   |
| 每次运行的自动恢复尝试次数       | 3                                                        |
| 契约检查中的样例用例数           | 3                                                        |
| 每次运行存储的进度事件数         | 5,000。Skynet 会先删除最旧的事件。                       |
| 单个沙箱的生命周期               | 45 分钟。需要更多时间的运行会打开一个新沙箱。            |

关于恢复尝试的工作方式，请阅读[运行](/docs/concepts/runs)。

## 存储

| 限制     | Free    | Pro    |
| -------- | ------- | ------ |
| 总存储量 | 250 MiB | 10 GiB |

总存储量包括你的运行、数据集、日志、智能体对话、暂存的上传文件和搜索数据。如果某次写入会超出你的存储上限，Skynet 会拒绝它。

## 文件与数据集

| 限制                               | 值                          |
| ---------------------------------- | --------------------------- |
| 保存到库中的数据集文件             | 每个文件 50 MiB（压缩后）   |
| 从导入记录的连接器导入的行数       | 20,000                      |
| 附加到智能体对话的文件             | 20 MiB                      |
| 从一个对话附件中读取的文本         | 50,000 个字符               |
| 语音输入的音频片段                 | 25 MB                       |
| GitHub 仓库归档                    | 200 MiB（压缩后）           |
| 在运行页面中打开的仓库文件         | 1 MiB                       |

导入记录的连接器包括数据库表、LLM 追踪记录和 Notion 数据库。请阅读[准备数据集](/docs/guides/datasets)。

### 向导中的工作区文件

| 限制               | 值                                                                      |
| ------------------ | ----------------------------------------------------------------------- |
| 工作区中的额外文件 | 20                                                                      |
| 文件名长度         | 120 个字符                                                              |
| 文件夹深度         | 3 层文件夹                                                              |
| 文件类型           | `.py`、`.txt`、`.md`、`.json`、`.yaml`、`.csv`、`.toml`、`.ini`、`.cfg` |

`run.py` 和 `metric.py` 是运行的入口文件。你不能删除、重命名或移动它们。

## 请求速率

| 限制                                         | 值                                  |
| -------------------------------------------- | ----------------------------------- |
| 运行提交                                     | 每个账户在滚动的一分钟内 30 次      |
| 语音输入片段                                 | 每个账户每小时 120 个               |
| 为智能体对话读取的文件                       | 每个账户每小时 300 个               |
| 账户请求（注册、重置密码、邮箱验证）         | 每个邮箱地址在滚动的一小时内 20 次  |
| 向导助手的对话轮次                           | 每个账户每个 UTC 日 50 轮           |
| 搜索和索引 token                             | 每个账户每月 2,000,000 个           |

当你超出速率限制时，API 会返回 HTTP 状态码 `429`。请等待，然后再次发送请求。

当某个账户超出每月的搜索和索引 token 时，Skynet 会停止为该账户索引新条目。此后搜索的表现就像语义搜索不可用一样。

## 费用

| 限制                                 | 值                                                    |
| ------------------------------------ | ----------------------------------------------------- |
| 新运行的默认支出上限                 | $5，如果开始所需金额更高，则为该金额                  |
| 开始所需金额中的余量                 | $1，如果最贵的单次模型调用费用更高，则为该费用        |
| 自定义充值                           | $5 到 $1,000                                          |
| 开始一次交互式模型轮次所需的余额     | $0.05                                                 |

关于费用和预留，请阅读[预算与计费](/docs/concepts/billing)。
