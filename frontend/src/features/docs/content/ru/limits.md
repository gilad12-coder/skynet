Skynet ограничивает запуски, файлы, хранилище и частоту запросов. Лимиты поддерживают стабильность платформы и защищают ваш баланс. На этой странице перечислены значения по умолчанию. Администратор может изменить некоторые лимиты для отдельного аккаунта.

> [!NOTE]
> Значения на этой странице — текущие значения по умолчанию. Когда вы достигаете лимита, приложение или API сообщает, какой лимит остановил запрос.

## Запуски

| Лимит                              | Free | Pro   |
| ---------------------------------- | ---- | ----- |
| Активных запусков одновременно     | 5    | 20    |
| Сохранённых запусков               | 100  | 1 000 |

Активный запуск — это запуск со статусом `pending`, `validating`, `running` или `paused`. Когда у вас максимальное число активных запусков, Skynet отклоняет новые запуски, пока один из них не завершится.

Лимит сохранённых запусков учитывает все ваши запуски. Удаляйте ненужные запуски, чтобы освободить место для новых.

Если продление Pro не прошло, аккаунт сохраняет лимиты Pro в течение 7 дней. После этого действуют лимиты Free, пока оплата не пройдёт.

| Лимит                                            | Значение                                                               |
| ------------------------------------------------ | ---------------------------------------------------------------------- |
| Копий в одном запросе клонирования через API     | От 1 до 5                                                              |
| Попыток автоматического восстановления запуска   | 3                                                                      |
| Примеров в проверке контракта                    | 3                                                                      |
| Сохранённых событий прогресса на запуск          | 5 000. Skynet удаляет сначала самые старые события.                    |
| Время жизни одной песочницы                      | 45 минут. Запуску, которому нужно больше времени, открывается новая песочница. |

Как работают попытки восстановления, описано в разделе [Запуски](/docs/concepts/runs).

## Хранилище

| Лимит              | Free    | Pro    |
| ------------------ | ------- | ------ |
| Общий объём хранилища | 250 MiB | 10 GiB |

Общий объём хранилища включает ваши запуски, наборы данных, логи, чаты с агентом, подготовленные загрузки и поисковые данные. Skynet отклоняет запись, которая превысила бы ваш лимит хранилища.

## Файлы и наборы данных

| Лимит                                              | Значение                                 |
| -------------------------------------------------- | ---------------------------------------- |
| Файл набора данных, сохранённый в библиотеку       | 50 MiB на файл, после сжатия             |
| Строк из коннектора, который импортирует записи    | 20 000                                   |
| Файл, прикреплённый к чату с агентом               | 20 MiB                                   |
| Текст, прочитанный из одного вложения в чате       | 50 000 символов                          |
| Аудиофрагмент для диктовки                         | 25 MB                                    |
| Архив репозитория GitHub                           | 200 MiB, в сжатом виде                   |
| Файл репозитория, открытый на странице запуска     | 1 MiB                                    |

К коннекторам, которые импортируют записи, относятся таблицы баз данных, трассировки LLM и базы данных Notion. Прочитайте [Подготовка набора данных](/docs/guides/datasets).

### Файлы рабочей области в мастере

| Лимит                                | Значение                                                                |
| ------------------------------------ | ----------------------------------------------------------------------- |
| Дополнительных файлов в рабочей области | 20                                                                   |
| Длина имени файла                    | 120 символов                                                            |
| Глубина вложенности папок            | 3 папки                                                                 |
| Типы файлов                          | `.py`, `.txt`, `.md`, `.json`, `.yaml`, `.csv`, `.toml`, `.ini`, `.cfg` |

`run.py` и `metric.py` — входные файлы запуска. Их нельзя удалить, переименовать или переместить.

## Частота запросов

| Лимит                                                                        | Значение                                        |
| ---------------------------------------------------------------------------- | ----------------------------------------------- |
| Отправка запусков                                                            | 30 на аккаунт за скользящую минуту              |
| Фрагменты диктовки                                                           | 120 на аккаунт в час                            |
| Файлы, прочитанные для чатов с агентом                                       | 300 на аккаунт в час                            |
| Запросы аккаунта (регистрация, сброс пароля, подтверждение электронной почты) | 20 на адрес электронной почты за скользящий час |
| Ходы ассистента мастера                                                      | 50 на аккаунт за сутки UTC                      |
| Токены поиска и индексации                                                   | 2 000 000 на аккаунт в месяц                    |

Если вы превышаете ограничение частоты, API возвращает HTTP-статус `429`. Подождите и отправьте запрос снова.

Когда аккаунт превышает месячный лимит токенов поиска и индексации, Skynet перестаёт индексировать для него новые элементы. После этого поиск работает так, как будто семантический поиск недоступен.

Комиссии и резервирование описаны в разделе [Бюджеты и оплата](/docs/concepts/billing).
