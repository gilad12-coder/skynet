На этой странице описано, как Skynet защищает ваш аккаунт, ваши ключи и ваши данные. Здесь же объясняется, как сообщить о проблеме безопасности.

## Сообщить об уязвимости

Сообщайте о проблемах безопасности конфиденциально. Не создавайте публичный issue.

- На GitHub откройте репозиторий Skynet и перейдите в **Security** > **Report a vulnerability**.
- Или отправьте письмо на `security@skynetml.com`.

Команда старается подтвердить получение каждого сообщения в течение пяти рабочих дней.

## Ваш аккаунт

### Способы входа

Войти можно с помощью:

- Адреса электронной почты и пароля.
- **Продолжить через Google** или **Продолжить через GitHub**.
- **Войти с помощью ключа доступа**. Ключ доступа использует Face ID, Touch ID или аппаратный ключ.

Используемыми провайдерами входа можно управлять в разделе **Связанные аккаунты**.

### Требования к паролю

Пароль должен:

- Содержать не меньше 8 символов.
- Содержать не больше 128 символов.
- Не содержать ваш адрес электронной почты.

Новый аккаунт должен подтвердить адрес электронной почты кодом. Для сброса пароля тоже используется код, который Skynet отправляет по почте.

После нескольких неудачных попыток Skynet временно блокирует вход для адреса электронной почты.

### Двухэтапная проверка

Включите двухэтапную проверку для дополнительной защиты. Выберите один способ:

| Способ                        | Как работает                                                        |
| ----------------------------- | ------------------------------------------------------------------- |
| **Приложение-аутентификатор** | Введите 6-значный код из приложения-аутентификатора.                |
| **Коды по почте**             | Введите 6-значный код, который Skynet отправляет при каждом входе.  |

Skynet также выдаёт коды восстановления. Храните их в надёжном месте. Используйте один из них, если потеряете доступ к выбранному способу.

> [!NOTE]
> Если вы входите через Google или GitHub, двухэтапной проверкой управляет этот провайдер.

## Где выполняется ваш код

Пользовательские задачи выполняются в изолированных песочницах. В облачном продукте границей выполнения служит Vercel Sandbox. Это касается проверок настроек, запусков оптимизации, восстановления и работы с завершёнными запусками.

Воркеры Skynet не выполняют ваш код. Они образуют управляющий слой: запускают задачи, резервируют и рассчитывают бюджеты, выдают песочницам учётные данные с ограниченными правами и сохраняют контрольные точки.

Перед началом платной работы Skynet резервирует запас в вашем кошельке и в бюджете запуска. См. [Бюджеты и оплата](/docs/concepts/billing).

В [приложении для Mac](/docs/guides/mac-app) задачи выполняются в локальных контейнерах Docker. Все локальные сервисы слушают только `127.0.0.1`.

## Ключи провайдеров (BYOK)

Вы можете добавить собственные ключи провайдеров моделей.

- Skynet хранит каждый ключ в зашифрованном виде.
- Skynet никогда не возвращает полный ключ через API.
- Skynet хранит только последние четыре символа и статус: не проверен, проверен или недействителен.
- Когда вы вводите ключ, Skynet отправляет небольшой тестовый запрос, чтобы его проверить.

Когда вы используете собственный ключ, провайдер списывает плату напрямую с вашего ключа. Skynet по-прежнему списывает со своего баланса комиссию платформы и плату за использование песочницы.

Skynet также удаляет секреты из логов и сообщений об ошибках. Он заменяет их на `[REDACTED]`.

## API-токены

API-токены позволяют скриптам и инструментам вызывать API Skynet.

- У каждого пользователя не больше одного действующего токена. Когда вы генерируете новый токен, старый перестаёт работать.
- Токены начинаются с `skyd_`.
- Skynet хранит только хеш токена.
- Skynet показывает полный токен только один раз. Сразу скопируйте и сохраните его.
- После этого Skynet показывает только маскированную форму: `skyd_…` и последние четыре символа.

Передавайте токен в заголовке `Authorization`:

```http
Authorization: Bearer skyd_...
```

Чтобы отключить токен, нажмите **Отозвать токен**. Полное описание API — в разделе [API](/docs/api).

> [!WARNING]
> Обращайтесь с токеном как с паролем. Любой, у кого есть токен, может действовать от вашего имени через API. Не коммитьте его в репозиторий.

## Конфиденциальность данных в моделях

Параметр **Конфиденциальность данных в моделях** определяет, что поставщики моделей могут делать с вашими данными. Он действует для оптимизаций, которые Skynet оплачивает с вашего баланса.

| Вариант             | Действие                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------- |
| **Разрешить все**   | Любой поставщик, включая тех, кто может обучаться на ваших промптах или хранить их.               |
| **Без обучения**    | Только поставщики, которые не обучаются на ваших промптах и не хранят их. Это значение по умолчанию. |
| **Без хранения**    | Только эндпоинты с соглашением о нулевом хранении данных. Некоторые модели могут быть недоступны. |

> [!NOTE]
> Оптимизации с вашим собственным ключом подчиняются настройкам конфиденциальности вашего аккаунта OpenRouter.

## Видимость запусков

> [!WARNING]
> Новые запуски по умолчанию **публичные**. Публичный запуск появляется в публичном поиске. Любой может найти его и просмотреть результаты.

Чтобы запуск не попал в публичный поиск, при отправке установите **Видимость** в значение **Приватная**. Позже видимость можно изменить в диалоге общего доступа. См. [Общий доступ и публикация](/docs/guides/sharing).

Новые наборы данных имеют доступ **Ограниченный**. Открыть их можете только вы и приглашённые вами люди, пока вы не измените доступ по ссылке. См. [Подготовка набора данных](/docs/guides/datasets).

## Ваши данные

Чтобы управлять своими данными, откройте вкладку **Приватность и данные** в разделе **Настройки**.

### Экспорт данных

Нажмите **Экспорт** в разделе **Экспортировать мои данные**. Экспорт содержит все данные вашего аккаунта. Выберите один формат: JSON, CSV, Excel, Pickle, Parquet или Feather.

### Удаление аккаунта

Нажмите **Удалить аккаунт**. Введите текущий пароль и адрес электронной почты для подтверждения.

> [!WARNING]
> Это действие безвозвратно удаляет ваш аккаунт и все его данные. Отменить его нельзя.

### Аналитика использования

Параметр **Отправлять анонимную аналитику использования** включает или выключает анонимную продуктовую аналитику.
