Skynet использует предоплаченный баланс. Вы пополняете баланс. У каждого запуска есть лимит расходов, и Skynet списывает с вашего баланса фактическое использование запуска. На этой странице описаны баланс, бюджеты запусков, резервирование, комиссии и собственные ключи провайдеров.

> [!NOTE]
> Числа на этой странице — текущие значения по умолчанию. Актуальные значения показывает приложение. Откройте **Настройки → Оплата**, чтобы увидеть баланс, комиссию за пополнение и историю транзакций.

## Баланс

Баланс ведётся в долларах США. Skynet хранит его в центах.

По умолчанию Skynet не начисляет бесплатный стартовый баланс. Пополните баланс перед первым платным запуском.

Баланс пополняется в разделе **Настройки → Оплата**. Можно выбрать фиксированную сумму или ввести свою:

| Пополнение            | Сумма, зачисляемая на баланс  |
| --------------------- | ----------------------------- |
| Фиксированные суммы   | $5, $20 или $50               |
| Произвольная сумма    | Любая сумма от $5 до $1 000   |

Выбранная сумма полностью зачисляется на баланс. Комиссия за пополнение добавляется сверху. См. раздел о комиссиях ниже.

**Настройки → Использование** показывает ваши расходы. История транзакций в разделе **Настройки → Оплата** содержит пополнения и списания за запуски.

## Бюджеты запусков

У каждого запуска есть лимит расходов. Лимит — это максимум, который запуск может потратить. Он покрывает настройку и оптимизацию.

До старта у запуска нет оценки стоимости. Он тратит до своего лимита, останавливается по бюджету и сохраняет лучшую версию. Как Skynet решает, когда остановиться, описано в разделе [Запуски](/docs/concepts/runs).

Лимит задаётся на экране **Бюджет** мастера отправки, в поле **Лимит расходов**:

- **Задать лимит** — режим по умолчанию. Начальный лимит — $5. Если для старта запуску нужно больше $5, начальный лимит равен этой сумме.
- **Без лимита** позволяет запуску расходовать баланс, пока он не завершится. Запуск никогда не приостанавливается. Если баланс закончится, запуск остановится и сохранит то, что успел получить.

### Сумма, необходимая для старта

Мастер показывает сумму **Нужно для старта**. Эта сумма складывается из:

- резервов для песочниц, которые запуск открывает до первого вызова модели, плюс
- запаса на первые вызовы модели. Запас равен $1 или стоимости самого дорогого одиночного вызова выбранных моделей, если она больше.

Мастер не даёт продолжить, если лимит меньше этой суммы. Он также останавливает вас, если ваш баланс меньше этой суммы. Чтобы продолжить, повысьте лимит или пополните баланс.

> [!TIP]
> Когда запуск останавливается по бюджету, нажмите **Повысить лимит и продолжить** на странице запуска. Запуск продолжится с последней контрольной точки.

## Резервирование

Перед платной работой Skynet резервирует часть лимита запуска. Когда работа рассчитана, Skynet снимает резерв и списывает только фактическую стоимость.

Если по бюджету уже были операции, карточка **Лимит расходов** в мастере показывает его учёт:

| Подпись                       | Значение                                                                          |
| ----------------------------- | --------------------------------------------------------------------------------- |
| **Осталось в этом лимите**    | Оставшаяся часть лимита.                                                          |
| **Потрачено на данный момент** | Стоимость, которая уже рассчитана.                                               |
| **Зарезервировано**           | Средства, удерживаемые под выполняемую работу. Skynet снимает резерв, когда работа рассчитана. |

## Комиссии

Помимо стоимости провайдера, Skynet взимает три вида платы.

| Плата                                   | Текущее значение по умолчанию            | К чему применяется                                         |
| --------------------------------------- | ---------------------------------------- | ---------------------------------------------------------- |
| Комиссия за пополнение                  | 12.5% от суммы плюс $0.35                | Каждое пополнение                                          |
| Наценка за использование                | Стоимость провайдера × 1.15 (плюс 15%)   | Вызовы моделей на ключах Skynet и вычисления в песочнице   |
| Комиссия платформы для собственного ключа | 5% от стоимости модели                 | Вызовы моделей на вашем собственном ключе провайдера       |

### Комиссия за пополнение

Skynet округляет процентную часть вверх до цента, а затем добавляет $0.35. Например, комиссия за пополнение на $20 составляет $2.85. Экран пополнения показывает комиссию до оплаты.

### Наценка за использование

Skynet умножает стоимость провайдера на коэффициент наценки. Наценка применяется к вызовам моделей, которые оплачивает Skynet, и к вычислениям в песочнице. Резервы, сумма, необходимая для старта, и цены моделей в приложении уже включают наценку.

Skynet определяет стоимость вызова модели у провайдера в таком порядке:

1. Стоимость, которую OpenRouter сообщает для этого вызова.
2. Актуальный прайс-лист OpenRouter для модели.
3. Таблица цен LiteLLM.
4. Высокая запасная ставка: $15 за миллион входных токенов и $75 за миллион выходных токенов. Эта ставка гарантирует, что Skynet никогда не берёт за неизвестную модель меньше её стоимости.

## Собственные ключи провайдеров (BYOK)

Вызовы моделей можно выполнять на собственном ключе провайдера. Ключи добавляются в разделе **Настройки → Провайдеры**. Для OpenRouter также можно использовать **Продолжить с OpenRouter**.

Когда вызов модели использует ваш ключ:

- Провайдер выставляет счёт за токены модели на ваш ключ.
- Skynet списывает с вашего баланса комиссию платформы — 5% от стоимости модели. Наценку за использование к этой комиссии Skynet не добавляет.
- Лимит расходов запуска покрывает только комиссию платформы и использование песочницы.

Плата внешнего оценщика или MCP-провайдера идёт напрямую этому провайдеру. Она не входит в лимит расходов запуска.

## Использование песочницы

Код запуска и метрика выполняются в песочнице. Skynet учитывает вычисления в песочнице:

1. Перед запуском песочницы Skynet резервирует сумму из лимита запуска.
2. Когда песочница завершает работу, Skynet списывает итоговое использование, которое сообщает провайдер песочницы.
3. К вычислениям в песочнице применяется наценка за использование.

Вычисления в песочнице входят в лимит расходов запуска, даже если вызовы моделей используют ваш собственный ключ.

## Тарифы

Есть два тарифа: Free и Pro. Pro повышает некоторые лимиты, например число одновременных запусков и объём хранилища. Если продление Pro не прошло, аккаунт сохраняет лимиты Pro в течение 7 дней. После этого действуют лимиты Free, пока оплата не пройдёт. См. [Лимиты](/docs/limits).

## Защитные механизмы платформы

- Для начала интерактивного хода модели, например чата с ассистентом, на балансе должно быть не меньше $0.05.
- Ассистент мастера бесплатный. Каждый аккаунт может начать 50 ходов ассистента мастера за сутки UTC.
