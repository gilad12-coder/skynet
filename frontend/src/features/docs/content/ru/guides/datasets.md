Набор данных — это таблица примеров, на которых запуск оптимизации учится и по которым оценивается. В этом руководстве показано, как загрузить файл, редактировать строки и столбцы, назначить роли столбцов и открыть общий доступ к набору данных. Основные понятия описаны в разделе [Наборы данных и разбиение](/docs/concepts/datasets).

## Поддерживаемые файлы

Skynet читает такие типы файлов:

| Расширение      | Как Skynet его читает                                                                       |
| --------------- | ------------------------------------------------------------------------------------------- |
| `.csv`          | Первая строка — строка заголовков. В файле должна быть хотя бы одна строка данных.          |
| `.json`         | Массив объектов или один объект. Ключи первого объекта становятся столбцами.                |
| `.xlsx`, `.xls` | Skynet читает только первый лист.                                                           |

Файлы с другими расширениями Skynet отклоняет с сообщением «Unsupported file format».

> [!TIP]
> Поместите ожидаемый выход в последний столбец. Мастер отправки по умолчанию отмечает последний столбец как выход.

### Пример CSV

```csv
question,answer
What is the capital of France?,Paris
How many legs does a spider have?,8
```

### Пример JSON

```json
[
  { "question": "What is the capital of France?", "answer": "Paris" },
  { "question": "How many legs does a spider have?", "answer": "8" }
]
```

## Загрузка набора данных

1. Откройте **Наборы данных**.
2. Нажмите **Загрузить набор данных** или перетащите файл на страницу. Пока вы перетаскиваете файл, на странице написано «Отпустите, чтобы загрузить».
3. Дождитесь уведомления «Набор данных сохранён в вашу библиотеку».

В качестве названия набора данных Skynet использует имя файла без расширения. Чтобы изменить его, выберите набор данных и нажмите **Переименовать**.

> [!NOTE]
> У каждого аккаунта есть квота хранилища. Если загрузка превышает квоту, Skynet открывает диалог с объяснением лимита. См. [Лимиты](/docs/limits).

Файл также можно загрузить в мастере отправки («Загрузите файл CSV, JSON или Excel») или прикрепить в [панели агента](/docs/guides/agent-panel).

## Поиск набора данных

В библиотеке перечислены ваши наборы данных. Чтобы отфильтровать список, используйте **Поиск по названию**. Наборы данных, к которым вам открыли доступ другие люди, находятся в разделе **Доступно мне**.

Когда вы выбираете один набор данных, появляются такие действия:

- **Разметить этот набор данных** открывает [разметчик](/docs/guides/tagger) с этим набором данных.
- **Изменить данные** открывает редактор набора данных.
- **Поделиться** открывает диалог общего доступа.
- **Переименовать** меняет название набора данных.

Другие действия — **Сохранить копию** и **Удалить**.

> [!WARNING]
> Удаление безвозвратно убирает набор данных из библиотеки. Отменить его нельзя. Запуски, созданные на основе набора данных, остаются действительными, но их ссылка на него перестаёт работать.

## Редактирование набора данных

Редактор показывает набор данных в виде таблицы, по 100 строк на странице. Для перехода между страницами используйте **Следующие строки** и **Предыдущие строки**.

### Изменение строк и столбцов

- **Добавить строку** и **Добавить столбец** добавляют новые ячейки в конец.
- **Вставить строку выше** и **Вставить строку ниже** добавляют строку рядом с выбранной.
- **Дублировать строку**, **Удалить строку**, **Удалить столбец** и **Переименовать столбец** меняют структуру.
- **Потяните для заполнения** копирует значение ячейки в соседние ячейки.
- **Отменить** и **Повторить** отменяют или повторяют последнее изменение.

Дважды щёлкните строку, чтобы просмотреть её полностью.

### Сохранение

Редактор сохраняет изменения автоматически, вскоре после каждой правки. Во время сохранения статус показывает **Сохранение…**. Если сохранить не удалось, статус показывает **Ошибка сохранения**.

> [!NOTE]
> Редактор не может сохранить набор данных без строк. Пока вы не добавите строку, он показывает сообщение «Добавьте строку, чтобы сохранить изменения».

Закончив, нажмите **Назад к библиотеке**.

### Доступ только для чтения

Если у вас роль «Зритель» в общем наборе данных, редактор открывается в режиме только для чтения. Чтобы изменить данные, попросите у владельца роль «Редактор» или используйте **Сохранить копию**.

### Разметка с помощью ИИ

В редакторе есть действие **Разметить с помощью ИИ**. Оно открывает разметчик, где ИИ-модель помогает добавлять метки. См. [Разметка данных в разметчике](/docs/guides/tagger).

## Назначение ролей столбцов

Запуск должен знать, какие столбцы являются входами, а какой столбец — ожидаемым выходом. Эти роли задаются при отправке запуска, а не в редакторе набора данных.

В мастере отправки на шаге «Как читать данные» для каждого столбца есть три варианта:

- **Вход**: программа получает это значение.
- **Выход**: ожидаемый ответ, с которым сравнивает оценщик.
- **Пропустить**: запуск игнорирует этот столбец.

Значения по умолчанию:

- Все столбцы — входы, а последний столбец — выход.
- В наборе данных с одним столбцом есть один вход и нет выхода.

Если столбца-выхода нет, Skynet использует первую строку как один вход. Нужно выбрать хотя бы один входной столбец.

Некоторые столбцы могут также содержать изображения. Для таких столбцов выберите **Изображение** или **Текст**, чтобы указать Skynet, как читать значения.

> [!TIP]
> Редактор набора данных показывает значок «output» на столбцах-выходах. Новый столбец, добавленный в редакторе, сначала является входом.

Мастер также делит строки на части для обучения и оценки. Сумма частей должна быть равна 1. Если это не так, мастер показывает «Сумма долей разбиения должна быть равна 1.». Полный процесс описан в разделе [Запуск через мастер](/docs/guides/submit).

## Общий доступ к набору данных

Выберите набор данных и нажмите **Поделиться**. Откроется диалог **Доступ и конфиденциальность**.

### Доступ по ссылке

| Вариант                       | Кто может открыть набор данных                                             |
| ----------------------------- | -------------------------------------------------------------------------- |
| **Ограниченный**              | Только владелец и приглашённые люди.                                       |
| **Любой, у кого есть ссылка** | Любой вошедший в систему пользователь со ссылкой, с выбранной вами ролью.  |

Для набора данных с доступом «Любой, у кого есть ссылка» выберите роль, которую даёт ссылка: **Зритель** или **Редактор**. Нажмите **Скопировать ссылку**, чтобы скопировать URL.

### Приглашение людей

1. В разделе **Пригласить людей** введите имя пользователя в поле **Добавьте людей по имени пользователя**.
2. Нажмите **Пригласить**.
3. Проверьте список в разделе **Люди с доступом**. Чтобы изменить роль человека, используйте **Изменить роль**.

Роли:

| Роль      | Доступ                                                                    |
| --------- | ------------------------------------------------------------------------- |
| Владелец  | Полный контроль, включая управление общим доступом и удаление.            |
| Редактор  | Доступ зрителя плюс запуск модели, чат и переименование.                  |
| Зритель   | Открывает набор данных. Редактор работает только для чтения.              |

### Передача владения

Чтобы отдать набор данных другому человеку, используйте **Передать владение**. Skynet попросит подтверждение.

> [!WARNING]
> После передачи вы становитесь редактором и теряете права владельца.
