Запуском можно поделиться с другими людьми и можно разместить его в публичной галерее «Обзор». Это две разные настройки. Доступ по ссылке и приглашения определяют, кто может открыть запуск. Публичная видимость определяет, показывается ли запуск в публичном поиске. В этом руководстве описаны обе настройки.

## Значения по умолчанию

| Настройка                                  | Значение по умолчанию для нового запуска                                       |
| ------------------------------------------ | ------------------------------------------------------------------------------ |
| Публичная видимость                        | **Публичная**. Запуск показывается в публичном поиске.                         |
| Доступ по ссылке                           | **Ограниченный**. Открыть запуск могут только владелец и приглашённые люди.    |
| Роль для варианта **Любой, у кого есть ссылка** | **Зритель**                                                               |

Мастер отправки показывает видимость нового запуска на последнем экране. Изменить её можно после старта запуска, в диалоге **Доступ и конфиденциальность**.

> [!WARNING]
> Новые запуски по умолчанию публичные. Если в запуске есть данные, которые не должны видеть другие пользователи, выберите **Приватная** в диалоге **Доступ и конфиденциальность**.

## Открытие настроек общего доступа

На странице запуска нажмите **Доступ и конфиденциальность**. Эту кнопку видит только владелец запуска.

## Роли

У каждого человека, который может открыть запуск, одна из трёх ролей:

| Роль         | Что может делать человек                                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| **Зритель**  | Открывать запуск и видеть его результаты и владельца. Клонировать запуск.                                                         |
| **Редактор** | Доступ зрителя плюс запуск модели, чат и переименование. Редактор также может отменять, приостанавливать, возобновлять и повторять запуск. |
| **Владелец** | Полный контроль, включая управление общим доступом и удаление.                                                                    |

У запуска ровно один владелец. Все, кто открывает общий запуск, должны войти в систему. Анонимного доступа к общему запуску нет.

## Общий доступ по ссылке

1. Откройте **Доступ и конфиденциальность**.
2. В разделе **Доступ по ссылке** выберите один из вариантов:
   - **Ограниченный**: открыть запуск могут только владелец и приглашённые люди.
   - **Любой, у кого есть ссылка**: открыть запуск может любой вошедший в систему пользователь, у которого есть ссылка.
3. Для варианта **Любой, у кого есть ссылка** выберите роль, которую даёт ссылка: **Зритель** или **Редактор**. Ссылка никогда не даёт роль **Владелец**.
4. Нажмите **Скопировать ссылку**.

Ссылка имеет вид `/share/<token>`. Токен — это часть ссылки, которую трудно угадать. Если ссылку отозвали или запуск удалили, по ссылке показывается **Доступ не найден**.

> [!NOTE]
> Секреты, такие как API-ключи и базовые URL, никогда не показываются в общем запуске.

## Приглашение людей

1. Откройте **Доступ и конфиденциальность**.
2. В разделе **Пригласить людей** введите имя пользователя. Список показывает до 10 подходящих пользователей.
3. Выберите роль: **Зритель** или **Редактор**.
4. Нажмите **Пригласить**.

В разделе **Люди с доступом** перечислены все, у кого есть роль в запуске. Для каждого человека можно:

- Изменить роль.
- Удалить доступ.

Человек сохраняет самый высокий доступ, который дают правила. Например, приглашённый редактор сохраняет роль **Редактор**, даже если ссылка даёт роль **Зритель**.

### Передача владения

Запуск можно отдать другому пользователю:

1. Откройте меню роли человека в разделе **Люди с доступом**. Также можно использовать меню роли в разделе **Пригласить людей**.
2. Выберите **Передать владение**.
3. Подтвердите передачу.

Новый владелец получает полный контроль. Вы становитесь редактором и теряете права владельца.

## Публичная видимость

Публичная видимость определяет, показывается ли запуск в публичном поиске галереи «Обзор». Она не меняет доступ по ссылке и приглашения.

| Вариант        | Значение                                                                          |
| -------------- | --------------------------------------------------------------------------------- |
| **Публичная**  | Показывается в публичном поиске. Виден всем пользователям.                        |
| **Приватная**  | Скрыт из публичного поиска. Виден только вам и приглашённым людям.                |

Изменить публичную видимость может только владелец. Изменение вступает в силу сразу.

## Галерея «Обзор»

На странице «Обзор» можно искать оптимизации. На ней три вкладки:

| Вкладка            | Что показывает                                         |
| ------------------ | ------------------------------------------------------ |
| **Мои**            | Ваши оптимизации, приватные и публичные                |
| **Публичная**      | Публичные оптимизации других пользователей             |
| **Доступно мне**   | Оптимизации, к которым вам открыли доступ другие пользователи |

Для поиска запусков используйте строку поиска и **Фильтры**.

Открыть публичный запуск из «Обзора» можно, только если он завершился со статусом `success`. Когда вы его открываете:

- Вы получаете роль **Зритель**. Вы можете читать запуск и клонировать его.
- Страница показывает владельца запуска.
- Skynet удаляет секреты, такие как API-ключи и базовые URL.
- Запустить модель нельзя. Модель расходовала бы ключ владельца.

> [!TIP]
> Чтобы дать одному человеку больше доступа к публичному запуску, пригласите его как **Редактор**.
