Страница запуска показывает прогресс и результаты запуска. В этом руководстве описаны вкладки страницы запуска, оценки, а также то, как экспортировать или развернуть лучшую версию.

## Вкладки страницы запуска

Страница запуска показывает только те вкладки, которые относятся к запуску. Некоторые вкладки зависят от пути, статуса и вашего уровня опыта.

| Вкладка                       | Когда показывается                                                     | Что содержит                                                                            |
| ----------------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **Обзор**                     | Всегда                                                                 | Прогресс, оценки и история оценок                                                       |
| **Использование**             | Успешный запуск с программой, которую Skynet может развернуть          | Форма для запуска оптимизированной программы и код интеграции                           |
| **Артефакт**                  | Запуск Промпт, Код или Текст с результатом                             | Версии вашего артефакта, включая лучшую                                                 |
| **Данные**                    | Завершённый запуск программы DSPy                                      | Данные, разделённые на обучающую, валидационную и тестовую выборки, и оценка на тестовой выборке |
| **Код**                       | Когда у запуска есть код для показа                                    | Код запуска и метрика                                                                   |
| **Награда**                   | Запуск Промпт, Код или Текст, метрика которого объявляет части награды | Части награды и их веса                                                                 |
| **Артефакт**                  | Запуск с оптимизированным промптом или файлами                         | Оптимизированный результат и **Экспортировать результаты**                              |
| **Логи**                      | Большинство запусков                                                   | Лог запуска                                                                             |
| **Использование и стоимость** | Когда вы вошли в систему                                               | Расходы запуска                                                                         |
| **Запуск по расписанию**      | Успешный запуск Промпт, Код или Текст                                  | Расписание для повторного запуска оптимизации                                           |
| **Конфигурация**              | Всегда                                                                 | Конфигурация запуска                                                                    |

> [!NOTE]
> На уровне **С подсказками** страница запуска скрывает вкладки **Данные**, **Код**, **Логи** и **Конфигурация**. Прямая ссылка на одну из этих вкладок всё равно её открывает. Уровень меняется в разделе **Настройки → Учётная запись**.

## Оценки

Skynet выбирает версии на валидационных примерах. Итоговую оценку он сообщает на тестовых примерах. Движки никогда не видят тестовые примеры. Прочитайте [Наборы данных и разбиение](/docs/concepts/datasets).

Вкладка **Обзор** показывает:

- **Улучшение**: изменение от исходной версии к лучшей.
- **Динамика оценки**: оценка на протяжении запуска.
- **Разбивка оценки**: каждая метрика со столбцами **Базовое значение**, **Оптимизировано** и **Изменение**.

Пока запуск активен, обзор также показывает **Прошло**, **Осталось** и **Скорость**.

Для запуска Промпт, Код или Текст обзор также показывает **Именованные оценки**, если ваша метрика их сообщает.

Для запуска программы DSPy на вкладке **Данные** есть раздел **Оценка на тестовой выборке**. Он показывает базовую и оптимизированную оценку для каждого тестового примера.

### Когда лучшая версия — исходная

Иногда ни один кандидат не превосходит исходную версию. Тогда Skynet возвращает исходную версию. Вкладка **Артефакт** сообщает, что сработала защита от регрессии.

Если запуск остановился по бюджету, страница запуска сообщает, какую версию сохранил Skynet. Прочитайте [Запуски](/docs/concepts/runs).

## Экспорт лучшей версии

### Запуски Промпт, Код и Текст

На вкладке **Артефакт** перечислены **Версии** вашего артефакта. Для каждой версии можно:

- Скопировать версию.
- Скачать версию в виде файла.
- Для запуска на репозитории — скачать версию в виде zip-архива всего репозитория.

Версию можно сравнить с другой версией. Вкладка также показывает **Отзыв оценщика** для версии.

### Запуски программ DSPy

На вкладке **Артефакт** есть панель **Экспортировать результаты**. Откройте меню **Скачать**. В нём показаны форматы, доступные для запуска:

| Вариант                      | Формат                                                |
| ---------------------------- | ----------------------------------------------------- |
| Программа DSPy               | `.zip`, самодостаточный экспорт, который можно запустить |
| Оптимизированная программа   | `.pkl`                                                |
| Промпт                       | `.json`                                               |
| Оптимизированный код         | `.py`                                                 |
| Логи                         | `.csv`                                                |

## Развёртывание лучшей версии

Оптимизированную программу DSPy можно вызывать из собственного кода. На вкладке **Использование** есть две части:

- Форма. Введите входные поля и нажмите **Запустить**, чтобы получить предсказание.
- **Код интеграции** на cURL, Python, JavaScript, Go и DSPy.

Программа всегда выполняется с теми настройками модели, с которыми она была оптимизирована. Нужно передать все входные поля. Лишние поля Skynet игнорирует.

Чтобы вызвать программу, создайте API-токен в разделе **Настройки → API**. Затем отправьте запрос:

```bash tab="cURL"
export APP_API_TOKEN=skyd_...
curl -X POST "$API_URL/serve/<optimization_id>" \
  -H "Authorization: Bearer $APP_API_TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"question": "What is DSPy?"}}'
```

```python tab="Python"
import os
import uuid
import requests

response = requests.post(
    f"{os.environ['API_URL']}/serve/<optimization_id>",
    headers={
        "Authorization": f"Bearer {os.environ['APP_API_TOKEN']}",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={"inputs": {"question": "What is DSPy?"}},
)
print(response.json()["outputs"])
```

Замените `question` на входные поля вашей программы. **Код интеграции** на вкладке **Использование** подставляет реальный URL и имена полей за вас.

Ответ содержит `outputs`, `input_fields`, `output_fields` и `model_used`.

> [!TIP]
> Тело запроса также принимает `max_cost_cents`. Это максимальная стоимость одного вызова в центах. Для некоторых запусков этот параметр обязателен.

Чтобы получать частичные выходы по мере их появления, отправьте тот же запрос на `/serve/<optimization_id>/stream`. Ответ приходит в виде потока server-sent events.

Аутентификация и другие эндпоинты описаны в разделе [API](/docs/api).
