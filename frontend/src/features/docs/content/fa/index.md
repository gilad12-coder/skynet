Skynet آرتیفکتی را که از قبل دارید بهتر می‌کند. شما یک نسخهٔ شروع، مجموعه‌ای از موردها و یک معیار به آن می‌دهید. Skynet نسخه‌های جدید پیشنهاد می‌کند، هر نسخه را روی موردهای شما اجرا می‌کند، خروجی را با معیار شما امتیاز می‌دهد و بهترین نسخه را نگه می‌دارد.

## Skynet چه چیزی را بهینه می‌کند

Skynet روی چهار نوع آرتیفکت کار می‌کند:

| نوع آرتیفکت  | چه چیزی تغییر می‌کند                                  |
| ------------ | ---------------------------------------------------- |
| پرامپت       | متن پرامپت                                           |
| کد           | کد منبع                                              |
| برنامهٔ DSPy | دستورالعمل‌های پیش‌بینی‌کننده‌ها در یک `dspy.Module` |
| متن          | هر متن دیگر، برای مثال یک سند یا یک پیکربندی         |

همهٔ اجراها از یک قرارداد استفاده می‌کنند. کد اجرای شما `run(artifact, input)` را تعریف می‌کند. معیار شما `score(input, output, expected=None)` را تعریف می‌کند. معیار یک امتیاز و یک بازخورد نوشتاری برمی‌گرداند. بهینه‌ساز بازخورد را می‌خواند تا نسخهٔ بعدی را بهتر کند.

> [!NOTE]
> کد اجرا و معیار شما در یک محیط اجرای ایزوله (sandbox) و در فرایندهای جداگانه اجرا می‌شوند. کد اجرا نمی‌تواند کد منبع معیار یا مقدارهای مورد انتظار را ببیند.

## یک محصول، موتورهای متعدد

Skynet همان Optimize Anything است. نوع آرتیفکت تعیین می‌کند کدام موتورها می‌توانند روی آن کار کنند:

- آرتیفکت‌های پرامپت، کد و متن از موتورهای بومی استفاده می‌کنند: GEPA، Best-of-N، Meta-Harness، AutoResearch، AutoSaddler و ShinkaEvolve.
- آرتیفکت‌های برنامهٔ DSPy از بهینه‌سازهای DSPy استفاده می‌کنند: DSPy GEPA، DSPy MIPROv2 و DSPy BootstrapFewShot.

**Auto** به جای شما انتخاب می‌کند. روی یک برنامهٔ DSPy، Auto از DSPy GEPA استفاده می‌کند. روی انواع دیگر آرتیفکت، Auto پنج موتور بومی را با هم ترکیب می‌کند. [بهینه‌سازی چگونه کار می‌کند](/docs/concepts/optimization) و [موتورها](/docs/concepts/engines) را بخوانید.

## یک اجرا چگونه کار می‌کند

1. کار را توصیف می‌کنید و نسخهٔ شروع را تعیین می‌کنید.
2. موردها را می‌دهید. Skynet آن‌ها را به مجموعه‌های آموزش، اعتبارسنجی و آزمون تقسیم می‌کند.
3. یک بهینه‌ساز، مدل‌ها و یک بودجه انتخاب می‌کنید.
4. کد اجرا و معیار را می‌نویسید. یک بررسی قرارداد آن‌ها را روی چند مورد نمونه اجرا می‌کند.
5. Skynet بهینه‌سازی را اجرا می‌کند و نتیجه‌ها را نشان می‌دهد.

Skynet نسخه‌ها را بر اساس موردهای اعتبارسنجی انتخاب می‌کند. امتیاز نهایی را روی موردهای آزمون گزارش می‌دهد. موتورها هرگز موردهای آزمون را نمی‌بینند.
