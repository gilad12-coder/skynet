صفحهٔ اجرا پیشرفت و نتایج یک اجرا را نشان می‌دهد. این راهنما زبانه‌های صفحهٔ اجرا، امتیازها و روش خروجی گرفتن از بهترین نسخه یا ارائهٔ آن را توضیح می‌دهد.

## زبانه‌های صفحهٔ اجرا

صفحهٔ اجرا فقط زبانه‌هایی را نشان می‌دهد که به آن اجرا مربوط هستند. برخی زبانه‌ها به مسیر، وضعیت و سطح تجربهٔ شما بستگی دارند.

| زبانه                 | چه زمانی نمایش داده می‌شود                                          | محتوای آن                                                                       |
| --------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **نمای کلی**          | همیشه                                                               | پیشرفت، امتیازها و تاریخچهٔ امتیاز                                               |
| **کاربرد**            | اجرای موفق با برنامه‌ای که Skynet می‌تواند ارائه کند                 | فرمی برای اجرای برنامهٔ بهینه‌شده، و کد یکپارچه‌سازی                             |
| **آرتیفکت**           | اجرای پرامپت، کد یا متن که نتیجه دارد                                | نسخه‌های آرتیفکت شما، همراه با بهترین نسخه                                      |
| **داده‌ها**           | اجرای تمام‌شدهٔ برنامهٔ DSPy                                         | تقسیم داده به مجموعه‌های آموزش، اعتبارسنجی و آزمون، و ارزیابی مجموعهٔ آزمون      |
| **کد**                | وقتی اجرا کدی برای نمایش دارد                                       | کد اجرا و معیار                                                                 |
| **پاداش**             | اجرای پرامپت، کد یا متن که معیار آن بخش‌های پاداش را اعلام می‌کند     | بخش‌های پاداش و وزن‌های آن‌ها                                                    |
| **آرتیفکت**           | اجرایی با پرامپت یا فایل‌های بهینه‌شده                               | خروجی بهینه‌شده و **خروجی گرفتن از نتایج**                                      |
| **لاگ‌ها**            | بیشتر اجراها                                                        | لاگ اجرا                                                                        |
| **مصرف و هزینه**      | وقتی وارد حساب شده‌اید                                              | آنچه اجرا خرج کرد                                                               |
| **اجرای زمان‌بندی‌شده** | اجرای موفق پرامپت، کد یا متن                                       | زمان‌بندی برای اجرای دوبارهٔ بهینه‌سازی                                          |
| **پیکربندی**          | همیشه                                                               | پیکربندی اجرا                                                                   |

> [!NOTE]
> در سطح **راهنمایی‌شده**، صفحهٔ اجرا زبانه‌های **داده‌ها**، **کد**، **لاگ‌ها** و **پیکربندی** را پنهان می‌کند. پیوند مستقیم به یکی از این زبانه‌ها همچنان آن را باز می‌کند. سطح را در **تنظیمات ← حساب** تغییر دهید.

## امتیازها

Skynet نسخه‌ها را روی نمونه‌های اعتبارسنجی انتخاب می‌کند. امتیاز نهایی را روی نمونه‌های آزمون گزارش می‌دهد. موتورها هرگز نمونه‌های آزمون را نمی‌بینند. صفحهٔ [مجموعه‌داده‌ها و تقسیم](/docs/concepts/datasets) را بخوانید.

زبانهٔ **نمای کلی** این موارد را نشان می‌دهد:

- **بهبود**: تغییر از نسخهٔ شروع تا بهترین نسخه.
- **روند پیشرفت امتیاز**: امتیاز در طول اجرا.
- **تفکیک امتیاز**: هر معیار، با ستون‌های **خط مبنا**، **بهینه‌شده** و **تغییر**.

تا وقتی اجرا فعال است، نمای کلی **زمان سپری‌شده**، **باقی‌مانده** و **نرخ** را هم نشان می‌دهد.

برای اجرای پرامپت، کد یا متن، وقتی معیار شما امتیازهای نام‌دار گزارش می‌دهد، نمای کلی **امتیازهای نام‌دار** را هم نشان می‌دهد.

برای اجرای برنامهٔ DSPy، زبانهٔ **داده‌ها** یک **ارزیابی مجموعه‌ی آزمون** دارد. این بخش امتیاز خط مبنا و امتیاز بهینه‌شده را برای هر نمونهٔ آزمون نشان می‌دهد.

### وقتی بهترین نسخه همان نسخهٔ شروع است

گاهی هیچ نامزدی از نسخهٔ شروع بهتر نمی‌شود. در این حالت Skynet نسخهٔ شروع را برمی‌گرداند. زبانهٔ **آرتیفکت** به شما می‌گوید که یک محافظ پسرفت اعمال شد.

اگر اجرا با رسیدن به بودجه‌اش متوقف شد، صفحهٔ اجرا به شما می‌گوید Skynet کدام نسخه را ذخیره کرد. صفحهٔ [اجراها](/docs/concepts/runs) را بخوانید.

## خروجی گرفتن از بهترین نسخه

### اجراهای پرامپت، کد و متن

زبانهٔ **آرتیفکت** **نسخه‌ها**ی آرتیفکت شما را فهرست می‌کند. برای هر نسخه می‌توانید:

- نسخه را کپی کنید.
- نسخه را به‌صورت فایل دانلود کنید.
- برای اجرای مخزن، نسخه را به‌صورت یک فایل zip از کل مخزن دانلود کنید.

می‌توانید یک نسخه را با نسخهٔ دیگری مقایسه کنید. این زبانه **بازخورد ارزیاب** را هم برای هر نسخه نشان می‌دهد.

### اجراهای برنامهٔ DSPy

زبانهٔ **آرتیفکت** یک پنل **خروجی گرفتن از نتایج** دارد. منوی **دانلود** را باز کنید. این منو قالب‌هایی را که اجرا دارد نشان می‌دهد:

| گزینه                 | قالب                                                   |
| --------------------- | ------------------------------------------------------ |
| برنامهٔ DSPy          | `.zip`، یک خروجی مستقل که می‌توانید آن را اجرا کنید     |
| برنامه‌ی بهینه‌شده     | `.pkl`                                                 |
| پرامپت                | `.json`                                                |
| کد بهینه‌شده          | `.py`                                                  |
| لاگ‌ها                | `.csv`                                                 |

## ارائهٔ بهترین نسخه

می‌توانید یک برنامهٔ DSPy بهینه‌شده را از کد خودتان فراخوانی کنید. زبانهٔ **کاربرد** دو بخش دارد:

- یک فرم. فیلدهای ورودی را وارد کنید و برای دریافت پیش‌بینی، **اجرا** را انتخاب کنید.
- **کد یکپارچه‌سازی** به زبان‌های cURL، Python، JavaScript، Go و DSPy.

برنامه همیشه با تنظیمات مدلی اجرا می‌شود که با آن بهینه شده است. باید همهٔ فیلدهای ورودی را بدهید. Skynet فیلدهای اضافی را نادیده می‌گیرد.

برای فراخوانی برنامه، یک توکن API در **تنظیمات ← API** بسازید. سپس یک درخواست بفرستید:

```bash tab="cURL"
export APP_API_TOKEN=skyd_...
curl -X POST "$API_URL/serve/<optimization_id>" \
  -H "Authorization: Bearer $APP_API_TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"question": "What is DSPy?"}}'
```

```python tab="Python"
import os
import uuid
import requests

response = requests.post(
    f"{os.environ['API_URL']}/serve/<optimization_id>",
    headers={
        "Authorization": f"Bearer {os.environ['APP_API_TOKEN']}",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={"inputs": {"question": "What is DSPy?"}},
)
print(response.json()["outputs"])
```

`question` را با فیلدهای ورودی برنامهٔ خود جایگزین کنید. **کد یکپارچه‌سازی** در زبانهٔ **کاربرد**، URL واقعی و نام فیلدها را برای شما پر می‌کند.

پاسخ شامل `outputs`، `input_fields`، `output_fields` و `model_used` است.

> [!TIP]
> بدنهٔ درخواست `max_cost_cents` را هم می‌پذیرد. این مقدار بیشترین هزینهٔ همین یک فراخوانی را به سنت تعیین می‌کند. برخی اجراها به آن نیاز دارند.

برای دریافت خروجی‌های جزئی هم‌زمان با رسیدنشان، همان درخواست را به `/serve/<optimization_id>/stream` بفرستید. پاسخ یک جریان از server-sent events است.

برای احراز هویت و endpointهای دیگر، صفحهٔ [API](/docs/api) را بخوانید.
