Skynet برای اجراها، فایل‌ها، فضای ذخیره‌سازی و نرخ درخواست‌ها محدودیت تعیین می‌کند. این محدودیت‌ها پلتفرم را پایدار نگه می‌دارند و از موجودی شما محافظت می‌کنند. این صفحه مقدارهای پیش‌فرض را فهرست می‌کند. یک مدیر سیستم می‌تواند برخی محدودیت‌ها را برای یک حساب تغییر دهد.

> [!NOTE]
> مقدارهای این صفحه پیش‌فرض‌های فعلی هستند. وقتی به یک محدودیت می‌رسید، اپلیکیشن یا API به شما می‌گوید کدام محدودیت درخواست را متوقف کرد.

## اجراها

| محدودیت                     | Free | Pro   |
| --------------------------- | ---- | ----- |
| اجراهای فعال هم‌زمان        | ۵    | ۲۰    |
| اجراهای ذخیره‌شده           | ۱۰۰  | ۱٬۰۰۰ |

اجرای فعال اجرایی است با وضعیت `pending`، `validating`، `running` یا `paused`. وقتی به حداکثر تعداد اجراهای فعال رسیده باشید، Skynet اجراهای جدید را تا پایان یکی از آن‌ها نمی‌پذیرد.

محدودیت اجراهای ذخیره‌شده همهٔ اجراهای شما را می‌شمارد. برای باز کردن جا برای اجراهای جدید، اجراهایی را که لازم ندارید حذف کنید.

اگر تمدید Pro ناموفق باشد، حساب تا ۷ روز محدودیت‌های Pro را نگه می‌دارد. پس از آن، تا موفق شدن پرداخت از محدودیت‌های Free استفاده می‌کند.

| محدودیت                                  | مقدار                                                           |
| ---------------------------------------- | -------------------------------------------------------------- |
| تعداد نسخه‌ها در یک درخواست کلون API     | ۱ تا ۵                                                          |
| تلاش‌های بازیابی خودکار برای یک اجرا     | ۳                                                               |
| موردهای نمونه در بررسی قرارداد           | ۳                                                               |
| رویدادهای پیشرفت ذخیره‌شده برای هر اجرا  | ۵٬۰۰۰. Skynet قدیمی‌ترین رویدادها را اول حذف می‌کند.             |
| طول عمر یک محیط اجرا                     | ۴۵ دقیقه. اجرایی که زمان بیشتری لازم دارد یک محیط اجرای جدید باز می‌کند. |

برای اینکه بدانید تلاش‌های بازیابی چگونه کار می‌کنند، [اجراها](/docs/concepts/runs) را بخوانید.

## فضای ذخیره‌سازی

| محدودیت               | Free    | Pro    |
| --------------------- | ------- | ------ |
| کل فضای ذخیره‌سازی    | 250 MiB | 10 GiB |

کل فضای ذخیره‌سازی شامل اجراها، مجموعه‌داده‌ها، لاگ‌ها، گفتگوهای عامل، بارگذاری‌های موقت و داده‌های جستجوی شماست. Skynet نوشتنی را که از محدودیت فضای ذخیره‌سازی شما فراتر برود نمی‌پذیرد.

## فایل‌ها و مجموعه‌داده‌ها

| محدودیت                                         | مقدار                                  |
| ----------------------------------------------- | ------------------------------------- |
| فایل مجموعه‌دادهٔ ذخیره‌شده در کتابخانهٔ شما     | 50 MiB برای هر فایل، پس از فشرده‌سازی |
| ردیف‌ها از یک اتصال‌دهنده که رکورد وارد می‌کند   | ۲۰٬۰۰۰                                |
| فایل پیوست‌شده به گفتگوی عامل                   | 20 MiB                                |
| متن خوانده‌شده از یک پیوست گفتگو                | ۵۰٬۰۰۰ نویسه                          |
| کلیپ صوتی برای دیکته                            | 25 MB                                 |
| آرشیو مخزن GitHub                               | 200 MiB، فشرده                        |
| فایل مخزن که در صفحهٔ اجرا باز می‌شود           | 1 MiB                                 |

اتصال‌دهنده‌هایی که رکورد وارد می‌کنند شامل جدول‌های پایگاه داده، ردگیری‌های LLM و پایگاه‌های داده Notion هستند. [آماده‌سازی مجموعه‌داده](/docs/guides/datasets) را بخوانید.

### فایل‌های فضای کار در ویزارد

| محدودیت                       | مقدار                                                                   |
| ----------------------------- | ----------------------------------------------------------------------- |
| فایل‌های اضافی در فضای کار    | ۲۰                                                                      |
| طول نام فایل                  | ۱۲۰ نویسه                                                               |
| عمق پوشه                      | ۳ پوشه                                                                  |
| نوع فایل                      | `.py`، `.txt`، `.md`، `.json`، `.yaml`، `.csv`، `.toml`، `.ini`، `.cfg` |

`run.py` و `metric.py` فایل‌های ورودی یک اجرا هستند. نمی‌توانید آن‌ها را حذف کنید، تغییر نام دهید یا جابه‌جا کنید.

## نرخ درخواست‌ها

| محدودیت                                                            | مقدار                                      |
| ------------------------------------------------------------------ | ----------------------------------------- |
| ارسال اجرا                                                         | ۳۰ برای هر حساب در یک دقیقهٔ غلتان         |
| کلیپ‌های دیکته                                                     | ۱۲۰ برای هر حساب در یک ساعت               |
| فایل‌های خوانده‌شده برای گفتگوهای عامل                             | ۳۰۰ برای هر حساب در یک ساعت               |
| درخواست‌های حساب (ثبت‌نام، بازنشانی رمز عبور، تأیید ایمیل)         | ۲۰ برای هر نشانی ایمیل در یک ساعت غلتان    |
| نوبت‌های دستیار ویزارد                                             | ۵۰ برای هر حساب در یک روز UTC              |
| توکن‌های جستجو و نمایه‌سازی                                         | ۲٬۰۰۰٬۰۰۰ برای هر حساب در یک ماه           |

وقتی از یک محدودیت نرخ فراتر بروید، API وضعیت HTTP `429` را برمی‌گرداند. صبر کنید، سپس درخواست را دوباره بفرستید.

وقتی یک حساب از توکن‌های ماهانهٔ جستجو و نمایه‌سازی خود فراتر برود، Skynet نمایه‌سازی موارد جدید را برای آن حساب متوقف می‌کند. جستجو پس از آن طوری کار می‌کند که انگار جستجوی معنایی در دسترس نیست.
