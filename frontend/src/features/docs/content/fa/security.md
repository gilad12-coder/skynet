این صفحه توضیح می‌دهد Skynet چگونه از حساب، کلیدها و داده‌های شما محافظت می‌کند. همچنین می‌گوید یک مشکل امنیتی را چگونه گزارش کنید.

## گزارش آسیب‌پذیری

مشکلات امنیتی را به‌صورت خصوصی گزارش کنید. یک issue عمومی باز نکنید.

- در GitHub، مخزن Skynet را باز کنید و به **Security** > **Report a vulnerability** بروید.
- یا یک ایمیل به `security@skynetml.com` بفرستید.

هدف تیم این است که دریافت هر گزارش را ظرف پنج روز کاری تأیید کند.

## حساب شما

### روش‌های ورود

می‌توانید با این روش‌ها وارد شوید:

- یک نشانی ایمیل و یک رمز عبور.
- **ادامه با Google** یا **ادامه با GitHub**.
- **ورود با کلید عبور**. کلید عبور از Face ID، Touch ID یا یک کلید سخت‌افزاری استفاده می‌کند.

ارائه‌دهندگانی را که استفاده می‌کنید می‌توانید زیر **حساب‌های متصل** مدیریت کنید.

### قاعده‌های رمز عبور

رمز عبور باید:

- دست‌کم ۸ نویسه داشته باشد.
- حداکثر ۱۲۸ نویسه داشته باشد.
- نشانی ایمیل شما را در خود نداشته باشد.

یک حساب جدید باید نشانی ایمیل خود را با یک کد تأیید کند. بازنشانی رمز عبور هم از کدی استفاده می‌کند که Skynet با ایمیل می‌فرستد.

Skynet پس از چند تلاش ناموفق پشت سر هم، ورود را برای آن نشانی ایمیل برای مدتی قفل می‌کند.

### تأیید دومرحله‌ای

برای محافظت بیشتر، تأیید دومرحله‌ای را روشن کنید. یکی از این روش‌ها را انتخاب کنید:

| روش                     | چگونه کار می‌کند                                         |
| ----------------------- | ------------------------------------------------------- |
| **برنامه احراز هویت**   | یک کد ۶ رقمی از برنامهٔ احراز هویت خود وارد کنید.       |
| **کدهای ایمیلی**        | کد ۶ رقمی‌ای را که Skynet در هر ورود می‌فرستد وارد کنید. |

Skynet به شما کدهای بازیابی هم می‌دهد. آن‌ها را در جای امنی نگه دارید. اگر دسترسی به روش خود را از دست دادید، از یکی از آن‌ها استفاده کنید.

> [!NOTE]
> اگر با Google یا GitHub وارد می‌شوید، همان ارائه‌دهنده تأیید دومرحله‌ای شما را مدیریت می‌کند.

## کد شما کجا اجرا می‌شود

بارهای کاری کاربران در محیط‌های اجرای ایزوله (sandbox) اجرا می‌شوند. در محصول میزبانی‌شده، Vercel Sandbox مرز اجراست. این شامل بررسی‌های تنظیمات، اجراهای بهینه‌سازی، بازیابی و کار روی اجراهای تمام‌شده است.

کارگرهای (workers) Skynet کد شما را اجرا نمی‌کنند. آن‌ها لایهٔ کنترل هستند. کارها را شروع می‌کنند، بودجه‌ها را رزرو و تسویه می‌کنند، اعتبارنامه‌های محدود به محیط‌های اجرا می‌دهند و نقطه‌های بازیابی (checkpoint) را ذخیره می‌کنند.

پیش از اینکه Skynet کار پولی را شروع کند، فضای کافی را در کیف پول شما و در بودجهٔ اجرا رزرو می‌کند. [صورت‌حساب](/docs/concepts/billing) را ببینید.

در [اپلیکیشن Mac](/docs/guides/mac-app)، کارها در کانتینرهای محلی Docker اجرا می‌شوند. همهٔ سرویس‌های محلی فقط روی `127.0.0.1` گوش می‌دهند.

## کلیدهای ارائه‌دهنده (BYOK)

می‌توانید کلیدهای ارائه‌دهندهٔ مدل خود را اضافه کنید.

- Skynet هر کلید را در حالت ذخیره رمزنگاری می‌کند.
- Skynet هرگز کلید کامل را از طریق API برنمی‌گرداند.
- Skynet فقط چهار نویسهٔ آخر و یک وضعیت را نگه می‌دارد: تأییدنشده، تأییدشده یا نامعتبر.
- وقتی کلیدی وارد می‌کنید، Skynet برای بررسی آن یک درخواست آزمایشی کوچک می‌فرستد.

وقتی از کلید خود استفاده می‌کنید، ارائه‌دهنده هزینه را مستقیماً از کلید شما دریافت می‌کند. Skynet همچنان کارمزد پلتفرم و مصرف محیط اجرا را از موجودی شما کم می‌کند.

Skynet همچنین اطلاعات محرمانه را از لاگ‌ها و پیام‌های خطا حذف می‌کند. آن‌ها را با `[REDACTED]` جایگزین می‌کند.

## توکن‌های API

توکن‌های API به اسکریپت‌ها و ابزارها اجازه می‌دهند API در Skynet را فراخوانی کنند.

- هر کاربر حداکثر یک توکن معتبر دارد. وقتی توکن جدیدی تولید می‌کنید، توکن قبلی از کار می‌افتد.
- توکن‌ها با `skyd_` شروع می‌شوند.
- Skynet فقط یک هش از توکن را ذخیره می‌کند.
- Skynet توکن کامل را فقط یک بار نشان می‌دهد. توکن را فوراً کپی و ذخیره کنید.
- پس از آن، Skynet فقط شکل پوشیده‌شده را نشان می‌دهد: `skyd_…` و چهار نویسهٔ آخر.

توکن را در سرآیند `Authorization` بفرستید:

```http
Authorization: Bearer skyd_...
```

برای از کار انداختن یک توکن، روی **ابطال توکن** کلیک کنید. برای API کامل، [API](/docs/api) را بخوانید.

> [!WARNING]
> با توکن مثل یک رمز عبور رفتار کنید. هر کسی که توکن را داشته باشد می‌تواند از طریق API به جای شما عمل کند. آن را در مخزن commit نکنید.

## حریم خصوصی داده در مدل‌ها

تنظیم **حریم خصوصی داده در مدل‌ها** تعیین می‌کند ارائه‌دهندگان مدل با داده‌های شما چه کاری می‌توانند بکنند. این تنظیم برای بهینه‌سازی‌هایی اعمال می‌شود که Skynet هزینه‌شان را از موجودی شما کم می‌کند.

| گزینه              | اثر                                                                                       |
| ------------------ | ----------------------------------------------------------------------------------------- |
| **اجازه به همه**   | هر ارائه‌دهنده‌ای، از جمله ارائه‌دهندگانی که می‌توانند روی پرامپت‌های شما آموزش دهند یا آن‌ها را ذخیره کنند. |
| **بدون آموزش**     | فقط ارائه‌دهندگانی که روی پرامپت‌های شما آموزش نمی‌دهند و آن‌ها را نگه نمی‌دارند. این گزینهٔ پیش‌فرض است. |
| **بدون نگهداری**   | فقط نقطه‌های پایانی‌ای که توافق‌نامهٔ عدم نگهداری داده (zero data retention) دارند. ممکن است برخی مدل‌ها در دسترس نباشند. |

> [!NOTE]
> بهینه‌سازی‌هایی که با کلید خود شما انجام می‌شوند از تنظیمات حریم خصوصی حساب OpenRouter شما پیروی می‌کنند.

## نمایان‌بودن اجراها

> [!WARNING]
> اجراهای جدید به‌طور پیش‌فرض **عمومی** هستند. یک اجرای عمومی در جستجوی عمومی دیده می‌شود. هر کسی می‌تواند آن را پیدا کند و نتیجه‌هایش را مرور کند.

برای اینکه اجرا در جستجوی عمومی دیده نشود، هنگام ارسال آن **نمایان‌بودن** را روی **خصوصی** بگذارید. بعداً می‌توانید نمایان‌بودن را در پنجرهٔ اشتراک‌گذاری تغییر دهید. [اشتراک‌گذاری](/docs/guides/sharing) را ببینید.

مجموعه‌داده‌های جدید **محدود** هستند. فقط شما و افرادی که دعوت می‌کنید می‌توانند آن‌ها را باز کنند، تا وقتی دسترسی با پیوند را تغییر دهید. [آماده‌سازی مجموعه‌داده](/docs/guides/datasets) را ببینید.

## داده‌های شما

برای مدیریت داده‌های خود، زبانهٔ **حریم خصوصی و داده‌ها** را در **تنظیمات** باز کنید.

### برون‌بری داده‌ها

زیر **برون‌بری داده‌های من**، روی **برون‌بری** کلیک کنید. فایل برون‌بری همهٔ داده‌های حساب شما را در بر دارد. یکی از این قالب‌ها را انتخاب کنید: JSON، CSV، Excel، Pickle، Parquet یا Feather.

### حذف حساب

روی **حذف حساب کاربری** کلیک کنید. برای تأیید، رمز عبور فعلی خود را وارد کنید و نشانی ایمیل خود را تایپ کنید.

> [!WARNING]
> این کار حساب شما و همهٔ داده‌هایش را برای همیشه حذف می‌کند. نمی‌توانید آن را برگردانید.

### آمار استفاده

تنظیم **ارسال آمار استفادهٔ ناشناس** آمار ناشناس محصول را روشن یا خاموش می‌کند.
