タガーは、データセットの行にラベルを付けます。すべての行に自分でラベルを付けることも、AI モデルに行のラベル付けを任せてその作業をレビューすることもできます。結果として、実行で使えるラベル付きのデータセットが得られます。

## セッションを開始する

次のいずれかの方法でタガーを開きます。

- ダッシュボードからタガーを開く。
- **データセット** でデータセットを 1 つ選択し、**このデータセットをタグ付け** をクリックする。
- データセットエディターで **AIでタグ付け** をクリックする。

### データを選ぶ

セットアップでは、ラベルを付けるデータを尋ねられます。

- **ライブラリから選択** は、アップロード済みのデータセットを使います。新しいファイルをアップロードするには、先に [データセット](/docs/guides/datasets) を使ってください。
- **合成データセットを生成** は、行を作成します。このオプションにはアシスタントが必要です。

### タスクの種類を選ぶ

| タスクの種類               | 各行に付けるもの                                                                         |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| **はい／いいえの質問**     | はい、またはいいえの回答。                                                               |
| **カテゴリから選択**       | 自分で定義したリストから 1 つ以上のカテゴリ。少なくとも 2 つのカテゴリを追加します。     |
| **記述式の回答**           | 自由記述の回答。                                                                         |

### モードを選ぶ

セットアップでは「どのようにタグ付けしますか？」と尋ねられます。モードは 3 つあります。

| モード        | 動作                                                                                                             |
| ------------- | ---------------------------------------------------------------------------------------------------------------- |
| **手動**      | すべての行に自分でラベルを付けます。AI は関与しません。                                                          |
| **コパイロット** (Co-pilot) | 短いインタビューの後、AI が最初のバッチにタグを付けます。レビューラウンドで、各ラベルを残すか修正します。       |
| **オートパイロット** (Autopilot) | 短いインタビューの後、AI がすべての行にタグを付け、確信が持てない行にフラグを立てます。                          |

セットアップでは、1 つのモードに **推奨** の印が付きます。

セットアップには **タグ付けモデル** の選択もあります。既定値はほとんどのデータセットに適しています。

> [!NOTE]
> Mac アプリでは、AI によるタグ付けに独自のプロバイダーキーが必要です。**自分のキー** でモデルを選んでください。[Mac アプリ](/docs/guides/mac-app) をご覧ください。

## データセットインタビュー

コパイロットとオートパイロットは、**データセットインタビュー** から始まります。AI がデータとラベルについて質問します。**インタビューをスキップ** をクリックすることもできます。

インタビューによって **ラベル付けガイド** が作られます。ガイドには、AI が従うルールが含まれます。独自のルールを追加するには、**ルールを追加** を使います。

最後に、AI が **これがプランです** を表示します。その後、作業を開始します。

- コパイロットでは、**確認用に最初の {rows} 行をタグ付け** をクリックします。
- オートパイロットでは、**{rows} 行すべてをタグ付け** をクリックします。

## コパイロットのレビューラウンド

コパイロットでは、AI がまずキャリブレーション用のバッチにタグを付けます。バッチのサイズはタスクの種類によって異なります。

| タスクの種類         | 最初のバッチ                                        |
| -------------------- | --------------------------------------------------- |
| はい／いいえの質問   | 24 行                                               |
| カテゴリから選択     | カテゴリごとに 6 行（最小 30 行、最大 60 行）       |
| 記述式の回答         | 30 行                                               |

データセットの行がそれより少ない場合、AI はすべての行にタグを付けます。

### 各ラベルをレビューする

各行について、サイドレールに AI のラベルが表示されます。

1. 行とラベルを読みます。
2. ラベルを残すには、**確定（Enter）** をクリックするか、Enter キーを押します。
3. ラベルを変更するには、修正します。レールに「修正しました。AIはこれから学習します」と表示されます。
4. 終わったら、**このラウンドを終了** をクリックします。

レールには目標が表示されます: 「意見が {gate}% 一致するようになったら、残りは私がタグ付けします。」

### 一致率のゲート

各ラウンドの後、Skynet はあなたが AI とどのくらいの頻度で一致したかを測定します。ゲートは、はい／いいえとカテゴリのタスクでは 92%、記述式の回答では 85% です。

ラウンドのサマリーには「このバッチでAIと {agreement}% 一致しました」と表示されます。その後、次のいずれかを選びます。

- **もう1回レビューラウンド** は、レビューする別のバッチを表示します。
- **残りの {rows} 行をタグ付け** は、残りを AI にタグ付けさせます。

## オートパイロットと自動タグ付け

AI が残りの行にタグを付けるとき、作業はサーバー上で実行されます。ページを離れて、後で戻ってきても問題ありません。

- **タグ付けを再開** は、停止したジョブを続行します。
- **キャンセル — タグ済みは保持** は、ジョブを停止し、既存のラベルを保持します。

### 確信の低い行をレビューする

AI は、自動で付けた各ラベルに信頼度を付けます。信頼度が 0.75 未満の場合、Skynet はその行にフラグを立てます。ジョブの完了後、**AIが確信を持てなかった {count} 行を確認** をクリックして、それらを確認します。

> [!TIP]
> データを実行で使う前に、フラグが立った行をレビューしてください。誤ったラベルは最適化の品質を下げます。

## 手動モード

手動モードでは、すべての行に自分でラベルを付けます。以下のキーボードショートカットを使うと、素早く作業できます。

### キーボードショートカット

| キー                     | 操作                                                     |
| ------------------------ | -------------------------------------------------------- |
| Ctrl+H または Cmd+H      | ショートカットを表示します。                             |
| Y / N                    | はい／いいえの行で、はい、またはいいえと回答します。     |
| 1〜9                     | カテゴリの行で、そのカテゴリを選択または解除します。     |
| U                        | 次の未タグ付けの行に移動します。                         |
| Home                     | 最初の行に移動します。                                   |
| E                        | CSV としてエクスポートします。                           |

## 結果

結果には、各ラベルの出どころが表示されます。

| 件数                       | 意味                                         |
| -------------------------- | -------------------------------------------- |
| **手動でラベル付け**       | あなたが書いたラベル。                       |
| **確認済みのAIラベル**     | レビューで残した AI のラベル。               |
| **自動でラベル付け**       | レビューされていない AI のラベル。           |
| **コスト**                 | このセッションでの AI の作業のコスト。       |

**ソース** 列には、各行について同じ値（**あなた**、**AI 確認済み**、**AI**）が表示されます。

## 保存とエクスポート

### ライブラリに保存する

ラベル付きのデータをデータセットとして残すには、**ライブラリに保存** または **データセットに移動** をクリックします。その後、[実行](/docs/guides/submit) で使えます。

### ファイルをエクスポートする

**タグをエクスポート** をクリックし、形式を選びます。

- CSV
- JSON
- Excel (`.xlsx`)
- Parquet
- Feather

ラベルのない行がある場合、Skynet はエクスポートの確認を求めます。

エクスポートではラベル列が追加されます。列の名前はタスクの種類によって異なります。

| タスクの種類         | 列                    |
| -------------------- | --------------------- |
| はい／いいえの質問   | `binary_label`        |
| カテゴリから選択     | `selected_categories` |
| 記述式の回答         | `extracted_text`      |

`label_source` 列には、各ラベルの出どころが記録されます。

## セッション

各タグ付けジョブはセッションです。セッションは、**進行中**、**レビュー中**、**自動ラベル付け**、**完了** のいずれかのステータスを持ちます。新しい設定でやり直すには、**新しいセッションを開始** をクリックします。

セッションは、共有ダイアログから他の人と共有できます。共有のルールについては、[共有と公開](/docs/guides/sharing) をご覧ください。
