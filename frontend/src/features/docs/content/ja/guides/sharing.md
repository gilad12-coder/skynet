実行を他の人と共有したり、公開の探索ギャラリーに掲載したりできます。これらは 2 つの別々の設定です。リンクのアクセス権と招待は、誰が実行を開けるかを制御します。公開設定は、実行が公開検索に表示されるかどうかを制御します。このガイドでは、両方を説明します。

## 既定値

| 設定                                       | 新しい実行の既定値                                                         |
| ------------------------------------------ | -------------------------------------------------------------------------- |
| 公開設定                                   | **公開**。実行は公開検索に掲載されます。                                   |
| リンクのアクセス権                         | **制限付き**。実行を開けるのは、オーナーと招待された人だけです。           |
| **リンクを知っている全員** のロール        | **閲覧者**                                                                 |

送信ウィザードは、新しい実行の公開範囲を最後の画面に表示します。実行の開始後に、**共有とプライバシー** ダイアログで変更できます。

> [!WARNING]
> 新しい実行は既定で公開です。他のユーザーに見せてはいけないデータが実行に含まれる場合は、**共有とプライバシー** ダイアログで **非公開** に設定してください。

## 共有設定を開く

実行ページで **共有とプライバシー** を選択します。このボタンは、実行のオーナーにだけ表示されます。

## ロール

実行を開ける各人は、次の 3 つのロールのいずれかを持ちます。

| ロール       | できること                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| **閲覧者**   | 実行を開き、その結果とオーナーを見る。実行をクローンする。                                                         |
| **編集者**   | 閲覧者のアクセスに加え、モデルの実行、チャット、名前の変更。実行のキャンセル、一時停止、再開、再試行もできます。   |
| **オーナー** | 共有と削除の管理を含む、すべての操作。                                                                             |

実行のオーナーはちょうど 1 人です。共有された実行を開く人は全員、サインインする必要があります。共有された実行に匿名でアクセスすることはできません。

## リンクを共有する

1. **共有とプライバシー** を開きます。
2. **リンクのアクセス権** で、次のいずれかのオプションを選択します。
   - **制限付き**: 実行を開けるのは、オーナーと招待された人だけです。
   - **リンクを知っている全員**: リンクを持つ、サインイン済みのすべてのユーザーが実行を開けます。
3. **リンクを知っている全員** の場合は、リンクが付与するロール（**閲覧者** または **編集者**）を選択します。リンクが **オーナー** のロールを付与することはありません。
4. **リンクをコピー** を選択します。

リンクは `/share/<token>` の形式です。トークンは、リンクのうち推測が難しい部分です。リンクが取り消された場合や、実行が削除された場合、リンクには **共有が見つかりません** と表示されます。

> [!NOTE]
> API キーやベース URL などのシークレットが、共有された実行に表示されることはありません。

## 人を招待する

1. **共有とプライバシー** を開きます。
2. **人を招待** で、ユーザー名を入力します。一覧には、一致するユーザーが最大 10 人表示されます。
3. ロール（**閲覧者** または **編集者**）を選択します。
4. **招待** を選択します。

**アクセスできる人** には、実行に対してロールを持つすべての人が一覧表示されます。各人について、次のことができます。

- ロールを変更する。
- アクセスを削除する。

各人は、ルールが与えるうちで最も高いアクセスを保持します。たとえば、リンクが **閲覧者** を付与する場合でも、招待された編集者は **編集者** のロールを保持します。

### オーナー権限を譲渡する

実行を別のユーザーに渡すことができます。

1. **アクセスできる人** で、人のロールメニューを開きます。**人を招待** の下にあるロールメニューも使えます。
2. **オーナー権限を譲渡** を選択します。
3. 譲渡を確認します。

新しいオーナーがすべての権限を得ます。あなたは編集者になり、オーナーの権限を失います。

## 公開設定

公開設定は、実行が探索ギャラリーの公開検索に表示されるかどうかを制御します。リンクのアクセス権や招待は変更しません。

| オプション   | 意味                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| **公開**     | 公開検索に掲載されます。すべてのユーザーに表示されます。                 |
| **非公開**   | 公開検索には表示されません。あなたと招待された人にだけ表示されます。     |

公開設定を変更できるのはオーナーだけです。変更はすぐに反映されます。

## 探索ギャラリー

探索ページでは、最適化を検索できます。3 つのタブがあります。

| タブ                 | 表示される内容                                   |
| -------------------- | ------------------------------------------------ |
| **自分**             | あなたの最適化（非公開と公開の両方）             |
| **公開**             | 他のユーザーの公開された最適化                   |
| **自分と共有済み**   | 他のユーザーがあなたと共有した最適化             |

実行を探すには、検索バーと **フィルター** を使います。

探索から公開された実行を開けるのは、ステータス `success` で完了した実行だけです。開くと、次のようになります。

- あなたには **閲覧者** のロールが付与されます。実行を読み、クローンできます。
- ページには実行のオーナーが表示されます。
- Skynet は、API キーやベース URL などのシークレットを取り除きます。
- モデルを実行することはできません。モデルを実行すると、オーナーのキーで支出が発生するためです。

> [!TIP]
> 公開された実行で特定の人により多くのアクセスを与えるには、その人を **編集者** として招待してください。
