データセットは、最適化の実行が学習と採点に使う例の表です。このガイドでは、ファイルのアップロード、行と列の編集、列の役割の設定、データセットの共有の方法を説明します。概念については、[データセット](/docs/concepts/datasets) をお読みください。

## 対応ファイル

Skynet は次のファイル形式を読み取ります。

| 拡張子          | Skynet の読み取り方                                                                  |
| --------------- | ------------------------------------------------------------------------------------ |
| `.csv`          | 1 行目がヘッダー行です。ファイルには少なくとも 1 行のデータ行が必要です。            |
| `.json`         | オブジェクトの配列、または 1 つのオブジェクト。最初のオブジェクトのキーが列になります。 |
| `.xlsx`, `.xls` | Skynet は最初のシートだけを読み取ります。                                            |

その他の拡張子は、「Unsupported file format」というメッセージとともに拒否されます。

> [!TIP]
> 期待される出力は最後の列に置いてください。送信ウィザードは、既定で最後の列を出力としてマークします。

### CSV の例

```csv
question,answer
What is the capital of France?,Paris
How many legs does a spider have?,8
```

### JSON の例

```json
[
  { "question": "What is the capital of France?", "answer": "Paris" },
  { "question": "How many legs does a spider have?", "answer": "8" }
]
```

## データセットをアップロードする

1. **データセット** を開きます。
2. **データセットをアップロード** をクリックするか、ページにファイルをドラッグします。ドラッグ中は「ドロップしてアップロード」と表示されます。
3. 「データセットをライブラリに保存しました」というトーストが表示されるまで待ちます。

Skynet は、拡張子を除いたファイル名をデータセット名として使います。名前を変更するには、データセットを選択して **名前を変更** をクリックします。

> [!NOTE]
> 各アカウントにはストレージのクォータがあります。アップロードがクォータを超える場合、Skynet は制限を説明するダイアログを開きます。[制限](/docs/limits) をご覧ください。

送信ウィザード（「CSV、JSON、Excel ファイルをアップロード」）でファイルをアップロードしたり、[エージェントパネル](/docs/guides/agent-panel) でファイルを添付したりすることもできます。

## データセットを探す

ライブラリにはデータセットが一覧表示されます。一覧を絞り込むには **名前で検索** を使います。他の人があなたと共有したデータセットは **自分と共有済み** に表示されます。

データセットを 1 つ選択すると、次の操作が表示されます。

- **このデータセットをタグ付け** は、このデータセットで [タガー](/docs/guides/tagger) を開きます。
- **データを編集** は、データセットエディターを開きます。
- **共有** は、共有ダイアログを開きます。
- **名前を変更** は、データセット名を変更します。

その他の操作には、**コピーを保存** と **削除** があります。

> [!WARNING]
> 削除すると、データセットはライブラリから完全に削除されます。元に戻すことはできません。そのデータセットから作られた実行は有効なままですが、データセットへのリンクは切れます。

## データセットを編集する

エディターは、データセットをグリッドとして表示します。1 ページに 100 行を表示します。ページ間を移動するには、**次の行** と **前の行** を使います。

### 行と列を変更する

- **行を追加** と **列を追加** は、末尾に新しいセルを追加します。
- **上に行を挿入** と **下に行を挿入** は、選択した行の隣に行を追加します。
- **行を複製**、**行を削除**、**列を削除**、**列名を変更** は構造を変更します。
- **ドラッグして自動入力** は、セルの値を隣のセルにコピーします。
- **元に戻す** と **やり直す** は、直前の変更を取り消したり、繰り返したりします。

行をダブルクリックすると、その行全体を表示できます。

### 保存

エディターは、各編集の直後に変更を自動で保存します。保存中は、ステータスに **保存中…** と表示されます。保存に失敗すると、ステータスに **保存に失敗しました** と表示されます。

> [!NOTE]
> エディターは、行のないデータセットを保存できません。行を追加するまで、「行を追加して変更を保存してください」と表示されます。

作業が終わったら、**ライブラリに戻る** をクリックします。

### 読み取り専用アクセス

共有されたデータセットで閲覧者のロールを持っている場合、エディターは読み取り専用モードで開きます。データを変更するには、オーナーに編集者のロールを依頼するか、**コピーを保存** を使います。

### AI でタグ付け

エディターには **AIでタグ付け** の操作があります。これはタガーを開き、AI モデルがラベルの追加を手伝います。[タガーでデータにラベルを付ける](/docs/guides/tagger) をご覧ください。

## 列の役割を設定する

実行では、どの列が入力で、どの列が期待される出力なのかがわかっている必要があります。これらの役割は、データセットエディターではなく、実行を送信するときに設定します。

送信ウィザードの「データの読み取り方」ステップでは、各列に 3 つの選択肢が表示されます。

- **入力**: プログラムがこの値を受け取ります。
- **出力**: スコアラーが比較に使う期待される答えです。
- **スキップ**: 実行はこの列を無視します。

既定値は次のとおりです。

- すべての列が入力で、最後の列が出力です。
- 列が 1 つのデータセットでは、入力が 1 つで出力はありません。

出力列がない場合、Skynet は最初の行を 1 つの入力として使います。少なくとも 1 つの入力列を選ぶ必要があります。

画像を保持できる列もあります。そのような列では、**画像** または **テキスト** を選んで、Skynet に値の読み取り方を伝えます。

> [!TIP]
> データセットエディターは、出力列に「出力」バッジを表示します。エディターで追加した新しい列は、入力として始まります。

ウィザードは、行を学習用と評価用の部分にも分割します。各部分の合計は 1 である必要があります。そうでない場合、ウィザードに「分割の合計は 1 にする必要があります。」と表示されます。全体の流れについては、[実行を開始する](/docs/guides/submit) をお読みください。

## データセットを共有する

データセットを選択して **共有** をクリックします。**共有とプライバシー** ダイアログが開きます。

### リンクのアクセス

| オプション                     | データセットを開ける人                                         |
| ------------------------------ | -------------------------------------------------------------- |
| **制限付き**                   | オーナーと招待された人だけ。                                   |
| **リンクを知っている全員**     | リンクを持つ、サインイン済みのすべての人。選んだロールで開けます。 |

「リンクを知っている全員」のデータセットでは、リンクが付与するロール（**閲覧者** または **編集者**）を選びます。URL をコピーするには **リンクをコピー** をクリックします。

### 人を招待する

1. **人を招待** の下にある **ユーザー名で人を追加** に、ユーザー名を入力します。
2. **招待** をクリックします。
3. **アクセスできる人** の一覧を確認します。人のロールを変更するには、**ロールを変更** を使います。

ロールは次のとおりです。

| ロール   | アクセス                                                       |
| -------- | -------------------------------------------------------------- |
| オーナー | 共有と削除の管理を含む、すべての操作。                         |
| 編集者   | 閲覧者のアクセスに加え、モデルの実行、チャット、名前の変更。   |
| 閲覧者   | データセットを開けます。エディターは読み取り専用です。         |

### オーナー権限を譲渡する

データセットを別の人に渡すには、**オーナー権限を譲渡** を使います。Skynet が確認を求めます。

> [!WARNING]
> 譲渡後、あなたは編集者になり、オーナーの権限を失います。
