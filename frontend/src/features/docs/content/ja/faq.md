このページでは、Skynet についてよくある質問に回答します。各回答には、詳細を説明したページへのリンクがあります。

## 全般

### Skynet とは何ですか？

Skynet は、プロンプト、プログラム、エージェント、ワークフローを、あなた自身のデータとメトリクスに対して最適化するプラットフォームです。データセットをアップロードし、タスクを説明して、実行を開始します。実行は新しいバージョンを試し、評価用に取り分けたデータでそれらを採点します。始めるには、[クイックスタート](/docs/quickstart) をお読みください。

### Skynet は何を最適化できますか？

Skynet は Optimize Anything です。プロンプト、コード、テキスト、DSPy プログラムを 1 つのプロダクトで最適化します。アーティファクトの種類によって、使えるエンジンが決まります。

- プロンプト、コード、テキストのアーティファクトは、ネイティブエンジン（GEPA、Best-of-N、Meta-Harness、AutoResearch、AutoSaddler、ShinkaEvolve）を使います。
- DSPy プログラムは、DSPy オプティマイザー（DSPy GEPA、DSPy MIPROv2、DSPy BootstrapFewShot）を使います。

**Auto** は、タスクに合うエンジンを組み合わせます。[最適化の仕組み](/docs/concepts/optimization) と [エンジン](/docs/concepts/engines) をご覧ください。

### インターフェースはどの言語に対応していますか？

インターフェースは 24 の言語に対応しています。ヘブライ語が基本言語で、レイアウトは右から左に書くテキストに対応しています。ヘブライ語のドキュメントは [/docs/he](/docs/he) にあります。

### Skynet はオープンソースですか？

はい。コードは AGPL-3.0 ライセンスです。Skynet を改変したバージョンをサービスとして提供する場合、ライセンスにより変更内容の公開が求められます。

## データ

### どのファイル形式をアップロードできますか？

CSV、JSON、`.xlsx`、`.xls` ファイルをアップロードできます。Excel ファイルの場合、Skynet は最初のシートだけを読み取ります。[データセットを準備する](/docs/guides/datasets) をご覧ください。

### データにラベルがありません。どうすればよいですか？

タガーを使ってください。自分で行にラベルを付けることも、AI モデルにラベルを付けさせてその作業をレビューすることもできます。[タガーでデータにラベルを付ける](/docs/guides/tagger) をご覧ください。

### 実行とデータセットは誰が見られますか？

> [!WARNING]
> 新しい実行は既定で **公開** です。公開された実行は公開検索に表示され、誰でもその結果を閲覧できます。

実行を公開検索に表示させないようにするには、送信時に **公開範囲** を **非公開** に設定します。新しいデータセットは **制限付き** です。開けるのは、あなたと、あなたが招待した人だけです。[共有と公開](/docs/guides/sharing) と [セキュリティ](/docs/security) をご覧ください。

### モデルプロバイダーは私のプロンプトで学習しますか？

既定では、学習しません。**モデルのデータプライバシー** の既定のオプションは **学習なし** です。このオプションでは、プロンプトで学習せず、保持もしないプロバイダーにだけプロンプトを送信します。この設定は、Skynet があなたの残高に請求する呼び出しに適用されます。あなた自身のキーによる呼び出しは、OpenRouter アカウントのプライバシー設定に従います。[セキュリティ](/docs/security) をご覧ください。

## 請求

### Skynet は実行にどのように課金しますか？

Skynet は前払いの残高を使います。ホスト型モデルの使用量、Skynet の手数料、サンドボックスの使用量が計測されます。有料の処理が始まる前に、Skynet はウォレットと実行予算に余裕分を確保します。[請求](/docs/concepts/billing) をご覧ください。

### 自分のモデルプロバイダーのキーを使えますか？

はい。独自キー (BYOK) を使う場合、モデル呼び出しの料金はプロバイダーがあなたのキーに直接請求します。プラットフォーム手数料とサンドボックスの使用量は、引き続き Skynet の残高から支払われます。Skynet はキーを暗号化し、二度と表示しません。[請求](/docs/concepts/billing) と [セキュリティ](/docs/security) をご覧ください。

### モデル呼び出しの料金を払わずに Skynet を実行できますか？

[Mac アプリ](/docs/guides/mac-app) は、あなた自身のコンピューターで Skynet を実行します。モデル呼び出しは、Mac でサインインしている Claude Code または Codex を経由して送信されます。それらの呼び出しは CLI のプランで支払われるため、実行に加算される料金は $0 です。

## ツールと連携

### 自分の AI クライアントから Skynet を操作できますか？

はい。Skynet には `https://mcp.skynetml.com/mcp` に MCP サーバーがあります。サインインには OAuth を使います。サーバーには `check_run`、`start_run`、`get_run`、`list_runs`、`stop_run` のツールがあります。[MCP](/docs/mcp) をご覧ください。

### API はありますか？

はい。設定で API トークンを生成し、`Authorization: Bearer <token>` として送信します。各ユーザーが同時に持てる有効なトークンは 1 つです。[API](/docs/api) をご覧ください。

### エージェントパネルは私の実行を削除できますか？

許可した場合に限ります。既定の **確認する** モードでは、エージェントはすべての操作の前に確認します。**自動** モードでも、削除や送信などの破壊的な操作の前には確認します。[エージェントパネル](/docs/guides/agent-panel) をご覧ください。
