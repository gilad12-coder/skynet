Skynet は、実行、ファイル、ストレージ、リクエストレートに制限を設けています。これらの制限は、プラットフォームを安定させ、あなたの残高を守ります。このページでは既定値を一覧にしています。管理者は、アカウントごとに一部の制限を変更できます。

> [!NOTE]
> このページの値は現在の既定値です。制限に達すると、アプリまたは API が、どの制限によってリクエストが止められたかを示します。

## 実行

| 制限                   | Free | Pro   |
| ---------------------- | ---- | ----- |
| 同時にアクティブな実行 | 5    | 20    |
| 保存済みの実行         | 100  | 1,000 |

アクティブな実行とは、ステータスが `pending`、`validating`、`running`、`paused` のいずれかである実行です。アクティブな実行が上限数に達している場合、そのうち 1 つが終了するまで、Skynet は新しい実行を受け付けません。

保存済みの実行の制限は、すべての実行を数えます。新しい実行の枠を空けるには、不要な実行を削除してください。

Pro の更新に失敗した場合、アカウントは 7 日間 Pro の制限を維持します。その後は、支払いが成功するまで Free の制限が適用されます。

| 制限                                     | 値                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------- |
| 1 回の API クローンリクエストでのコピー数 | 1〜5                                                                 |
| 実行ごとの自動復旧の試行回数             | 3                                                                    |
| コントラクトチェックのサンプルケース数           | 3                                                                    |
| 実行ごとに保存される進捗イベント数       | 5,000。Skynet は古いイベントから削除します。                         |
| 1 つのサンドボックスの存続時間           | 45 分。それ以上の時間が必要な実行は、新しいサンドボックスを開きます。 |

復旧の試行の仕組みについては、[実行](/docs/concepts/runs) をお読みください。

## ストレージ

| 制限             | Free    | Pro    |
| ---------------- | ------- | ------ |
| ストレージの合計 | 250 MiB | 10 GiB |

ストレージの合計には、実行、データセット、ログ、エージェントとのチャット、一時保存されたアップロード、検索データが含まれます。ストレージの制限を超える書き込みは、Skynet が拒否します。

## ファイルとデータセット

| 制限                                           | 値                                 |
| ---------------------------------------------- | ---------------------------------- |
| ライブラリに保存するデータセットファイル       | ファイルごとに 50 MiB（圧縮後）    |
| レコードをインポートするコネクターからの行数   | 20,000                             |
| エージェントとのチャットに添付するファイル     | 20 MiB                             |
| 1 つのチャット添付ファイルから読み取るテキスト | 50,000 文字                        |
| 音声入力用の音声クリップ                       | 25 MB                              |
| GitHub リポジトリのアーカイブ                  | 200 MiB（圧縮後）                  |
| 実行ページで開くリポジトリのファイル           | 1 MiB                              |

レコードをインポートするコネクターには、データベースのテーブル、LLM のトレース、Notion のデータベースが含まれます。[データセットを準備する](/docs/guides/datasets) をお読みください。

### ウィザードのワークスペースファイル

| 制限                               | 値                                                                      |
| ---------------------------------- | ----------------------------------------------------------------------- |
| ワークスペース内の追加ファイル     | 20                                                                      |
| ファイル名の長さ                   | 120 文字                                                                |
| フォルダーの階層                   | 3 階層                                                                  |
| ファイル形式                       | `.py`, `.txt`, `.md`, `.json`, `.yaml`, `.csv`, `.toml`, `.ini`, `.cfg` |

`run.py` と `metric.py` は実行のエントリーファイルです。削除、名前の変更、移動はできません。

## リクエストレート

| 制限                                                         | 値                                              |
| ------------------------------------------------------------ | ----------------------------------------------- |
| 実行の送信                                                   | アカウントごとに直近 1 分間で 30 回             |
| 音声入力クリップ                                             | アカウントごとに 1 時間で 120 回                |
| エージェントとのチャット用に読み取るファイル                 | アカウントごとに 1 時間で 300 件                |
| アカウントのリクエスト（登録、パスワードリセット、メール確認） | メールアドレスごとに直近 1 時間で 20 回         |
| ウィザードアシスタントのターン                               | アカウントごとに UTC の 1 日で 50 回            |
| 検索とインデックス作成のトークン                             | アカウントごとに 1 か月で 2,000,000             |

レート制限を超えると、API は HTTP ステータス `429` を返します。しばらく待ってから、リクエストを再送してください。

アカウントが月間の検索・インデックス作成トークンを超えると、Skynet はそのアカウントの新しい項目のインデックス作成を停止します。その後、検索はセマンティック検索が利用できない場合と同じように動作します。

## 金額

| 制限                                                   | 値                                                                      |
| ------------------------------------------------------ | ----------------------------------------------------------------------- |
| 新しい実行の既定の支出上限                             | $5、または開始に必要な金額のほうが大きい場合はその金額                  |
| 開始に必要な金額に含まれる余裕分                       | $1、または最も高価な単一のモデル呼び出しのコストのほうが大きい場合はその金額 |
| カスタムのチャージ額                                   | $5〜$1,000                                                              |
| 対話的なモデルのターンを開始するのに必要な残高         | $0.05                                                                   |

手数料と確保額については、[予算と請求](/docs/concepts/billing) をお読みください。
