यह पेज बताता है कि Skynet आपके खाते, आपकी कुंजियों और आपके डेटा की सुरक्षा कैसे करता है। यह यह भी बताता है कि किसी सुरक्षा समस्या की रिपोर्ट कैसे करें।

## कमज़ोरी की रिपोर्ट करें

सुरक्षा समस्याओं की रिपोर्ट निजी तौर पर करें। कोई सार्वजनिक issue न खोलें।

- GitHub पर Skynet रिपॉज़िटरी खोलें और **Security** > **Report a vulnerability** पर जाएँ।
- या `security@skynetml.com` पर ईमेल भेजें।

टीम का लक्ष्य है कि हर रिपोर्ट की पावती पाँच कार्यदिवसों के भीतर दी जाए।

## आपका खाता

### साइन-इन के तरीके

आप इनसे साइन इन कर सकते हैं:

- एक ईमेल पता और पासवर्ड।
- **Google के साथ जारी रखें** या **GitHub के साथ जारी रखें**।
- **पासकी से साइन इन करें**। पासकी Face ID, Touch ID या हार्डवेयर कुंजी इस्तेमाल करती है।

आप जिन प्रदाताओं का इस्तेमाल करते हैं, उन्हें **जुड़े हुए खाते** में प्रबंधित कर सकते हैं।

### पासवर्ड के नियम

पासवर्ड में:

- कम से कम 8 अक्षर होने चाहिए।
- ज़्यादा से ज़्यादा 128 अक्षर होने चाहिए।
- आपका ईमेल पता नहीं होना चाहिए।

नए खाते को अपना ईमेल पता एक कोड से सत्यापित करना होता है। पासवर्ड रीसेट के लिए भी एक कोड इस्तेमाल होता है, जिसे Skynet ईमेल से भेजता है।

बार-बार असफल प्रयासों के बाद Skynet किसी ईमेल पते के लिए साइन-इन को कुछ समय के लिए लॉक कर देता है।

### दो-चरणीय सत्यापन

ज़्यादा सुरक्षा के लिए दो-चरणीय सत्यापन चालू करें। एक तरीका चुनें:

| तरीका                 | यह कैसे काम करता है                                           |
| --------------------- | ------------------------------------------------------------ |
| **ऑथेंटिकेटर ऐप**     | अपने ऑथेंटिकेटर ऐप से 6 अंकों का कोड दर्ज करें।                 |
| **ईमेल कोड**          | 6 अंकों का वह कोड दर्ज करें जो Skynet हर साइन-इन पर भेजता है।     |

Skynet आपको रिकवरी कोड भी देता है। उन्हें सुरक्षित जगह पर रखें। अगर आप अपने तरीके तक पहुँच खो देते हैं, तो इनमें से एक का इस्तेमाल करें।

> [!NOTE]
> अगर आप Google या GitHub से साइन इन करते हैं, तो वही प्रदाता आपका दो-चरणीय सत्यापन प्रबंधित करता है।

## आपका कोड कहाँ चलता है

उपयोगकर्ता के वर्कलोड अलग-थलग सैंडबॉक्स में चलते हैं। होस्टेड प्रोडक्ट में Vercel Sandbox निष्पादन की सीमा है। इसमें सेटअप जाँच, ऑप्टिमाइज़ेशन रन, रिकवरी और पूरे हो चुके रन पर होने वाला काम शामिल है।

Skynet वर्कर आपका कोड नहीं चलाते। वे कंट्रोल प्लेन हैं। वे जॉब शुरू करते हैं, बजट आरक्षित और सेटल करते हैं, सैंडबॉक्स को सीमित दायरे वाले क्रेडेंशियल देते हैं, और चेकपॉइंट सहेजते हैं।

पेड काम शुरू करने से पहले, Skynet आपके वॉलेट और रन बजट में गुंजाइश आरक्षित करता है। [बिलिंग](/docs/concepts/billing) देखें।

[Mac ऐप](/docs/guides/mac-app) में जॉब स्थानीय Docker कंटेनरों में चलते हैं। सभी स्थानीय सेवाएँ सिर्फ़ `127.0.0.1` पर सुनती हैं।

## प्रदाता कुंजियाँ (BYOK)

आप अपनी मॉडल प्रदाता कुंजियाँ जोड़ सकते हैं।

- Skynet हर कुंजी को स्टोरेज में एन्क्रिप्ट करके रखता है।
- Skynet API के ज़रिए पूरी कुंजी कभी नहीं लौटाता।
- Skynet सिर्फ़ आखिरी चार अक्षर और एक स्थिति रखता है: असत्यापित, सत्यापित या अमान्य।
- जब आप कोई कुंजी दर्ज करते हैं, तो Skynet उसे जाँचने के लिए एक छोटा टेस्ट अनुरोध भेजता है।

जब आप अपनी कुंजी इस्तेमाल करते हैं, तो प्रदाता शुल्क सीधे आपकी कुंजी से लेता है। Skynet फिर भी अपना प्लेटफ़ॉर्म शुल्क और सैंडबॉक्स उपयोग आपके बैलेंस से लेता है।

Skynet लॉग और एरर संदेशों से सीक्रेट भी हटाता है। वह उनकी जगह `[REDACTED]` लिखता है।

## API टोकन

API टोकन स्क्रिप्ट और टूल को Skynet API कॉल करने देते हैं।

- हर उपयोगकर्ता के पास ज़्यादा से ज़्यादा एक मान्य टोकन होता है। जब आप नया टोकन जनरेट करते हैं, तो पुराना टोकन काम करना बंद कर देता है।
- टोकन `skyd_` से शुरू होते हैं।
- Skynet टोकन का सिर्फ़ एक हैश सहेजता है।
- Skynet पूरा टोकन सिर्फ़ एक बार दिखाता है। टोकन को तुरंत कॉपी करके सहेज लें।
- उसके बाद Skynet सिर्फ़ छिपा हुआ रूप दिखाता है: `skyd_…` और आखिरी चार अक्षर।

टोकन `Authorization` हेडर में भेजें:

```http
Authorization: Bearer skyd_...
```

किसी टोकन को बंद करने के लिए **टोकन निरस्त करें** पर क्लिक करें। पूरे API के लिए [API](/docs/api) पढ़ें।

> [!WARNING]
> टोकन को पासवर्ड की तरह संभालें। जिसके पास भी टोकन है, वह API के ज़रिए आपकी तरह काम कर सकता है। इसे किसी रिपॉज़िटरी में कमिट न करें।

## मॉडल डेटा गोपनीयता

**मॉडल डेटा गोपनीयता** सेटिंग तय करती है कि मॉडल प्रदाता आपके डेटा के साथ क्या कर सकते हैं। यह उन ऑप्टिमाइज़ेशन पर लागू होती है जिनका बिल Skynet आपके बैलेंस से लेता है।

| विकल्प             | प्रभाव                                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| **सभी की अनुमति**  | कोई भी प्रदाता, उन प्रदाताओं समेत जो आपके प्रॉम्प्ट पर ट्रेनिंग कर सकते हैं या उन्हें सहेज सकते हैं।               |
| **ट्रेनिंग नहीं**   | सिर्फ़ वे प्रदाता जो आपके प्रॉम्प्ट पर ट्रेनिंग नहीं करते और उन्हें अपने पास नहीं रखते। यह डिफ़ॉल्ट है।              |
| **शून्य संग्रहण**   | सिर्फ़ वे एंडपॉइंट जिनके साथ ज़ीरो-डेटा-रिटेंशन समझौता है। कुछ मॉडल उपलब्ध न हों, ऐसा हो सकता है।              |

> [!NOTE]
> आपकी अपनी कुंजी पर होने वाले ऑप्टिमाइज़ेशन आपके OpenRouter खाते की गोपनीयता सेटिंग्स का पालन करते हैं।

## रन की दृश्यता

> [!WARNING]
> नए रन डिफ़ॉल्ट रूप से **सार्वजनिक** होते हैं। सार्वजनिक रन सार्वजनिक खोज में दिखता है। कोई भी उसे ढूँढ सकता है और उसके परिणाम ब्राउज़ कर सकता है।

किसी रन को सार्वजनिक खोज से बाहर रखने के लिए, उसे सबमिट करते समय **दृश्यता** को **निजी** पर सेट करें। आप बाद में शेयर डायलॉग में दृश्यता बदल सकते हैं। [साझा करें और प्रकाशित करें](/docs/guides/sharing) देखें।

नए डेटासेट **प्रतिबंधित** होते हैं। जब तक आप लिंक एक्सेस नहीं बदलते, उन्हें सिर्फ़ आप और आपके आमंत्रित लोग खोल सकते हैं। [डेटासेट तैयार करें](/docs/guides/datasets) देखें।

## आपका डेटा

अपना डेटा प्रबंधित करने के लिए **सेटिंग्स** में **गोपनीयता और डेटा** टैब खोलें।

### अपना डेटा एक्सपोर्ट करें

**मेरा डेटा एक्सपोर्ट करें** के नीचे **एक्सपोर्ट करें** पर क्लिक करें। एक्सपोर्ट में आपके खाते का सारा डेटा होता है। एक फ़ॉर्मेट चुनें: JSON, CSV, Excel, Pickle, Parquet या Feather।

### अपना खाता हटाएँ

**खाता हटाएं** पर क्लिक करें। पुष्टि करने के लिए अपना मौजूदा पासवर्ड दर्ज करें और अपना ईमेल पता टाइप करें।

> [!WARNING]
> यह आपके खाते और उसके सारे डेटा को हमेशा के लिए हटा देता है। आप इसे पूर्ववत नहीं कर सकते।

### उपयोग विश्लेषण

**गुमनाम उपयोग विश्लेषण भेजें** सेटिंग गुमनाम प्रोडक्ट एनालिटिक्स को चालू या बंद करती है।
