Skynet Mac ऐप Skynet को आपके अपने कंप्यूटर पर चलाता है। यह मॉडल कॉल आपके Mac पर साइन इन किए गए किसी कोडिंग CLI के ज़रिए भेजता है, इसलिए उन कॉल का भुगतान आपका CLI प्लान करता है। आप ऐप को अपने होस्टेड Skynet खाते से भी लिंक कर सकते हैं।

## आवश्यकताएँ

- Apple silicon वाला Mac। Intel बिल्ड मौजूद हैं, लेकिन किसी ने उन्हें Intel हार्डवेयर पर नहीं जाँचा।
- Docker Desktop, चालू, और **Use Rosetta for x86_64/amd64 emulation** चालू किया हुआ।
- एक कोडिंग CLI, साइन इन किया हुआ:
  - Claude Code (`claude`) 2.1.226 या नया, या
  - Codex (`codex`) 0.160.0 या नया।

> [!WARNING]
> Codex को ChatGPT साइन-इन इस्तेमाल करना होगा। API कुंजी से साइन-इन नहीं गिना जाता। macOS Keychain में रखा गया लॉगिन भी नहीं गिना जाता।

### Codex सेट अप करें

Codex को अपने क्रेडेंशियल एक फ़ाइल में रखने होंगे। पहली बार लॉन्च करने से पहले ये चरण करें:

1. `~/.codex/config.toml` खोलें और यह पंक्ति जोड़ें:

```toml
cli_auth_credentials_store = "file"
```

2. अपने ChatGPT खाते से साइन इन करें:

```bash
codex login
```

## ऐप इंस्टॉल करें

बिल्ड ad hoc साइन किए गए हैं और notarized नहीं हैं। जब तक आप quarantine फ़्लैग नहीं हटाते, macOS उन्हें ब्लॉक करता है।

1. `.dmg` फ़ाइल खोलें।
2. **Skynet** को **Applications** में खींचें।
3. Terminal में यह कमांड चलाएँ:

```bash
xattr -dr com.apple.quarantine /Applications/Skynet.app
```

4. **Applications** से Skynet खोलें।

> [!NOTE]
> पहली बार लॉन्च में कई मिनट लगते हैं। ऐप एक लोकल सैंडबॉक्स इमेज बनाता है और अपना डेटाबेस तैयार करता है।

## लॉन्च पर क्या होता है

ऐप ये चरण क्रम से करता है:

1. यह आपके लॉगिन शेल से `PATH` पढ़ता है, ताकि Docker और आपका CLI ढूँढ सके।
2. यह Docker और आपके कोडिंग CLI की जाँच करता है।
3. यह Docker में एक लोकल Postgres डेटाबेस शुरू करता है।
4. यह `linux/amd64` के लिए सैंडबॉक्स इमेज `skynet-local-sandbox` बनाता है। Docker इसे Rosetta के तहत चलाता है।
5. यह डेटाबेस स्कीमा अपडेट करता है।
6. यह लोकल API और वेब ऐप शुरू करता है, और विंडो में वेब ऐप दिखाता है।

### ऑनबोर्डिंग जाँचें

ऐप जाँचों की एक सूची दिखाता है: **Docker**, **Coding CLI**, **Signed in**, **Usage limit**, **Local services** और **Account**। अगर कोई जाँच विफल होती है, तो ऐप एक स्क्रीन दिखाता है जो बताती है कि क्या करना है:

| स्क्रीन                             | क्या करें                                                              |
| ---------------------------------- | --------------------------------------------------------------------- |
| **Install Docker Desktop**      | Docker Desktop इंस्टॉल करें।                                            |
| **Start Docker**                 | Docker Desktop शुरू करें।                                               |
| **Install a coding CLI**          | Claude Code या Codex इंस्टॉल करें।                                       |
| **Update your coding CLI**        | CLI को ऊपर दिए न्यूनतम संस्करण तक अपडेट करें।                               |
| **Sign in to your CLI**         | Terminal में CLI में साइन इन करें।                                        |
| **Usage limit reached**            | रीसेट समय का इंतज़ार करें। रीसेट के बाद नए जॉब फिर से शुरू हो सकते हैं।           |

समस्या ठीक करने के बाद **Check again** पर क्लिक करें। लॉग फ़ाइलें देखने के लिए **Open logs** पर क्लिक करें। **Usage limit reached** स्क्रीन पर, आप **Open Skynet anyway** पर क्लिक कर सकते हैं।

## लोकल रन

ऐप में, मॉडल कॉल आपके Mac के CLI के ज़रिए जाती हैं। मॉडल मेनू इस मोड को **लोकल** दिखाता है। संकेत कहता है: "कॉल का भुगतान आपका प्लान करता है, इसलिए यह मॉडल रन में $0 जोड़ता है।"

ऐप में CLI के नाम **Claude Code** और **Codex** हैं।

> [!NOTE]
> ऐप जिन प्रोसेस को शुरू करता है, उनके environment से API कुंजियाँ हटा देता है। इसलिए CLI आपकी सब्सक्रिप्शन इस्तेमाल करता है, API कुंजी नहीं।

### प्रस्तावक को अपने CLI पर चलाएँ

**प्रस्तावक को मेरे CLI पर चलाएँ** सेटिंग तय करती है कि प्रस्तावक (proposer) एजेंट कहाँ चलता है। विकल्प हैं **एजेंट इंजन (डिफ़ॉल्ट)** और **बंद (सैंडबॉक्स प्रस्तावक)**।

**प्रस्तावक की पहुँच** तय करती है कि CLI किन चीज़ों तक पहुँच सकता है:

- **केवल वर्कस्पेस** डिफ़ॉल्ट है। यह हर CLI के अपने सैंडबॉक्स पर निर्भर करता है।
- **पूरी पहुँच** CLI को आपके उपयोगकर्ता अधिकारों के साथ चलाती है।

> [!WARNING]
> **पूरी पहुँच** के साथ, CLI वह हर फ़ाइल पढ़, बदल और हटा सकता है जो आप कर सकते हैं, और नेटवर्क तक पहुँच सकता है। Claude का acceptEdits मोड नेटवर्क को अलग नहीं करता, **केवल वर्कस्पेस** के साथ भी नहीं।

### ऐप में टैगिंग

Mac ऐप में AI टैगिंग के लिए आपकी अपनी प्रदाता कुंजी चाहिए। **आपकी अपनी कुंजी** के नीचे एक मॉडल चुनें। [टैगर से डेटा लेबल करें](/docs/guides/tagger) देखें।

## अपने Skynet खाते से लिंक करें

आप ऐप को बिना खाते के इस्तेमाल कर सकते हैं। इसके लिए **Use without signing in** पर क्लिक करें। अपने होस्टेड खाते से सिंक करने के लिए, ऐप को लिंक करें।

### इस Mac को लिंक करें

1. **Sign in to Skynet** चरण पर, ऐप आपके डिफ़ॉल्ट ब्राउज़र में **Link a Mac** पेज खोलता है।
2. अगर ब्राउज़र माँगे, तो उसमें Skynet में साइन इन करें।
3. **लिंक होने के बाद यह Mac:** के नीचे की सूची जाँचें।
4. **इस Mac को लिंक करें** पर क्लिक करें। पेज "Mac ऐप पर लौट रहे हैं…" दिखाता है।

अगर साइन-इन विफल होता है या आप रद्द करते हैं, तो ऐप **Try again** और **Use without signing in** दिखाता है।

लिंक होने के बाद, Mac:

- आपका नाम और ईमेल देख सकता है।
- आपका बैलेंस देख सकता है।
- आपके रन आपके खाते से सिंक कर सकता है।
- आपके बैलेंस से भुगतान किए गए होस्टेड मॉडल इस्तेमाल कर सकता है।
- आपके कनेक्ट किए गए डेटा स्रोत इस्तेमाल कर सकता है।
- Skynet के ज़रिए वेब पर खोज और ब्राउज़ कर सकता है।

लिंक एक सुरक्षित साइन-इन प्रक्रिया (PKCE के साथ OAuth) इस्तेमाल करता है। ऐप अपने टोकन आपके Mac पर एन्क्रिप्ट करके रखता है। जब आप अनलिंक करते हैं, तो Skynet टोकन रद्द कर देता है।

### लिंक की सीमाएँ

| सीमा                              | मान                                          |
| -------------------------------- | ------------------------------------------- |
| हर खाते के लिए लिंक किए गए Mac       | 10                                          |
| एक्सेस टोकन की अवधि                 | 1 घंटा, फिर ऐप इसे रिफ़्रेश करता है               |
| लिंक का निष्क्रियता टाइमआउट            | 30 दिन तक इस्तेमाल न होने पर                     |
| लिंक की अधिकतम आयु                 | 365 दिन                                     |

निष्क्रियता टाइमआउट या अधिकतम आयु के बाद, Mac को फिर से लिंक करें।

### लिंक की स्थिति

ऐप इनमें से एक स्थिति दिखाता है: **लोकल मोड**, **इस Mac से लिंक है**, **सिंक करने के लिए साइन इन करें** या **लिंक है (ऑफ़लाइन)**।

## लोकल सेवाएँ और डेटा

सभी लोकल सेवाएँ केवल `127.0.0.1` पर सुनती हैं:

| सेवा      | पोर्ट रेंज        |
| -------- | -------------- |
| API      | 48100 से 48119 |
| वेब ऐप    | 48120 से 48139 |
| Postgres | 48140 से 48159 |

ऐप अपना डेटा `~/Library/Application Support/Skynet` में रखता है। `logs/` फ़ोल्डर में `desktop.log`, `api.log`, `frontend.log`, `migrate.log` और `sandbox-build.log` होते हैं।

जब आप ऐप बंद करते हैं, तो यह वेब ऐप, API, Postgres और सभी जॉब कंटेनर रोक देता है।

### ऐप रीसेट करें

> [!WARNING]
> ये कमांड सारा लोकल डेटा हटा देते हैं, जिसमें आपके लोकल रन और डेटासेट शामिल हैं।

पहले ऐप बंद करें। फिर चलाएँ:

```bash
docker volume rm skynet-local-pgdata
rm -rf ~/Library/Application\ Support/Skynet
```
