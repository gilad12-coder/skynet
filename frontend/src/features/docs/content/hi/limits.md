Skynet रन, फ़ाइलों, स्टोरेज और अनुरोध दरों पर सीमाएँ लगाता है। ये सीमाएँ प्लेटफ़ॉर्म को स्थिर रखती हैं और आपके बैलेंस की रक्षा करती हैं। यह पेज डिफ़ॉल्ट मानों की सूची देता है। एक एडमिनिस्ट्रेटर किसी खाते के लिए कुछ सीमाएँ बदल सकता है।

> [!NOTE]
> इस पेज के मान मौजूदा डिफ़ॉल्ट हैं। जब आप किसी सीमा तक पहुँचते हैं, तो ऐप या API बताता है कि किस सीमा ने अनुरोध रोका।

## रन

| सीमा                        | Free | Pro   |
| --------------------------- | ---- | ----- |
| एक साथ सक्रिय रन            | 5    | 20    |
| सहेजे गए रन                 | 100  | 1,000 |

सक्रिय रन वह रन है जिसकी स्थिति `pending`, `validating`, `running` या `paused` है। जब आपके सक्रिय रन अधिकतम संख्या तक पहुँच जाते हैं, तो Skynet नए रन तब तक अस्वीकार करता है जब तक उनमें से कोई एक पूरा नहीं हो जाता।

सहेजे गए रन की सीमा आपके सभी रन गिनती है। नए रन के लिए जगह बनाने के लिए उन रन को हटाएँ जिनकी आपको ज़रूरत नहीं है।

अगर Pro का नवीनीकरण विफल होता है, तो खाता 7 दिन तक Pro सीमाएँ रखता है। उसके बाद, भुगतान सफल होने तक वह Free सीमाएँ इस्तेमाल करता है।

| सीमा                                   | मान                                                              |
| -------------------------------------- | ---------------------------------------------------------------- |
| एक API क्लोन अनुरोध में कॉपियाँ          | 1 से 5                                                           |
| किसी रन के लिए स्वचालित रिकवरी प्रयास   | 3                                                                |
| कॉन्ट्रैक्ट जाँच में नमूना केस           | 3                                                                |
| हर रन के लिए सहेजे गए प्रगति इवेंट       | 5,000। Skynet सबसे पुराने इवेंट पहले हटाता है।                     |
| एक सैंडबॉक्स का जीवनकाल                 | 45 मिनट। जिस रन को ज़्यादा समय चाहिए, वह एक नया सैंडबॉक्स खोलता है। |

रिकवरी प्रयास कैसे काम करते हैं, यह जानने के लिए [रन](/docs/concepts/runs) पढ़ें।

## स्टोरेज

| सीमा          | Free    | Pro    |
| ------------- | ------- | ------ |
| कुल स्टोरेज    | 250 MiB | 10 GiB |

कुल स्टोरेज में आपके रन, डेटासेट, लॉग, एजेंट चैट, स्टेज किए गए अपलोड और खोज डेटा शामिल हैं। Skynet ऐसा कोई भी राइट अस्वीकार करता है जो आपकी स्टोरेज सीमा से ज़्यादा हो जाए।

## फ़ाइलें और डेटासेट

| सीमा                                         | मान                                     |
| -------------------------------------------- | --------------------------------------- |
| आपकी लाइब्रेरी में सहेजी गई डेटासेट फ़ाइल      | हर फ़ाइल के लिए 50 MiB, कम्प्रेशन के बाद  |
| रिकॉर्ड इंपोर्ट करने वाले कनेक्टर से पंक्तियाँ   | 20,000                                  |
| एजेंट चैट में अटैच की गई फ़ाइल                | 20 MiB                                  |
| एक चैट अटैचमेंट से पढ़ा गया टेक्स्ट            | 50,000 अक्षर                            |
| डिक्टेशन के लिए ऑडियो क्लिप                   | 25 MB                                   |
| GitHub रिपॉज़िटरी आर्काइव                    | 200 MiB, कम्प्रेस्ड                     |
| रन पेज पर खोली गई रिपॉज़िटरी फ़ाइल             | 1 MiB                                   |

रिकॉर्ड इंपोर्ट करने वाले कनेक्टरों में डेटाबेस टेबल, LLM ट्रेस और Notion डेटाबेस शामिल हैं। [डेटासेट तैयार करें](/docs/guides/datasets) पढ़ें।

### विज़ार्ड में वर्कस्पेस फ़ाइलें

| सीमा                          | मान                                                                     |
| ----------------------------- | ----------------------------------------------------------------------- |
| वर्कस्पेस में अतिरिक्त फ़ाइलें    | 20                                                                      |
| फ़ाइल नाम की लंबाई             | 120 अक्षर                                                               |
| फ़ोल्डर की गहराई               | 3 फ़ोल्डर                                                               |
| फ़ाइल टाइप                     | `.py`, `.txt`, `.md`, `.json`, `.yaml`, `.csv`, `.toml`, `.ini`, `.cfg` |

`run.py` और `metric.py` किसी रन की एंट्री फ़ाइलें हैं। आप उन्हें हटा, उनका नाम बदल या उन्हें मूव नहीं कर सकते।

## अनुरोध दरें

| सीमा                                                              | मान                                           |
| ----------------------------------------------------------------- | --------------------------------------------- |
| रन सबमिशन                                                         | हर खाते के लिए किसी भी एक मिनट में 30          |
| डिक्टेशन क्लिप                                                     | हर खाते के लिए एक घंटे में 120                 |
| एजेंट चैट के लिए पढ़ी गई फ़ाइलें                                     | हर खाते के लिए एक घंटे में 300                 |
| खाता अनुरोध (रजिस्टर, पासवर्ड रीसेट, ईमेल सत्यापन)                     | हर ईमेल पते के लिए किसी भी एक घंटे में 20       |
| विज़ार्ड सहायक के टर्न                                               | हर खाते के लिए एक UTC दिन में 50               |
| खोज और इंडेक्सिंग टोकन                                              | हर खाते के लिए एक महीने में 2,000,000          |

जब आप किसी रेट सीमा से आगे जाते हैं, तो API HTTP स्थिति `429` लौटाता है। इंतज़ार करें, फिर अनुरोध दोबारा भेजें।

जब कोई खाता अपने मासिक खोज और इंडेक्सिंग टोकन से आगे जाता है, तो Skynet उस खाते के लिए नए आइटम इंडेक्स करना बंद कर देता है। तब खोज ऐसे काम करती है जैसे सिमेंटिक खोज उपलब्ध न हो।
